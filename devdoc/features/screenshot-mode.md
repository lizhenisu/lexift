# 截图模式与临时贴图

## 交互

标注工具条的截图按钮位于撤销之前，沿用一秒悬停提示。截图按“暂停标注 → 冻结底图 → 框选 → 编辑 → 输出 → 恢复标注”执行；框选期间没有工具条，编辑期间只有截图工具条。

- 已有标注合成进冻结底图；截图文档从空文档开始，拥有独立的对象、参数和撤销历史。截图橡皮擦无法擦掉底图。
- 松手确认非空选区。鼠标模式仅可移动选区及拖动八个尺寸控制点，不能命中或编辑标注对象；选区变化不会变换对象。绘制输入限制在选区内，选区外对象保留但不显示或输出。
- 首次拖出有效选区即在左上角显示 `宽 × 高 px`；框选、移动和八方向缩放期间始终可见并实时更新整体物理像素尺寸，工具条隐藏不影响尺寸标签。支持负坐标及跨显示器选区；每屏保留自己的 DPI。原标注实时呈现路径不变，截图效果只取样冻结帧。
- Escape 优先取消选区手势、文字编辑及现有内部编辑；没有内部编辑时退出截图。右键取消初始框选；Alt+A 退出截图并恢复原标注。截图期间不启动划词或 OCR；打开 Settings 先结束截图。
- 复制、PNG 保存、贴图成功后恢复原标注；取消保存对话框或输出失败保留截图编辑。恢复对象、工具参数、收起状态及撤销历史，并通过既有模式切换进入“鼠标操作”，不恢复此前绘制工具；不长期保留原窗口。

## 职责与所有权

### 选区调整反馈

截图编辑的“鼠标操作”模式下，选区控制点优先执行八方向缩放；选区内部可移动，标注对象不阻挡选区命中。光标与输入共用 `RegionEditor` 的命中及当前调整类型：可移动处显示系统四向移动光标，控制点显示对应缩放光标，手势期间保持开始时的光标。

开始移动或缩放时暂时隐藏截图工具条并清理悬停提示；松手、Escape 取消或捕获丢失后按最终选区恢复位置及显示。取消恢复调整前的选区，参数和收起状态不变。短暂隐藏不销毁组件；显示任务校验截图、工具条实例和调整编号，退出后的旧回调不得恢复窗口。普通标注与贴图编辑不使用这一隐藏规则。

尺寸标签不再使用独立可见窗口。初始框选时，它是框选宿主中的 Slint 视觉组件；编辑时，标签、边界、控制点及遮罩合成到同一份预览像素帧。UI 不提前移动标签，旧版本完整帧不能覆盖已显示的新版本。

标签仅按选区和所属屏幕工作区定位，顺序固定为上方（靠左）、左侧、右侧、下方。外部候选保留 8 个逻辑像素间距，只沿对齐方向夹紧且整块标签必须放入工作区；四处均不足时，在选区内左上角附近保留 8 个逻辑像素内边距，并夹紧到工作区。初始框选和编辑阶段共用该纯函数。

标签与可移动工具条各自独立定位：不做碰撞判断、侧边纵向搜索或空间预留。工具条遮住标签时可以手动拖开，移动或调整工具条尺寸不会改变标签位置。工具条仍在隐藏准备阶段完成自身定位后再显示，调整恢复时重新计算选区、窗口尺寸、工作区和 DPI；手动拖动期间不覆盖其位置。

共享样式与位置计算使用整体物理选区、当前显示器 DPI 和工作区避让；跨屏仅指定一个宿主绘制标签。尺寸文字需要的有限字符在隐藏准备阶段由 Slint 生成纹理，组件随即销毁；拖动只读缓存，不创建、移动或截图标签窗口，不启动标注系统字体扫描。退出截图清理会话缓存，后台任务只持有不可变像素引用。

预览工作线程按显示器保留一份未裁切的标注合成结果及变暗底图。仅移动／缩放选区时复用它们，通过行拷贝和交互装饰更新最终帧；对象、样式、水印、效果覆盖、捕获源或 DPI 变化使对应缓存失效。已有 16ms 调度与合并待处理任务规则保持不变；导出始终使用领域文档和冻结底图，不包含反馈标签或控制点。

当前验证见 [截图尺寸同帧呈现验证](../releases/screenshot-same-frame.md)。此前 [持续显示](../releases/screenshot-size-label.md) 和 [层级修复](../releases/screenshot-label-order.md) 记录保留历史过程，其独立标签窗口方案已被本次替代。

### 鼠标操作与对象编辑

箭头按钮统一称为“鼠标操作”。普通标注中鼠标穿透画布操作桌面；截图中仅移动和缩放选区；贴图标注中鼠标穿透当前目标贴图，工具条仍可操作，其他贴图保持自己的交互策略。

所有宿主的鼠标模式均使用 `EditScope::None`。切入时收尾文字、绘制和参数事务，清空对象选择、悬停、参数面板及控制点，拒绝对象输入与旧参数回调。截图、贴图开始编辑时同样立即同步此范围，不能只改变工具条高亮而保留对象编辑权限。

编辑标注需切换到对应绘制工具，继续复用普通标注的控制点、参数、文字编辑及撤销。截图选区调整不会修改对象；贴图的穿透使用实例所属的 Pin 策略，不将贴图注册为画布，结束标注后恢复普通贴图的拖动、缩放和菜单。

当前验证见 [鼠标模式语义与穿透回归](../releases/mouse-mode-validation.md)。上一轮 [选择对象模式回归](../releases/screenshot-object-selection.md) 的鼠标对象编辑行为已撤销，不再代表当前交互。

`pinned_screenshot` 管理多个独立辅助窗口。每张保留裁切底图、截图模式新增的可编辑标注及独立撤销历史；App 还按纯合成器要求保留必要的效果采样小区域，不保留完整多屏截图。截图前的桌面标注仍是底图像素。窗口无边框、置顶、排除任务栏和 Alt+Tab；主动拖动可取得必要焦点。拖动请求经过窗口实例所属的输入队列，在 Slint 按下回调退出后启动原生移动，避免释放捕获时重入当前回调；窗口关闭取消未执行请求。滚轮围绕鼠标等比缩放并受工作区限制，仅保留可关闭的蓝色光晕，悬停不显示额外边框，不设置右上角关闭按钮；Escape 在菜单关闭后关闭当前交互贴图。

窗口关闭即销毁组件、纹理和输入回调；不写配置、不在重启后恢复。截图取消使输出及未完成窗口准备失效；已完成贴图独立于恢复后的标注。

## 失败与清理

采集、合成或窗口准备失败都会结束截图并重建原标注窗口。退出时取消后台任务、退休输入、销毁截图宿主及全部贴图。选区提交后销毁框选宿主，截图结束释放完整多屏底图及截图会话；贴图仅保留自己的裁切底图、必要采样和独立文档历史。

采集复用现有屏幕后端，多个显示器的冻结不承诺硬件级同一时钟原子快照。本功能未增加依赖、配置、全局快捷键或 workspace crate。

验证与未覆盖范围见 [截图模式验证](../releases/screenshot-mode-2026-10-13.md)。

### 多实例输入与关闭

每张贴图独立管理准备、显示和关闭阶段，以及递增的鼠标按下编号。拖动排队时冻结实例和按下编号，松手或捕获丢失只取消该手势，不退休窗口输入；已显示窗口不再检查截图输出会话是否仍为当前会话。

原生移动使用窗口所属的唯一请求标识。启动前核对捕获归属及按键状态，主动释放捕获时保留交接标记；异步消息再次检查标识、按键、可见性及是否已有其他捕获窗口。旧消息不得清掉较新的请求。迟到松手和取消只释放当前 HWND 自己持有的捕获。

关闭先标记状态、退休输入并取消手势，再由独立关闭任务移出 Registry；原生取消、隐藏及组件析构在 Registry 借用释放后执行。全部关闭先退休所有实例，再逐个销毁。捕获取消不会转换成关闭按钮的有效点击。

本轮验证见 [多贴图输入与生命周期验证](../releases/multi-pin-interaction-2026-10-13.md)。

### 贴图与标注画布层级

贴图在原生层级注册为独立 Pin，位于普通标注画布与 GPU 视觉窗口之上；画布重建、显示或重排时不能覆盖已有贴图。Pin 注册不加入标注采集排除列表，下一次截图仍将已有贴图作为桌面内容冻结。

冻结采集完成后，截图选择及编辑暂时隐藏已有贴图的实时窗口并取消其手势；它们已经包含在冻结底图中，不能再次覆盖选区输入。取消、成功输出或准备失败恢复时，无激活地恢复这些贴图，再重建普通标注画布。该临时隐藏仅持续当前截图交互，关闭仍销毁窗口。

贴图使用可由用户点击激活的输入桥，而非划词工具条的永久被动输入桥；准备和显示仍不抢焦点。右上角关闭组件已移除，关闭入口为菜单和 Escape。

### 贴图菜单与输出

右键采用 Slint 内置 ContextMenuArea，菜单依次为复制图像、保存图像、标注、隐藏标注、窗口阴影、窗口置顶、关闭，按功能分组分隔。菜单优先处理 Escape；保存对话框的 Escape 只取消保存。

标注关闭或处于“鼠标操作”时，贴图接收拖动、缩放和菜单输入；绘制工具选中时，独立的 Pin 原生策略使鼠标穿透到标注画布。进入截图准备时先关闭菜单并禁止贴图输入，但保留实时图像参与冻结；冻结完成后才隐藏实时贴图。

蓝色光晕和置顶默认开启，各实例独立、只在当前进程有效。光晕使用 Colors.primary 为共享高斯透明遮罩着色，以九宫格拉伸保持边缘和四角连续衰减，不绘制实线边框。遮罩为 33×33 RGBA 静态资源（532 bytes），由 `scripts/generate-pin-glow.py` 使用标准库生成；模糊标准差为 2.5px、强度为 1.5，16px 九宫格角区保留 8px 外侧衰减与内侧圆角过渡。Slint 软件渲染器的 drop-shadow 尚未实现，因此不依赖它。光晕不新增 HWND，不按窗口尺寸生成纹理或在缩放时重新计算模糊；外边距不参与图像命中、缩放比例或输出。隐藏准备使用后端实际 DPI 确定物理边距。

取消置顶将实例移出强制置顶层级；后续画布重排不得将其重新置顶。开关失败回滚，准备和属性变更不主动激活窗口。

Core `pinned_image` 管理实例、编辑会话、文档版本、隐藏状态、输出编号及结果；已退休身份不得重用。App 持有裁切底图及必要采样的共享引用，在后台复用纯合成器、ClipboardPort 与 AnnotationSavePort。输出冻结请求时的文档与可见状态，隐藏时仅输出底图；使用原始分辨率，不包含光晕、控制点或菜单。成功、失败及保存取消均保留贴图，编辑期间输出也不退出编辑。

### 贴图标注

“标注”先暂停原屏幕标注，销毁其窗口并保存纯恢复状态，再由共用编辑控制器借用贴图自身的 Surface 和输入桥，不创建第二个画布 HWND。一次只编辑一张贴图，工具条只有一套；操作区为撤销、保存、复制、完成。固定整张图像范围，关闭选区调整、再次贴图及截图入口；编辑时禁用目标窗口拖动和缩放，其他贴图仍可交互。

文档使用稳定的原图物理像素坐标，保留裁切原点和源 DPI 分区；贴图局部输入经视图映射进入文档，移动或缩放不改写几何、字号及撤销历史。文字编辑窗口使用同一正反坐标映射。新水印按图像范围布局，导入水印保持原锚点，撤销恢复原锚点。

“完成”或没有内部编辑时的 Escape 保留可见草稿并退出；原标注恢复为“鼠标操作”，原标注此前关闭时不额外打开。切换编辑目标、Alt+A、进入截图、OCR 或 Settings 前收尾。工具选择、字体、参数事务及撤销继续复用既有实现；捕获丢失取消当前手势，销毁时暂停所属真实原生输入，不能退休仍存活贴图的输入桥。

“隐藏标注”默认关闭，各实例独立，不删除对象或历史。编辑中隐藏会先收尾；隐藏状态进入标注会恢复显示。正文图像与控制点使用分离纹理，结束编辑即释放装饰纹理，后续桌面截图不会捕获控制点。

验证见 [贴图可编辑标注验证](../releases/pinned-image-annotation-2026-10-14.md)。

关闭请求先退休实例输入并取消 Core 输出，再安排独立销毁。菜单右键事件离开原生输入回调后再交给 Slint，防止系统菜单的嵌套消息循环重入输入桥。反馈窗口及重试、超时、关闭回调校验所属实例和反馈版本。

本轮验证见 [贴图菜单与恢复行为验证](../releases/pinned-image-menu-2026-10-14.md)。
