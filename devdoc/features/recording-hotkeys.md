# 录屏全局快捷键

录制期间可从原应用直接控制 Lexift，无需切回控制条：

| 操作 | 默认快捷键 |
| --- | --- |
| 暂停／继续 | Ctrl+Alt+F9 |
| 完成录制并进入预览 | Ctrl+Alt+F10 |

两项可在 Settings 的热键设置页修改，与翻译、标注、OCR、截图共六组组合互斥。保存前后台临时注册验证，再释放；失败保留旧配置。每次开始冻结已成功保存的配置，启动采集前临时注册两键，暂停期间保留，完成、取消、中断、开始失败及退出时注销。准备和倒计时不占键。配置 Schema 12 为旧配置补上默认值，不影响原四键启动注册。

两项独立确认：一项被占用时另一项仍可工作，录制照常开始，工具条提示实际可用按键并通过一次被动提示说明失败项；没有自动换键或连续重试。旧监听未退役时不创建替代线程，当前录制仍可通过控制条操作。

仅实际录制或暂停阶段接受动作，切换和收尾期间忽略，不补执行。Lexift 绘制、平移、拖动、菜单、原生模态输入及 Settings 快捷键录制拥有输入时不执行。标注文字或参数输入期间暂停键忽略，完成键沿用既有文字／参数提交、标注末帧呈现和封尾流程。外部应用输入不受本应用的输入屏蔽条件影响，不拦截其 Escape，不主动激活控制条或画布。

开始请求至收尾期间两项设置只读；取消倒计时返回准备后恢复修改，预览期间可为下一次录制修改。空闲状态显示“录制开始时启用”，不将未注册误报为故障。其他软件通过低层键盘拦截而非系统快捷键注册处理同一组合时，系统注册成功不能保证没有第三方行为；可在 Settings 修改组合。

业务接纳和代次由 Core 管理，App 调度现有 HotkeyPort，Windows 用一个所属消息线程及 MOD_NOREPEAT 管理两键；UI 补充输入与窗口条件检查并复用录屏控制入口。作用域绑定截图会话、录屏操作及注册代次，不绑定随暂停／继续改变的控制请求号。注册中取消由完成方清理迟到成功，退出不在 UI 线程等待注销。

本功能不新增开始录制快捷键、全局 Escape、按钮、托盘项或录制配置入口。[专项验证](../releases/recording-hotkeys.md)区分自动化、真实输入和环境限制。
