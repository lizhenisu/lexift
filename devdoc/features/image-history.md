# 截图与长图图片历史

## 范围与入口

图片历史只保留本次进程内的成功图片输出。入口位于标注工具条及托盘菜单，不增加全局快捷键。退出程序后清空，不写入配置、文本剪贴板数据库或其他持久化文件。

- 静态截图、长截图，以及这些图片后续的贴图和历史编辑，复制图片、保存 PNG／JPEG 或创建贴图成功后才记录。
- 同一逻辑图片有稳定进程内来源身份；再次成功输出更新原记录并移到最前。失败、取消保存、OCR 和取色不更新记录。
- 普通桌面标注导出不纳入图片历史。历史输出和恢复编辑输出不修改 R 的上次桌面区域。
- 不提供跨重启记录、搜索、收藏、录屏或图片自动落盘。外部图片已通过[文件／剪贴板导入](image-import.md)接入，成功输出后以“导入图片”来源记录。

## 历史窗口

使用单份约 800×600 逻辑像素的辅助窗口，限制在入口所在显示器工作区的 90% 内，可拖动和调整大小。列表显示缩略图、类型、最终输出尺寸和最近成功输出时间；右侧等比适应预览。

单击选择条目，双击或 Enter 打开编辑；方向键切换条目，Escape 关闭。列表更新按来源身份保留选择，过期版本不能删除或输出新版本。底部提供编辑、复制、保存、贴图和删除；全部清除需要确认。删除和清空不删除已保存的图片文件，也不关闭已存在的贴图。

已有截图、长图或贴图编辑时，只允许浏览、删除和清空。首次框选、长截图采集、OCR 或外部图片输出忙碌时不打开历史窗口，并退役已打开窗口。成功输出更新数据，不自动打开历史或抢焦点。

## 可编辑恢复

记录保留完整底图、确认裁剪、对象及效果参数、标注显隐、效果采样、来源 DPI 分区和水印锚点，以及同版本成品和预览。

整体方向和颜色文档状态同样保留，包括灰度、反色、九档对比度和九档亮度。恢复后可编辑原始资源；旧历史栈清空，但确认颜色不会丢失。历史直接输出使用已记录成品，重新编辑输出仍按完整合成、裁剪、方向及颜色顺序生成。详见[贴图对比度](pin-interaction.md#对比度)与[贴图亮度](pin-interaction.md#亮度)。

- 静态截图完整底图仅覆盖成功输出的选区，不为历史额外保留整张虚拟桌面。
- 长图保留完整拼接底图，历史中输出已裁剪时，再次编辑仍能扩大裁剪恢复内容。
- 恢复时保留原图坐标和对象身份，清空旧撤销、重做、选择和手势状态；新编辑正常记录撤销和重做。
- 共用图片宿主默认浏览模式、居中适应确认范围，小图不放大。支持拖动平移、鼠标锚点滚轮缩放、空格切换绘图、Ctrl+0、文字、标注和裁剪。
- 右键菜单可以隐藏或重新显示保留的标注。图片源范围可以有负原点；显示、命中、原生文字和裁剪共用同一物理变换。
- 不提供桌面选区移动、宽高输入、比例锁定和重新开始长截图采集。

普通桌面文档可临时挂起，关闭恢复编辑器后恢复文档与工具条并回到鼠标模式。关闭而未成功输出，不改写原记录；失败和取消保存保留当前编辑供重试。图片输出先按原图坐标完整合成，再裁切，避免改变裁剪边缘的效果采样。

## 分层与资源

- Core 的 `image_history` 管理来源、输出票据、版本顺序、容量、删除/清空及恢复编辑阶段。业务完成和后台资源准备都属于同一票据时才接纳。
- App 的 `screenshot_history` 保留不可变资源引用、生成有界预览、执行图片输出。历史直接输出复用成品，恢复编辑复用冻结底图与文档。
- UI 管理单份浏览窗口和临时编辑状态。共用 `image_editor` 宿主区分长图和历史来源，不创建虚假的截图/长截图采集状态。

最多保留 **20 条、512MiB**，按最后成功更新顺序淘汰。共享资源按唯一分配身份计费，包含完整底图、采样、文档、成品、预览和预览的 UI 像素副本；同一分配不会因多条引用重复计费。单条超过预算则跳过并显示被动提示，同源无法替换时保留旧记录。

512MiB 是已接纳历史的资源预算，不是进程工作集或峰值总内存上限；正在输出、采集、编辑和贴图仍可独立拥有资源。删除、清空、淘汰和退出释放历史引用，活跃编辑或贴图的引用继续有效。关闭窗口销毁组件、原生窗口、回调和定时器，不保留隐藏窗口。遵循辅助窗口身份、用户主动激活及两分钟空闲工作集修剪规则。

记录只含进程内身份、几何、阶段、时间和资源字节，不将图片、OCR 正文或个人保存路径写入日志。历史窗口及通知纳入图片采集排除，启动截图时先退役浏览窗口再采集。

## 验证

见 [图片历史专项验证](../releases/screenshot-image-history.md)。

保存 JPEG 时，历史仍保留压缩前成品及完整可编辑资源，不使用有损解码图片替换底图。见[图片保存格式](image-save-formats.md)。

## 独立图片编辑器 OCR

长图结果和历史恢复编辑器支持直接识别底图并复制文字，识别后保留编辑器及视口。详见[图片编辑器 OCR](image-editor-ocr.md)。

独立编辑器现支持右键灰度、反色、亮度、对比度和恢复原始颜色，保留视口与共享历史；详见[独立图片编辑器颜色调整](image-editor-colors.md)。

独立图片编辑器支持[等比调整实际像素尺寸](image-resize.md)，保留原始资源及倍率；图片历史、贴图和 OCR 沿用确认尺寸状态。
