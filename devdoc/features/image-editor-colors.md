# 独立图片编辑器颜色调整

长截图结果、导入文件及图片历史恢复的独立编辑器共用颜色右键菜单。图片和空白视口均可打开；不增加工具条按钮、面板或快捷键。菜单提供灰度、反色、九档亮度、九档对比度和“恢复原始颜色”。亮度与对比度沿用 −100 至 ＋100、间隔 25 的档位，0 表示不调整。

恢复原始颜色一次清除四项颜色参数，保留原图、裁剪、方向、对象及标注显隐；已写入底图的外部滤镜无法撤销。默认颜色时禁用恢复。历史来源原有隐藏标注菜单继续保留。

## 输入与历史

打开画布菜单前收尾文字和参数事务；原生文字输入框继续使用自己的菜单。正在绘制、平移、裁剪草稿、候选准备、OCR 或输出时不执行颜色操作。菜单消费点击和 Escape，不顺带启动画布手势或关闭编辑器。键盘菜单在菜单键及修饰键释放后打开，避免 Windows 原生菜单接管 Shift 松开事件而影响后续撤销；失焦或取消会退役待打开状态。

颜色应用、恢复以及颜色撤销／重做共用文档历史与后台候选渲染。准备时保留旧画面，成功后一起安装文档、像素、反馈和菜单确认值；失败不提交历史。无变化不添加历史，也不清空重做。颜色操作保留工具、有效对象选择、倍率、平移和窗口几何；方向或裁剪的历史操作仍遵守原有适应行为。

## 像素与输出

统一流程为完整原图合成 → 确认范围裁切 → 整体方向 → 灰度 → 反色 → 对比度 → 亮度。图片及标注共同处理；工作区、控制点、文字输入窗口、菜单和工具条保持原色。平移缩放不重新处理底图。

复制、PNG／JPEG 保存、图片历史及新贴图使用确认颜色状态。OCR 使用处理后的确认范围底图，排除新增标注。完整原始资源和颜色参数继续保留，可恢复原始颜色。颜色修改本身不更新图片历史或 R 区域；成功输出沿用原来源规则。

候选校验编辑器、会话、窗口实例和呈现版本；关闭或替换编辑器使旧结果失效。旧成功或失败不能覆盖新画面或解除新任务的忙碌状态。
