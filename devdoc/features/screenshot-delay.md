# 延迟截图

## 入口与行为

标注工具条的截图按钮保持立即截图；右侧 SVG 箭头打开“立即截图、3 秒后截图、5 秒后截图、10 秒后截图”。选择后立即开始，不记忆延迟、不增加快捷键或托盘入口。

倒计时提示位于触发显示器工作区底部居中，16px 逻辑边距，显示剩余秒数与取消按钮。不激活窗口，不注册全局 Escape；用户可继续操作原应用、展开菜单或切换应用。图片编辑、OCR、长截图及输出忙碌时拒绝延迟请求，重复请求不叠加。

## 采集与恢复

Core 使用同一截图会话的 CountingDown 阶段；文档和文字/参数事务先收尾并挂起，工具条、菜单及历史窗口退出。此时不采集底图、不查询窗口或 UIA。现有贴图保持可见以成为到期桌面内容，编辑交互暂停；进入框选后仍沿用原有贴图冻结/恢复流程。

提示原生准备和显示完成后，App 使用 Tokio 可取消任务等待单调时钟截止时间。UI 按截止时间向上取整计算秒数，不累积 tick。到期先销毁提示，再复用截图准备、DWM 呈现同步与采集链路。

到期重新取得鼠标和前台身份，允许倒计时期间主动切换原应用；之后发生新的外部前台变化，仍受现有一次性激活保护。取消不采集像素，恢复标注文档、贴图和工具条，不更新图片历史或 R 区域。

倒计时窗口在隐藏准备阶段使用辅助窗口身份、禁止激活但保留点击输入，并启用原生捕获排除。捕获排除不代替到期销毁。显示准备失败取消任务，不回退为立即截图。

## 生命周期

计时任务按会话取消；旧截止事件不能开始新截图。附加菜单属于工具条实例，关闭或重建工具条退役其回调；截图取消、失败、替换及退出清理窗口、计时器和延迟任务。普通截图键盘入口不改变。
