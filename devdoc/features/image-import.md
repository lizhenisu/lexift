# 从文件与剪贴板打开图片

## 入口与范围

标注工具条的“打开图片”主按钮打开文件，旁侧箭头提供“打开图片”和“从剪贴板贴图”；托盘提供相同入口。没有新增快捷键、配置或自动监听。

- 文件对话框单选 PNG／JPEG，成功后打开独立图片编辑器；默认浏览、整图居中适应，小图不放大。支持已有平移、缩放、标注、文字、非破坏裁剪与图片输出。
- 独立文档编辑器不直接执行截图 OCR，工具条对应入口禁用；需要 OCR 时先创建贴图，再使用贴图右键菜单的“识别文字”。
- 剪贴板图片直接成为普通贴图，保留完整底图，可继续编辑、裁剪和 OCR；导入不写剪贴板。准备贴图时收尾桌面事务并进入鼠标模式，原文档和历史保留；准备失败恢复原工具，成功后保持鼠标模式，让新贴图立即可操作。
- 已有截图、长图、贴图或独立图片编辑尚未结束，以及采集、OCR、输出或导入忙碌时，不接受新导入。重复请求不叠加。普通桌面文档在独立编辑器打开时挂起，关闭后恢复。
- 取消文件选择不弹错误；无图片、数据损坏或准备失败以被动提示反馈，不替换原文档。未接入拖放、文件关联、多选、网址或剪贴板文件列表。

## 像素与资源

Windows 使用现有 WIC 和辅助窗口策略。按实际编码限定 PNG／JPEG，应用 JPEG EXIF 方向；保持 PNG 透明度，统一转换为 `(0,0)` 原点的紧密预乘 RGBA。打印 DPI 元数据不改变原始像素尺寸。

剪贴板依次读取注册 PNG、DIBV5、DIB、BITMAP。无 Alpha 的传统位图按不透明处理；检查头部、位深、掩码、调色板、方向、行跨度和缓冲边界。复制系统数据后释放剪贴板锁，再解码；不释放系统拥有的句柄。

沿用 4000 万像素限制；编码文件和剪贴板块另限 160,000,000 字节，防止在解码前分配过大的缓冲。无 HDR 或新增色彩管理。后台结果以导入操作号和编辑宿主编号隔离；不记录图片正文或个人文件路径。

## 编辑、历史与焦点

每次导入分配新的进程内来源。同一路径重新打开也不视为同源。文件打开和关闭不产生历史；复制、保存或贴图成功后，以“导入图片”类型进入现有 20 条／512MiB 历史。剪贴板导入在原生贴图准备成功后记录；后续输出沿用同一来源。导入输出不修改 R 的桌面区域记录。

图片从空文档及空撤销栈开始，裁剪保留完整底图；保存使用现有 PNG／JPEG 对话框，不自动覆盖来源文件。独立编辑器复用共用视口，显示、命中及导出始终使用原图坐标。

窗口显示前准备辅助身份；迟到结果不能重开已取消的窗口。解码结束时已转到外部应用，不把该外部前台作为新的自动激活授权。关闭时销毁所属组件、回调和任务，沿用空闲内存修剪机制。

验证范围见[图片导入验证](../releases/image-import.md)。
