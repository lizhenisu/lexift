# 图片尺寸调整

长图结果、文件导入及图片历史恢复的独立编辑器提供右键“调整图片尺寸”。普通截图、桌面标注和贴图没有新增入口。

## 操作

紧凑面板提供宽、高、像素单位、原始尺寸、取消和应用。两个输入框均可编辑，按当前确认裁剪及方向下的原始尺寸联动，宽度默认选中。Tab 切换，Enter 应用，Escape、关闭、失焦或外部点击取消；标题栏可拖动。

只接受正整数，最小 1×1px。非法、溢出或超出资源限制时禁用应用并显示原因。可计算的超限尺寸仍联动显示另一边的草稿，不以旧高度或宽度误导用户。输入只改变草稿；未修改草稿直接确认保留已有精确倍率。“原始尺寸”只将草稿设为 1:1，保留裁剪、方向和颜色。

## 非破坏文档与像素

倍率保存为约分后的正有理数，原始底图、对象坐标、效果采样及水印锚点保留。成功提交一次共享历史；无变化、取消及失败不新增历史，也不清空重做。裁剪保留倍率，90° 旋转交换输出宽高；尺寸计算四舍五入并保证每边至少一像素。

成品按“完整原图合成 → 确认裁剪 → 整体方向 → 颜色 → 尺寸重采样”生成。缩小采用覆盖面积加权，放大采用像素中心双线性插值；预乘 RGBA 各通道与 Alpha 同步处理，透明像素归零，1:1 复用像素。后台逐行处理并检查取消，不生成放大的完整源底图。

目标仍限制 4000 万像素，源合成、反馈及目标替换缓冲按既有 512MiB 预算预检；不满足限制时拒绝操作。扩大裁剪导致超限时保留草稿，不自动降低倍率。

新建标注的笔宽、字号、圆角等长度以目标图片像素解释，保存时反算为原图单位；选中已有对象显示有效长度。原始显示器 DPI 分区仍用于原图合成。图片编辑器的参数单位约定随文档进入贴图，恢复 1:1 或撤销尺寸后仍保留；它不作为一个像素历史步骤。

## 视口、OCR 与恢复

编辑器 100% 表示一个调整后像素对应一个屏幕物理像素；浏览缩放和平移只更新视图变换。候选准备成功后一次提交文档、内容、反馈与坐标映射，再居中适应；失败保留旧文档与画面。

OCR 采用确认底图的裁剪、方向、颜色和调整后分辨率，排除新增标注。复制、PNG/JPEG 保存及贴图使用同一确认成品；JPEG 白底仍在保存编码阶段执行。

图片历史和生成贴图保留原始资源及精确倍率，可继续编辑、裁剪扩大、撤销/重做和恢复 1:1。贴图锁定时禁止涉及倍率变化的历史操作。修改尺寸本身不更新图片历史或 R 区域，独立编辑器输出仍不更新 R。
