# 主页面使用指南

主页面是只读的“开始使用”指南，不再提供翻译输入、译文或生成状态。顶部仅保留 Settings 操作，翻译交互继续使用 Popup。

## 内容与快捷键

四张卡片分别介绍选中文字翻译、屏幕 OCR、截图与标注、长截图与图片处理。图片导入和图片历史的位置为托盘菜单；截图可通过 Alt+S 直接启动；长截图仍从截图编辑工具条进入。页面止于四张卡片，不再显示底部快捷键设置说明、R 复用提示或分隔线。

默认快捷键为 Alt+X、Alt+T、Alt+A、Alt+S；截图卡片区分直接截图与标注工具条按键。展示值来自实际注册结果，而非 Settings 草稿：修改失败但旧键仍有效时显示旧键和失败提示；没有注册成功的按键显示不可用。OCR 关闭时说明需在 Settings 启用。打开指南不会触发翻译、OCR、抓图、下载或网络请求。

## 布局与生命周期

默认 720×640 逻辑像素，按入口屏幕工作区限制；640px 起双列，较窄时单列，内容溢出可滚动。卡片和快捷键仅展示信息，不承载启动动作。沿用主题、SVG 图标、辅助窗口身份、托盘打开及关闭销毁规则；普通状态更新不重新打开主页。重开时使用最新运行状态重建指南。

Core 的注册能力快照只记录当前注册成功的快捷键。App 在启动注册及运行配置应用完成后回报快照，UI 的独立指南映射不借用 Settings 草稿。Popup 和 OCR 翻译仍使用原链路。

专项证据和覆盖范围见[主页面验证记录](../releases/main-usage-guide.md)。

## 默认后台启动

普通启动和既有 `--background` 启动均只初始化后台运行时、托盘和快捷键，不创建指南窗口。重复启动退出新进程，原实例不打开指南或改变焦点。用户可从托盘主动打开主页及 Settings；托盘注册失败时例外显示主页，关闭时沿用无托盘即退出策略。没有新增设置或启动参数。
