# 贴图交互与显示

每张新贴图默认可移动、可缩放并接收鼠标。右键菜单提供独立的“锁定位置与大小”和“鼠标穿透”勾选项；仅属于当前窗口实例，不进入配置、图片历史或标注撤销栈。

## 锁定

锁定后禁止普通拖动、滚轮缩放和原生移动入口，仍可标注、复制、保存、OCR、隐藏标注、切换阴影和置顶，以及关闭。裁剪须先解锁。撤销／重做如果将改变图片显示范围的尺寸，则停在该历史条目，不跳过；普通标注历史仍可使用。DPI 和工作区变化所需的系统调整不受锁定限制。

编辑期间可以切换锁定，但绘制、裁剪、候选合成、OCR 和图片输出期间禁止修改策略。进入穿透前必须结束编辑。

## 鼠标穿透与恢复

开启后，点击、右键、拖动和滚轮交给下方应用，贴图也不消费本地按键。短暂被动提示说明恢复入口。托盘的“取消所有贴图鼠标穿透”只取消穿透，不改变锁定、置顶和阴影，不激活贴图；没有可恢复实例时禁用。

恢复逐张确认，失败项保留穿透状态并提示错误，允许重试；其他成功项不回滚。截图或倒计时挂起期间恢复不会显示隐藏的贴图，截图结束按最新策略恢复。关闭后丢弃策略，同源图片再次贴图仍使用默认值。

## 接线与资源

Core 管理每实例的已应用策略、待处理策略和递增编号；App 调度 UI 窗口桥接，Platform 安装原生策略，成功后才确认。窗口实例、策略编号和会话共同隔离迟到结果。用户策略与临时输入屏蔽分开，最终输入能力取交集，OCR 完成和样式重写不得解除穿透。

Windows 普通 HWND 的 HTTRANSPARENT 不足以完成跨应用穿透。穿透期间在**原有贴图 HWND** 上使用既有 RGBA 呈现桥接安装分层快照，与 WS_EX_TRANSPARENT 配合；恢复时交还 Slint 重绘。本地键盘输入独立禁用。不新增窗口，不轮询；尺寸／DPI 通知合并刷新，关闭释放所属回调。贴图仍属于桌面内容，不套用截图交互层的捕获排除标记。底图、文档与导出像素不变。原生依据见 [Windows 分层窗口说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。

验证和未覆盖范围见[专项记录](../releases/pin-lock-passthrough.md)。

## 透明度

右键菜单的“透明度”子菜单提供 100%、80%、60%、40%、20% 五档，单选后立即生效。每张新贴图默认 100%，只保留于当前实例；锁定不阻止调节，托盘恢复鼠标穿透也不改变透明度。穿透期间须先通过托盘恢复输入，再调节透明度。

编辑空闲时可调节，先收尾文字和参数事务；保留工具与当前透明度。绘制、拖动、裁剪草稿、候选合成、OCR、输出或策略变更期间禁用。图片背景、底图及标注统一衰减一次，边框、阴影、控制点、裁剪反馈、文字输入和工具条保持原有显示效果。不改变命中范围或自动开启穿透。

透明度只影响显示，不改变标注文档、撤销／重做、效果采样、复制、PNG／JPEG、OCR、历史或 R 区域。历史或编辑器再次创建贴图使用默认 100%。再次截图时，冻结的是贴图当前透明度与下层桌面的实际合成画面。

普通显示只更新 Slint 内容组属性；背景在既有图片上传中合入显示纹理，原始资源保持不变。穿透显示仍使用同一 HWND 的快照，直通 RGBA 在交给原生分层呈现前原地转换为预乘 RGBA。透明度调节不重新合成长图、不复制底图、不使用整窗 Alpha。蓝色阴影蒙版中心透明，避免在低透明度时遮住下层桌面。

透明度的验证结果和未覆盖范围见[专项记录](../releases/pin-opacity.md)。

## 统一隐藏与恢复

托盘提供“隐藏所有贴图”和“恢复隐藏贴图”，无可操作对象时禁用。隐藏只作用于请求时已有、未被用户隐藏的贴图；之后新建的贴图正常显示，不自动加入旧批次。恢复只显示用户隐藏的贴图，不激活窗口，保留位置、物理大小、置顶、阴影、锁定、穿透及透明度。工作区未变化时不调整几何；工作区变化后仅在需要时夹紧。

任意贴图编辑、绘制、拖动、裁剪、候选合成、OCR、图片输出、策略变更或显隐批次未结束时，两项操作暂时禁用。截图倒计时、截图、长截图、独立 OCR 和图片导入／输出期间同样禁用；任务结束后须手动恢复，不登记延迟恢复意图。普通桌面标注文档不因显隐操作被替换或修改。

窗口隐藏与“隐藏标注”是不同状态。用户隐藏的贴图不进入新截图；截图取消、输出结束、OCR 完成和托盘恢复穿透都不会将其显示。操作不改变图片、裁剪、标注、历史、撤销／重做或 R 区域，不写配置或磁盘。

Core 冻结显隐批次的目标 ID，逐张接收窗口完成结果。成功项独立确认，失败项保留原状态，批次结束只显示一次被动错误提示，可通过原菜单重试。关闭目标会退役所属请求，旧结果不能操作新窗口。批次期间不接受新的图片任务，仍可关闭贴图和退出程序。

隐藏保留存活贴图及其资源，不销毁后重建。窗口关闭才释放组件、原生资源、回调及任务；保留的隐藏实例仍计入既有存活窗口判断，工作集修剪不替代资源释放。恢复取消旧空闲计时。原生恢复复用原窗口及输入接收器，重新完成辅助窗口与交互桥接准备，再显示；不通过恢复时主动激活来修补输入。

验证结果与未覆盖范围见[贴图显隐专项记录](../releases/pin-visibility.md)。

## 旋转与翻转

普通贴图和编辑中的贴图均可通过右键“旋转／翻转”子菜单向左／向右旋转 90°，或按当前画面水平／垂直翻转。不增加工具条按钮及快捷键。编辑中先提交文字、参数事务，完成后保留工具；普通贴图不自动进入编辑。

四项操作在锁定时全部禁用，包括正方形图片和不改变尺寸的翻转。锁定时，下一步撤销／重做若涉及方向变化也不能执行，不跳过该历史条目；原裁剪尺寸锁定规则继续保留。穿透贴图需先从托盘恢复鼠标操作。手势、裁剪草稿、候选合成、OCR、输出、策略变更及显隐批次期间不接受方向操作。

变换固定图片内容中心，保留物理缩放；阴影外边距不参与中心计算。以原内容中心所属工作区计算边界，超出时仅缩小和夹紧，小图不放大；方向撤销／重做采用相同规则。保留分数中心，避免奇偶尺寸反复旋转造成累计漂移；普通裁剪仍固定左上角。

方向、裁剪和标注保留在同一非破坏历史中；普通贴图变换后进入编辑可以撤销。候选后台合成成功后同时安装文档、像素、窗口几何和输入映射；失败保留原结果及历史，旧回调不提交新窗口。完整底图和原图坐标不改变，不重新栅格化标注。

复制、保存和历史成品继续先完整合成、再裁剪、最后整体变换；OCR 使用当前方向排列的确认底图，不包含新增标注。方向操作本身不更新图片历史或 R，成功输出才按原来源规则更新历史。实测和限制见[贴图旋转／翻转验证](../releases/pin-image-transform.md)。
