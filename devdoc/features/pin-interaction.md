# 贴图交互与显示

每张新贴图默认可移动、可缩放并接收鼠标。右键菜单提供独立的“锁定位置与大小”和“鼠标穿透”勾选项；仅属于当前窗口实例，不进入配置、图片历史或标注撤销栈。

## 锁定

锁定后禁止普通拖动、滚轮缩放和原生移动入口，仍可标注、复制、保存、OCR、隐藏标注、切换阴影和置顶，以及关闭。裁剪须先解锁。撤销／重做如果将改变图片显示范围的尺寸，则停在该历史条目，不跳过；普通标注历史仍可使用。DPI 和工作区变化所需的系统调整不受锁定限制。

编辑期间可以切换锁定，但绘制、裁剪、候选合成、OCR 和图片输出期间禁止修改策略。进入穿透前必须结束编辑。

## 鼠标穿透与恢复

开启后，点击、右键、拖动和滚轮交给下方应用，贴图也不消费本地按键。短暂被动提示说明恢复入口。托盘的“取消所有贴图鼠标穿透”只取消穿透，不改变锁定、置顶和阴影，不激活贴图；没有可恢复实例时禁用。

恢复逐张确认，失败项保留穿透状态并提示错误，允许重试；其他成功项不回滚。截图或倒计时挂起期间恢复不会显示隐藏的贴图，截图结束按最新策略恢复。关闭后丢弃策略，同源图片再次贴图仍使用默认值。

## 接线与资源

Core 管理每实例的已应用策略、待处理策略和递增编号；App 调度 UI 窗口桥接，Platform 安装原生策略，成功后才确认。窗口实例、策略编号和会话共同隔离迟到结果。用户策略与临时输入屏蔽分开，最终输入能力取交集，OCR 完成和样式重写不得解除穿透。

Windows 普通 HWND 的 HTTRANSPARENT 不足以完成跨应用穿透。穿透期间在**原有贴图 HWND** 上使用既有 RGBA 呈现桥接安装分层快照，与 WS_EX_TRANSPARENT 配合；恢复时交还 Slint 重绘。本地键盘输入独立禁用。不新增窗口，不轮询；尺寸／DPI 通知合并刷新，关闭释放所属回调。贴图仍属于桌面内容，不套用截图交互层的捕获排除标记。底图、文档与导出像素不变。原生依据见 [Windows 分层窗口说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。

验证和未覆盖范围见[专项记录](../releases/pin-lock-passthrough.md)。

## 透明度

右键菜单的“透明度”子菜单提供 100%、80%、60%、40%、20% 五档，单选后立即生效。每张新贴图默认 100%，只保留于当前实例；锁定不阻止调节，托盘恢复鼠标穿透也不改变透明度。穿透期间须先通过托盘恢复输入，再调节透明度。

编辑空闲时可调节，先收尾文字和参数事务；保留工具与当前透明度。绘制、拖动、裁剪草稿、候选合成、OCR、输出或策略变更期间禁用。图片背景、底图及标注统一衰减一次，边框、阴影、控制点、裁剪反馈、文字输入和工具条保持原有显示效果。不改变命中范围或自动开启穿透。

透明度只影响显示，不改变标注文档、撤销／重做、效果采样、复制、PNG／JPEG、OCR、历史或 R 区域。历史或编辑器再次创建贴图使用默认 100%。再次截图时，冻结的是贴图当前透明度与下层桌面的实际合成画面。

普通显示只更新 Slint 内容组属性；背景在既有图片上传中合入显示纹理，原始资源保持不变。穿透显示仍使用同一 HWND 的快照，直通 RGBA 在交给原生分层呈现前原地转换为预乘 RGBA。透明度调节不重新合成长图、不复制底图、不使用整窗 Alpha。蓝色阴影蒙版中心透明，避免在低透明度时遮住下层桌面。

透明度的验证结果和未覆盖范围见[专项记录](../releases/pin-opacity.md)。

## 统一隐藏与恢复

托盘提供“隐藏所有贴图”和“恢复隐藏贴图”，无可操作对象时禁用。隐藏只作用于请求时已有、未被用户隐藏的贴图；之后新建的贴图正常显示，不自动加入旧批次。恢复只显示用户隐藏的贴图，不激活窗口，保留位置、物理大小、置顶、阴影、锁定、穿透及透明度。工作区未变化时不调整几何；工作区变化后仅在需要时夹紧。

任意贴图编辑、绘制、拖动、裁剪、候选合成、OCR、图片输出、策略变更或显隐批次未结束时，两项操作暂时禁用。截图倒计时、截图、长截图、独立 OCR 和图片导入／输出期间同样禁用；任务结束后须手动恢复，不登记延迟恢复意图。普通桌面标注文档不因显隐操作被替换或修改。

窗口隐藏与“隐藏标注”是不同状态。用户隐藏的贴图不进入新截图；截图取消、输出结束、OCR 完成和托盘恢复穿透都不会将其显示。操作不改变图片、裁剪、标注、历史、撤销／重做或 R 区域，不写配置或磁盘。

Core 冻结显隐批次的目标 ID，逐张接收窗口完成结果。成功项独立确认，失败项保留原状态，批次结束只显示一次被动错误提示，可通过原菜单重试。关闭目标会退役所属请求，旧结果不能操作新窗口。批次期间不接受新的图片任务，仍可关闭贴图和退出程序。

隐藏保留存活贴图及其资源，不销毁后重建。窗口关闭才释放组件、原生资源、回调及任务；保留的隐藏实例仍计入既有存活窗口判断，工作集修剪不替代资源释放。恢复取消旧空闲计时。原生恢复复用原窗口及输入接收器，重新完成辅助窗口与交互桥接准备，再显示；不通过恢复时主动激活来修补输入。

验证结果与未覆盖范围见[贴图显隐专项记录](../releases/pin-visibility.md)。

## 旋转与翻转

普通贴图和编辑中的贴图均可通过右键“旋转／翻转”子菜单向左／向右旋转 90°，或按当前画面水平／垂直翻转。不增加工具条按钮及快捷键。编辑中先提交文字、参数事务，完成后保留工具；普通贴图不自动进入编辑。

四项操作在锁定时全部禁用，包括正方形图片和不改变尺寸的翻转。锁定时，下一步撤销／重做若涉及方向变化也不能执行，不跳过该历史条目；原裁剪尺寸锁定规则继续保留。穿透贴图需先从托盘恢复鼠标操作。手势、裁剪草稿、候选合成、OCR、输出、策略变更及显隐批次期间不接受方向操作。

变换固定图片内容中心，保留物理缩放；阴影外边距不参与中心计算。以原内容中心所属工作区计算边界，超出时仅缩小和夹紧，小图不放大；方向撤销／重做采用相同规则。保留分数中心，避免奇偶尺寸反复旋转造成累计漂移；普通裁剪仍固定左上角。

方向、裁剪和标注保留在同一非破坏历史中；普通贴图变换后进入编辑可以撤销。候选后台合成成功后同时安装文档、像素、窗口几何和输入映射；失败保留原结果及历史，旧回调不提交新窗口。完整底图和原图坐标不改变，不重新栅格化标注。

复制、保存和历史成品继续先完整合成、再裁剪、最后整体变换；OCR 使用当前方向排列的确认底图，不包含新增标注。方向操作本身不更新图片历史或 R，成功输出才按原来源规则更新历史。实测和限制见[贴图旋转／翻转验证](../releases/pin-image-transform.md)。

## 贴图倍率与编辑视口

右键“缩放”提供 25%、50%、75%、100%、150%、200% 和“适应工作区”，父菜单显示当前物理倍率。100% 表示一个原图像素对应一个屏幕物理像素；图片 DPI 元数据和显示器缩放不改变原始像素尺寸。倍率、平移和普通显示返回几何只属于当前贴图实例，不写配置、图片历史或撤销栈。

普通显示按指定倍率调整窗口，固定图片内容中心，滚轮按鼠标锚点每档 1.1 倍缩放，精细增量累计整档。窗口可越出工作区，但至少保留 64×64 逻辑像素的可操作内容（图片较小时取实际大小）。适应是一次性居中操作，小图不放大。默认软件渲染的保守窗口预算为外框单边 8192 物理像素、外框 1600 万像素；超过预算的档位禁用并注明限制，不能将请求的 100% 静默缩小。其他未确认的渲染器保留工作区内限制；这是本应用的分配预算，不是 Windows 的窗口尺寸上限。

进入编辑复用原 HWND，保存普通显示倍率及返回位置；窗口沿用当前大小，过大时限制在工作区的 90% 内。图片在主题点阵视口中显示，浏览模式左键平移、滚轮围绕鼠标放大，空格在浏览和上次绘图工具间切换。绘图模式保留原滚轮操作。局部放大没有 1000% 等固定产品倍率上限，但受原有 f32 标注坐标精度限制；不能区分相邻屏幕像素或往返误差超过半个物理像素时，拒绝继续放大，保留有效视图。视口尺寸和缓冲始终有界，不按放大倍率分配整张长图纹理。

平移时 Escape 恢复本次起点并消费按键；失焦或捕获丢失结束平移并保留位置。拖动中不切换模式或修改倍率，输入框和菜单优先消费按键。锁定禁止倍率修改；穿透须先从托盘恢复。裁剪、候选合成、OCR、输出、策略变更、显隐批次和截图挂起时禁用倍率操作。绘图和浏览的工具条选中态同步；鼠标模式按钮沿用一秒延迟提示说明浏览操作。

裁剪在同一视口内暂时适应完整底图，取消恢复原视图；应用或范围／方向历史变化后适应确认结果。普通返回几何随裁剪固定左上角、随方向变化固定中心，结束编辑恢复普通倍率及相应几何，不将局部放大变成巨大普通窗口。恢复完整长图后仍检查返回窗口预算。复制和保存不结束编辑。

图片、标注命中、光标及原生文字输入共用原图／方向／裁剪／视口的变换。后台编辑预览仍按原始分辨率合成；视图变化只从不可变预览提取有界显示像素，不重新合成文档或复制完整底图。图片及标注统一应用贴图透明度；点阵、控制层和工具条不淡化。复制、保存、OCR 和历史继续使用完整确认范围的原始像素，与当前可见局部、平移和倍率无关。隐藏保留实例视图，关闭释放缓冲、捕获、光标及回调。

实际验证与未覆盖范围见[贴图倍率验证记录](../releases/pin-image-zoom.md)。

## 灰度与反色

右键菜单提供“灰度”“反色”两个独立勾选项，可同时启用；组合顺序固定为先灰度再反色。它们属于可编辑图片文档，与标注、裁剪和方向共用撤销／重做历史，不同于仅影响窗口显示的透明度。新导入原图默认关闭；从贴图或历史保留的文档继续保留确认值。关闭开关可恢复原始颜色，不修改完整底图。

普通贴图直接处理，不自动进入编辑；编辑中先收尾文字和参数事务，完成后保留当前工具、倍率、平移和窗口几何。锁定允许颜色处理及其历史操作；穿透须先恢复输入。绘制、拖动、裁剪草稿、候选合成、OCR、图片输出、策略和显隐批次期间禁止修改。失败保留旧画面及历史，迟到结果按窗口实例、请求和呈现版本隔离。

图片处理顺序为完整原图合成、确认范围裁切、整体方向、颜色处理；因此新增标注和效果一起变色，而边框、控制点、文字输入及工具条保持原色。预乘 RGBA 的灰度为 `(54R + 183G + 19B + 128) >> 8`，反色为 `A - 通道值`，Alpha 不变。透明像素处理后归零。显示缓存、输出及 OCR 共用纯像素算法，透明度仍只影响窗口显示。

OCR 使用确认裁剪和方向下经过颜色处理的底图，排除新增标注；处理不保证提高识别率。复制、PNG／JPEG、图片历史和新贴图保留颜色状态，JPEG 白底合成在编码阶段执行。历史恢复清空旧操作栈并保留状态；共用编辑器本轮没有颜色菜单，可再次贴图后取消勾选。颜色切换本身不更新历史或 R，成功输出沿用原来源规则。

验证与未覆盖范围见[专项记录](../releases/pin-image-color.md)。

## 亮度

右键“亮度”提供 −100、−75、−50、−25、0、＋25、＋50、＋75、＋100 九档，单选显示确认值；0 标为“不调整”，只取消亮度，不取消灰度或反色。普通和编辑中的贴图均可使用，锁定不限制亮度；手势、裁剪草稿、候选合成、OCR、输出、策略变更、显隐批次及截图挂起期间禁用。普通贴图不会自动进入编辑；编辑中先收尾文字和参数事务，保留工具、窗口、倍率和平移。

亮度是图片文档属性，与标注、裁剪、方向及其他颜色调整共享撤销／重做。成功确认记一步，无变化、失败和取消不提交；从历史或贴图恢复的文档保留确认值。完整原始底图始终保留，每次重新合成后再处理，不在上次已调整的像素上叠加。颜色顺序为**灰度 → 反色 → 对比度 → 亮度**，位于完整合成、确认范围裁剪和方向之后。

对于预乘 RGBA，档位 `B` 产生偏移 `sign(B) × ((A × abs(B) + 50) / 100)`，整数除法，三个通道分别加偏移并限制到 `[0,A]`，Alpha 不变，透明像素归零。−100／＋100 分别为保留透明度的黑色／白色；档位是加性偏移，不是乘法曝光或窗口透明度。

复制、PNG／JPEG、图片历史及后续贴图保留相同结果和可编辑颜色状态；JPEG 白底处理仍在编码阶段执行。OCR 处理确认范围、方向和颜色状态下的底图，排除新增标注。亮度不改变控制层、效果采样原图、输出尺寸或 R 区域；操作本身不更新图片历史，成功输出才更新。窗口透明度在内容处理后独立应用。

候选失败保留旧画面和历史，旧请求不能覆盖新实例；平移、缩放及透明度变化不重新执行整图亮度处理。本轮不增加共用图片编辑器的亮度菜单，可生成贴图后继续调整。验证见[亮度专项记录](../releases/pin-brightness.md)。

## 对比度

普通及编辑贴图右键提供“对比度”九档：−100、−75、−50、−25、0、＋25、＋50、＋75、＋100，默认 0，标为“不调整”；恢复 0 不取消灰度、反色和亮度。调整围绕中间灰展开，增益为 `(100 + K) / 100`；−100 收敛至中间灰，＋100 放大差异至 2 倍，超出通道范围时截断。

对比度在灰度／反色之后、亮度之前执行。预乘通道 `C`、Alpha `A` 和档位 `K` 使用 `N = 200 × C + K × (2 × C − A)`；以 i32 计算，`N / 200` 四舍五入、半值远离零，再夹紧至 `[0,A]`。不反预乘，Alpha 不变，完全透明像素归零。对比度为 0 时现有输出逐像素保持不变。

对比度属于图片文档，与标注、裁剪、方向及其他颜色共享历史；保留完整原图，每次从原始资源生成，不累计处理成品。成功确认记一步；相同值、取消和失败不提交历史，不清除重做。普通贴图不自动进入编辑，编辑中先收尾文字和参数事务，保留工具、焦点、倍率、平移和几何。

锁定允许调整；穿透须先恢复输入。手势、裁剪草稿、候选合成、OCR、输出、策略变更、显隐批次及截图挂起时禁用。候选成功后统一安装文档、像素和呈现版本，失败保留旧画面，旧回调继续按所属实例与请求隔离。

图片及标注统一处理，背景与控制层不处理，窗口透明度独立应用。复制、PNG／JPEG、历史恢复、新贴图及 OCR 沿用全部确认颜色状态；OCR 仍排除新增标注，不保证识别率改善。操作本身不更新图片历史或 R，成功输出才按来源更新历史。本轮没有增加独立编辑器颜色入口、滑杆、配置或快捷键。验证见[对比度专项记录](../releases/pin-contrast.md)。

独立图片编辑器支持[等比调整实际像素尺寸](image-resize.md)，保留原始资源及倍率；图片历史、贴图和 OCR 沿用确认尺寸状态。
