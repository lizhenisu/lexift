# 贴图锁定与鼠标穿透

每张新贴图默认可移动、可缩放并接收鼠标。右键菜单提供独立的“锁定位置与大小”和“鼠标穿透”勾选项；仅属于当前窗口实例，不进入配置、图片历史或标注撤销栈。

## 锁定

锁定后禁止普通拖动、滚轮缩放和原生移动入口，仍可标注、复制、保存、OCR、隐藏标注、切换阴影和置顶，以及关闭。裁剪须先解锁。撤销／重做如果将改变图片显示范围的尺寸，则停在该历史条目，不跳过；普通标注历史仍可使用。DPI 和工作区变化所需的系统调整不受锁定限制。

编辑期间可以切换锁定，但绘制、裁剪、候选合成、OCR 和图片输出期间禁止修改策略。进入穿透前必须结束编辑。

## 鼠标穿透与恢复

开启后，点击、右键、拖动和滚轮交给下方应用，贴图也不消费本地按键。短暂被动提示说明恢复入口。托盘的“取消所有贴图鼠标穿透”只取消穿透，不改变锁定、置顶和阴影，不激活贴图；没有可恢复实例时禁用。

恢复逐张确认，失败项保留穿透状态并提示错误，允许重试；其他成功项不回滚。截图或倒计时挂起期间恢复不会显示隐藏的贴图，截图结束按最新策略恢复。关闭后丢弃策略，同源图片再次贴图仍使用默认值。

## 接线与资源

Core 管理每实例的已应用策略、待处理策略和递增编号；App 调度 UI 窗口桥接，Platform 安装原生策略，成功后才确认。窗口实例、策略编号和会话共同隔离迟到结果。用户策略与临时输入屏蔽分开，最终输入能力取交集，OCR 完成和样式重写不得解除穿透。

Windows 普通 HWND 的 HTTRANSPARENT 不足以完成跨应用穿透。穿透期间在**原有贴图 HWND** 上使用既有 RGBA 呈现桥接安装分层快照，与 WS_EX_TRANSPARENT 配合；恢复时交还 Slint 重绘。本地键盘输入独立禁用。不新增窗口，不轮询；尺寸／DPI 通知合并刷新，关闭释放所属回调。贴图仍属于桌面内容，不套用截图交互层的捕获排除标记。底图、文档与导出像素不变。原生依据见 [Windows 分层窗口说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。
