# 图片编辑器 OCR 识别复制

长图结果、文件导入和图片历史恢复的独立编辑器均通过工具条“识别文字”读取当前确认裁剪范围内的底图。隐藏标注不改变识别内容；新增标注、遮罩和窗口装饰不参与识别。静态截图仍沿用识别完成后关闭截图的行为。

请求前收尾文字与参数事务；绘制、平移、裁剪草稿或输出期间不接受请求。识别期间暂停标注、裁剪、撤销／重做和图片输出，临时切到浏览输入，允许平移、缩放、移动及调整窗口。结束后恢复原工具；正在平移时，等当前手势结束再恢复，保留视口位置。

所属编辑器或工具条中 Escape 取消识别，不关闭编辑器；菜单和输入控件先处理自己的按键。普通失焦不取消 OCR。关闭或替换编辑器取消所属请求，迟到结果不能改变新窗口。新图片 OCR 替换旧图片 OCR，系统写入开始前检查取消，已开始的剪贴板写入可完成。

成功复制、空结果、资源不可用、识别失败及复制失败均保留编辑器，通过约三秒的被动提示反馈。空结果和失败不写剪贴板；取消不显示旧提示，不自动翻译、下载模型或打开设置。

Core 管理宿主、操作和冻结范围；App 从所属完整底图裁切，并按请求冻结的图片方向排列像素后识别，共用贴图的最新请求队列、OCR 推理资源、长图分块与串行剪贴板写入。浏览和 OCR 均不改变对象、确认裁剪、撤销历史、图片历史排序或 R 区域记录，不新增识别正文持久化。

验证见[图片编辑器 OCR 验证](../releases/image-editor-ocr.md)。

旋转或翻转后的识别以显示方向为准，不按文字、序号或贴纸的局部朝向重采样。窗口 DPI、缩放和平移均不改变识别输入。专项检查见[旋转／翻转验证](../releases/image-editor-transform.md)。

贴图文档的灰度／反色也适用于历史恢复的共用图片编辑器 OCR：确认底图先裁切、按当前方向排列，再按灰度后反色处理；新增标注仍排除。窗口透明度与浏览倍率不进入 OCR。见[贴图颜色处理](pin-interaction.md#灰度与反色)。
