# 大图编辑性能与资源管理

独立图片编辑器和贴图编辑的后台预览将确认内容与交互反馈分开处理，保持原有全分辨率画质、重采样和输出规则。

## 内容复用

同一冻结源图、文档内容、DPI 分区、裁剪、方向、颜色及尺寸倍率可以共用一个不可变内容缓冲。每个 worker 的可重建内容缓存最多 32MiB；超过时仍正常呈现并释放可重建缓存，不降低图片尺寸或预览画质。选择、悬停和手势反馈独立生成；独立编辑器在内容身份不变时不重复安装底图。浏览缩放、平移和窗口移动仍仅改变视口。

源图或文档内容变化时淘汰旧的 worker 内容缓存，再生成候选；已经安装的 Slint 画面保留到候选就绪。单分区合成结果直接移交，完整范围进入重采样前不再额外复制裁切图片。可变成品与反馈仍有各自所有权。

## 队列与取消

每个预览 worker 最多有一个运行任务和一个最新待处理任务。普通反馈更新不反复取消运行任务，保证连续输入期间能持续完成画面；明确取消或替换候选时按版本停止所属计算，并拒绝旧输入再次入队。

关闭请求发出后，UI 不等待线程结束。worker 在安全检查点退出，释放自己的缓存、源图引用和队列；UI 保留原有会话、画布及版本校验，迟到结果不能修改新窗口。

## 观测与边界

诊断区分排队、合成、方向/颜色/重采样、反馈、UI 安装和 renderer 回调。renderer 回调返回不等于桌面合成器已经呈现；实际画面仍须原生截图核对。

源图、内容及反馈的字节统计用于说明所属 CPU 缓冲，图片历史继续按唯一资源身份执行 20 条/512MiB 预算。进程 PrivateBytes、工作集、GPU 资源和分配器空闲保留分别报告，不视作同一个预算。原有目标像素和缓冲限制不变，未把所有源图包装迁移为新的公共像素类型。

实现及实测范围见[专项验证记录](../releases/large-image-performance.md)。
