# Lexift 0.0.1-rc.9

本候选版本增加剪贴板历史和翻译流式输出，并继续完善 Popup 与标注工具的窗口交互。

## 更新内容

- 划词工具条新增独立剪贴板历史窗口，可记录、查看、复制、删除并粘贴近期纯文本；历史采用 Windows 用户级加密保存，并提供记录开关和数量上限。
- Ollama、LM Studio、DeepSeek 翻译服务新增按模型保存的流式传输选项，生成时逐步显示译文。
- 标注工具条支持收起和展开，收起时保留当前工具、标注内容和撤销历史。
- 剪贴板历史窗口支持固定、拖动与八方向调整尺寸；统一 Popup 和历史窗口的标题栏控件。
- 改进 Popup 圆角、语言菜单边缘、窗口缩放以及工具条按钮间距。

## 安装

下载 `Lexift-0.0.1-rc.9-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

这是候选版本。请通过 GitHub Issues 报告问题。
