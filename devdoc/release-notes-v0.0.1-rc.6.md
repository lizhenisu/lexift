# Lexift 0.0.1-rc.6

本候选版本新增序号标注，并继续改进标注工具的编辑与工具条交互。

## 更新内容

- 新增序号标注，支持数字、罗马数字、字母和中文编号，以及多种徽章外形、颜色和字号。
- 支持按下放置并拖动序号，编辑说明文字、调整文字样式，以及添加可弯曲的连接箭头。
- 按实际可见字形居中序号文字；说明文字插入光标在空内容时立即显示并规律闪烁。
- 修复修改说明颜色、字号、字体或描边后无法继续输入的问题，并保留光标位置和选区。
- 参数操作期间保持二级工具条展开；绘制完成的铅笔笔迹不可选中或修改。

## 安装

下载 `Lexift-0.0.1-rc.6-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
