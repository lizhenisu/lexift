# 复制按钮反馈

## 行为

- 剪贴板历史条目右侧依次为复制、删除。复制写入完整正文，不粘贴、不激活、不关闭历史窗口；剪贴板通知按既有去重规则将记录移到顶部，记录 ID 保持稳定。
- 翻译 Popup 原文、译文，以及四个 Provider 的凭证复制，成功后只在原按钮显示主题色 SVG 对号，1.5 秒后恢复。复制成功不再生成 Toast；失败保留错误反馈。划词工具条复制仍立即关闭。
- 反馈按窗口 / 会话、具体按钮或条目及请求编号隔离。同一复制操作等待期间不能重复提交；旧完成或超时回调不能更新新目标。历史复制等待期间暂时禁止行点击粘贴，避免两次剪贴板写入交错。
- 凭证仍使用敏感写入，尊重历史排除标记。普通历史复制使用既有剪贴板 Port，不新增配置或依赖。
- Popup 原文编辑草稿不会被复制反馈更新覆盖；编辑后的文本仍能完整复制。内容更换会隐藏旧成功状态。
- 历史列表保留同一展示模型并增量更新行；鼠标按下后若该位置已换成另一条记录，释放时不执行复制、删除或粘贴，避免重排误操作。
- 历史删除使用两次点击确认：首次将该行复制 / 删除区域替换为带 SVG 的红色“删除”按钮，再次点击才删除。一次仅确认一条；点击另一条删除会切换确认目标，复制或粘贴会清除确认。条目被移除或窗口销毁时清理状态，排序变化按条目 ID 保留，不按行号确认。
