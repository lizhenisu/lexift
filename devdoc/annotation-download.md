# 标注下载

## 行为

- 主工具条中心所在显示器的完整物理边界决定 PNG 尺寸，包含任务栏区域，不使用工作区裁剪。
- 点击时冻结标注文档、文字草稿、绘制预览及 DPI。取得点击后首次完整的新采集，再打开原生保存对话框。各底层窗口沿用现有独立采集，因此不承诺多个窗口在同一时钟瞬间的原子快照。
- 普通标注、水印、聚光灯、贴纸、马赛克、模糊、放大镜及擦除覆盖进入导出；工具窗口、控制点、选区、光标和反馈提示不进入导出。
- 保存与取消均不提交文字、不改变撤销历史，也不关闭标注会话。原编辑实例仍有效时恢复其输入焦点；切到其他应用时不主动激活编辑窗口。

## 所有权与边界

- Core 的 `AnnotationSavePort` 接收已经冻结的 premultiplied RGBA，返回保存／取消／失败；UI 在工作线程调用，App 注入 Windows 实现。
- 每次点击通过工厂建立独立 `ScreenCapturePort`。请求包含保存屏幕及效果所需的取样区，使用当前精确窗口排除集合和绘制层标记。不替换、清空实时效果的采集实例。
- 画布与工具窗口在原生登记时也设置现有私有采集排除标记；下载等待期间新打开的菜单因此仍被排除。标记随窗口销毁消失，不修改系统截图权限或其他应用的录屏行为。
- 采集等待最多五秒；本次实例的新完整帧即可完成，不要求像素版本增长。停止采集后复用软件效果处理与无交互装饰的合成路径，随后以 STA 原生文件对话框选择路径。
- WIC 在内存完成 PNG 编码，再写入同目录临时文件并原子替换目标。原生对话框负责覆盖确认；取消或失败不留下临时文件。
- 会话拥有结果轮询与取消标记。关闭后旧结果不能操作新会话；采集资源随独立实例退出，STA 对话框取消观察线程随 `Show` 返回退出，帧及字体／纹理线程缓存随导出线程结束释放。

## 验证记录

- 最终 workspace 测试：648 项通过、95 项忽略、无失败；UI／Platform／App 全目标 Clippy（`-D warnings`）、workspace 构建及 Windows Release 构建通过，UI 构建包含 Slint 编译检查。
- 自动像素回归覆盖擦除缺口、选中控制点排除、马赛克与模糊的新底图、后绘制标注、跨屏放大镜及“包含标注”开关。
- 草稿回归覆盖正文、插入位置、选区和冻结后继续输入，确认没有提交对象或产生撤销；另覆盖采集完整性、未变化版本、超时、取消及过期完成回调。
- Windows WIC 编码／解码回归检查尺寸与 RGBA 通道；文件回归检查中文路径、取消保留已有文件、替换、写入失败和临时文件清理。
- 原生取消回归实际打开 STA 保存对话框，设置取消后返回并释放观察线程。
- 原生窗口回归确认画布、工具条及嵌套菜单在首次显示前已有采集排除标记；普通窗口不受影响。现有 WGC 原生回归也确认普通底层窗口仍可采集，绘制层及显式排除窗口不会进入底图。
- 实际 Release App 在 125%／100% 双屏导出分别得到 2560×1440／1920×1080。保存对话框出现后将自有底层夹具由绿色改为蓝色，导出仍为绿色：抽样绿色像素分别为 520／534，工具条白色像素均为零，矩形标注像素均为 800。
- 两个 DPI 下均实际验证取消、重新下载，以及保存对话框打开时通过标注快捷键关闭会话；没有残留工具条或保存对话框。
- 实机截图：`target/annotation-download-toolbar-125.png`、`target/annotation-download-toolbar-100.png`；导出对照：`target/annotation-download-125-verified.png`、`target/annotation-download-100-verified.png`。自有夹具与 App 已关闭，生成文件保留在忽略目录。
- 负坐标由自动化覆盖；中文 IME 在原生保存对话框往返时的组字行为、实机所有效果组合及故障采集尚未单独实测。
