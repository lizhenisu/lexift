# 贴图 OCR 与长图分块验证

日期：2026-10-21。分支 `codex/pin-image-ocr`，基于本地 `main` 的 `6486e4c`。实现及验证阶段未提交；2026-10-22 按用户授权提交功能分支并快进合入本地 `main`，未推送。

## 实现

- 贴图右键“识别文字”，普通贴图和贴图编辑共用确认底图及裁剪范围；不从显示窗口或新增标注合成图取样。Core 保存贴图、操作号、文档版本和结果类别，不保存正文。
- 同一贴图去重，另一贴图替换旧请求。App 仅运行一个贴图 OCR 调度任务，保留最新待处理描述和共享底图引用；返回后再处理新请求。识别、资源检查、语言策略、推理空闲释放及剪贴板串行门与截图 OCR 共用。
- 识别暂停文档编辑、历史、裁剪及图片输出，保留移动、缩放、阴影、置顶和关闭；不改变编辑工具或历史。原生移动采用实际结束通知，不能将投递系统拖动消息的返回误认为拖动结束。取消和完成在原生拖动结束后恢复绘制输入。
- 结果使用三秒被动 toast，隐藏准备、跨 DPI 测量稳定后显示，鼠标穿透、不激活；按窗口及通知版本回收。文案复用全部十二种语言。
- 高于 960px 且高大于宽的图片逐块检测：块高最多 960px，重叠 192px，末块覆盖尾部。检测框映射到原图，按空间位置合并，识别裁片来自原分辨率。不同位置的相同文字保留；接缝不完整框先用完整重叠框替代，再补检一次，仍未解决时整次失败。
- 保留 4000 万像素输入限制，块逐次释放，不缓存所有块像素。普通图片仍使用原检测路径；未新增 Port、依赖、crate、配置或模型。

### 耗时与内存口径

App 的 `Pinned image OCR finished` 从开始处理至完成／取消返回计时，包含裁切、资源检查、推理和剪贴板串行写入，不包含脚本等待。首个普通贴图为 **303ms**，驻留普通／标注后为 **127～171ms**，裁剪后 **109ms**；31 行长图成功为 **743～802ms**。56 行跨 DPI 夹具首个请求 **1449ms**，外部输入夹具为 **1857ms**。这是本轮少量功能实测，不能当作 P95 或与修改前版本的速度比较。

基础检测块数：400px 普通图 1；2000px 长图 3；3600px 长图 5；4400px 英文模型夹具 6；2400px 混排模型夹具 3。不包含未单独记录的接缝补检次数。按原分辨率分块增加检测调用次数，以避免长图整体降采样；本轮没有同口径旧路径性能基线，不声称推理总耗时下降。

多实例脚本记录到整个进程峰值工作集约 **483.26MiB**，采样的进程 PrivateBytes 最高 **558.44MiB**，包含窗口、冻结屏幕、模型和其他运行时，不能当作 OCR 专属缓冲或与长截图 512MiB 专属预算直接比较。尚未进行独立分配器峰值分析。取消请求从开始到后台返回的记录分别为 444／454ms（Escape）、494ms（被替换）、156ms（关闭）；没有单独打取消时刻，不能将这些数字冒充取消响应延迟。

证据位于忽略目录 `target/pin-image-ocr/`：已知文字图、原生脚本、剪贴板对照、窗口截图、进程身份、构建和测试日志。`preflight-evidence/` 单独保留预检证据。

## 验证边界

- 贴图编辑的鼠标模式继续沿用已有穿透策略；原生菜单验证在选择标注工具后进行，裁剪应用后亦如此。识别期间临时浏览输入可直接移动和缩放，不改变工具。
- 模型资源缺失、损坏、待移除与系统剪贴板故障未通过破坏本机资源或系统状态作原生故障注入；领域与共用后台路径的测试不能表述为原生故障实测。
- 全部语言复用文案已检查，现有 UI 全量回归包含语言与主题组件检查；未逐一在真实桌面展开十二种语言的菜单。
- 韩文长图、大于夹具尺寸的复杂排版、竖排、多栏与低清晰度照片未作本轮准确率承诺；真实模型夹具通过不代表任意内容必然无漏识。
- 截图 OCR、独立 OCR 翻译入口的回归为本轮自动化结果，未重新运行真实外部翻译服务；未穷尽每种绘图工具与原生对话框交错。
- 运行时不持久化 OCR 图片或正文。验证脚本覆盖系统剪贴板为已知夹具文本，未读取或清理个人历史；脚本创建的进程与窗口已结束，截图和对照仅存忽略目录。
