# 录屏预览同步与资源收尾专项

## 结论与构建

基线 `main c0810fb`；实施分支 `codex/recording-preview-validation`。软件播放同步、所属资源退役及最终界面链路通过；真实声学／屏幕光子同步为环境未覆盖。本轮没有修改播放时钟、音量、视频编码参数或波形，没有用固定延迟补偿同步。

证据均在忽略的 `target/recording-preview-validation/`，包括失败、对照、脚本和逐轮原始数据，不纳入源码提交。

## 软件同步测量

独立路径直接使用 WASAPI 渲染时钟和已知脉冲取得测量时标参考，在播放组前后各测一次。实际视频事件来自交换链呈现缓冲与提交时间，不以进度条或解码纹理作为呈现证据。使用整个前后参考区间计算不确定性，不根据播放器误差反推补偿。

| --- | --- | --- |
| 两屏、30／60fps、共 20 次短测 | 参考校正后最大偏差上界 31.8335ms，通过 | `sync-matrix.json`、各组独立校准与原始报告 |
| 十分钟实际播放 | 35937 个活动呈现帧、299 次闪光与脉冲，59.895fps | `long-sync/playback-sync.json` |

| 十分钟源文件独立流式解码 | 35938 视频帧、28749792 音频样本；两声道各 299 脉冲，源音画最大偏差 0.032ms | `independent-long-reference.json` |

原始回环 50ms 断言仍然失败：十分钟最大原始差值 138.6874ms，短测原始失败报告也保留，未改为通过。十分钟前参考区间为 122.3529～122.9760ms，后参考为 112.0078～112.7927ms；校正仅用于测量报告，没有进入产品播放路径。原始值、参考值和不确定性不得混为一个结果。

十分钟源片包含 AAC 拼接时间差，不能假定固定 300 个事件或正好 36000 帧；独立检查覆盖全程并按实际 PTS 对照。检查器的错误计数、倒序区间、非单调时间、低帧率及无效参考负夹具均被检出，见 `assessor-negative-checks.json`。

无音轨首帧暂停、播放、定位和释放通过 `no-audio-native.log`。十分钟片中段／尾部的实际交换链编号为 2855／1706，独立 FFmpeg 邻帧解码包含对应编号，时间容差明确为 40ms，见 `seek-long-independent.json`，没有将请求时间当作目标已呈现。

真实扬声器／麦克风声学延迟及屏幕光子输出没有独立外部仪器，标为**环境未覆盖**；软件参考结果不证明这两项物理指标。

## 句柄归因

使用独立进程分离播放器、录制及完整界面，包含预热、连续至少二十轮和两分钟空闲采样。类型 56 经系统类型表确认是 `EtwRegistration`；句柄追踪在本机返回空用户栈，不能以空栈证明释放。

| 对照 | 观测 | 判定 |
| --- | --- | --- |
| 仅播放器 21 轮 | 约 524，空闲后 521 | 无持续增长 |
| Release 播放器＋表面 21 轮 | 约 537，空闲后 523；私有副本可删除、子窗口消失 | 所属资源退役通过 |
| 仅录制 21 轮 | 总句柄 455→495，空闲后 481；ALPC 13→51→41 | 与播放器分离 |
| 仅 WGC 41 轮，两段各 20 轮及空闲 | File 固定 15；两段 ALPC 峰值均 30、空闲均 26 | 采集代理延迟缓存稳定，无逐轮线性增长 |
| 旧正式保存 22 轮 | File 约 81→159，空闲仍 145 | 实际持续保留，继续定位 |
| 不打开保存框的完整界面 22 轮 | 延长空闲后总句柄约 744，File 固定 47，ALPC 106→18→11 | 播放／录制不是目录引用增长来源 |

独立最小 Rust 原生夹具只调用 Windows `IFileSaveDialog`，不加载 Lexift 录制或播放，仍复现 File／Event 持续增长。复用同一 STA、排空消息及 `CoFreeUnusedLibrariesEx` 都未消除。83 个目录引用表现为两组重复对象（42／41）；对话框最终 `IUnknown::Release` 返回 0，指向 Shell 的进程级保留，而非未释放的对话框 COM 引用。证据为 `shell-only-*`、`shell-same-sta-*`、`shell-pump-*`、`shell-trim-*`、`shell-file-identities.json` 和 `shell-refcount.log`。未将目录路径写入报告，也未把试验性的 DLL 修剪或 STA 缓存应用到产品。

## 修复

1. Media Engine 创建成功即建立 `Shutdown` 所有权，再执行可能失败的配置和加载。初始化部分失败也执行所属退役。
2. 播放器原生登记按所属 `Weak` 实例删除；旧线程不能删除同一 HWND 的新登记，线程创建失败会撤销登记。
3. MP4 保存路径选择使用同一可执行文件的短生命周期内部角色。子进程只初始化 STA 原生对话框，不初始化配置、日志、单实例、托盘、快捷键或 UI 运行时。父进程继续持有封尾文件并执行既有原子发布，不传视频、不重新编码。
4. 私有继承管道采用有界请求和长度前缀响应；路径不在命令行、Core、UI 或日志中。父窗口 PID 和属性代号校验防止旧 HWND 复用；异常退出只恢复所属仍有效的禁用状态，不激活窗口。
5. 持有确切子进程句柄直至退出。取消时关闭所属对话框，尚未显示时直接退役以避免迟到弹窗；挂起的已显示对话框有两秒失败收尾上限。这是故障截止时间，不是显示等待、轮询激活或隐藏窗口缓存。

最终默认保存 22 轮中，File 在预热后为 58，末轮仍为 58，空闲后 51；混合模式 20 轮空闲后同为 51。默认组总句柄 810→894→819，ALPC 23→102→50，说明系统代理仍会延迟退役，不能宣称进程总句柄回到冷启动。默认组 PrivateBytes 约 192.6→198.4→38.7MiB；工作集另计，未调用工作集修剪证明释放。见 `delivery-default/handles.json`、`validated-delivery/handles.json`。隔离版另一独立进程 22 轮也验证 File 约 55 稳定、空闲后 48。

每轮播放器、视频表面、源帧及采集所属计数回到预期，成品私有副本可删除；最终正式窗口枚举包含隐藏窗口，未残留预览父窗口或视频子窗口，线程审计无所属播放／音频线程。运行时保留的录制服务和共享平台线程不作为会话泄漏。

## 最终 Release 正式链路

- `validated-delivery/result.json`：两屏各十轮混合场景，覆盖 30／60fps、两档画质和四种声音；播放／暂停、前后定位、末尾重播、静音、保存取消重试及丢弃通过。
- `delivery-default/result.json`：两屏各十一轮默认档（各一次预热＋十次测量）通过。所有保存均检查父进程成品与保存文件 SHA256 相同，关闭后所属临时成品消失。
- `delivery-decode-checks.json`：35 个正式输出 MP4 独立完整解码通过，物理尺寸、视频格式及音轨逐文件记录；两屏实时标注／文字末帧的 60fps 双声源输出中，实际最后一帧保留文字，控制条位置取样为 [32,52,77]，与夹具底色相符。
- `delivery-live-125/`、`delivery-live-100/`：倒计时取消保留位置、真实下层点击／拖动／滚轮、控制条移动、暂停标注、效果、末帧文字及保存取消重试通过。
- `delivery-focus/checks.json`：每屏两轮，在封尾阶段真实点击另一个显示器的独立原生窗口，自动预览未夺回前台；未使用强制激活。
- `delivery-extras/extras.json`：标题拖动、窗口缩放、跨 DPI 子窗口几何、键盘定位及居中丢弃确认通过。
- `delivery-region/checks.json`：录制保存前后实际截图复制均为 480×240 且像素一致，R 区域保持。
- `delivery-faults/checks.json`：故意终止经父子身份核对的保存辅助进程，所属预览恢复输入，成品不变；下一次真实取消保留成品，再次保存 SHA256 一致，没有残留子进程。
- `delivery-exit-fault/checks.json`：辅助进程显示前被原生测试挂起，再真实托盘退出；子进程和主进程退出，成品清理，无迟到弹窗。该项明确属于注入故障。
- `validated-delivery/protocol-checks.json`：非法 JSON、超大请求、错误协议版本和外部窗口身份被拒绝。

布局未改变，复用本轮 UI 渲染的十二语言、浅深主题、100%／125% 回归。外部声学／光子仪器、HDR、物理设备拔除未覆盖；没有破坏系统编解码器或音频服务来制造异常。

## 性能与检查

静态机器上、没有并行编译及性能测试干扰的默认档对照，每屏各一次预热和十次测量，最近秩 P95。`delivery-performance.json` 保存完整中位数、P95 及原始来源。

| 屏幕 | 首帧提交 P95 基线→最终 | 停止至封尾 P95 | 封尾至 UI 首帧呈现 P95 |
| --- | --- | --- | --- |
| 125% | 163.47→162.70ms | 152.24→109.71ms | 188.83→138.86ms |
| 100% | 161.83→162.39ms | 133.81→107.75ms | 142.40→143.50ms |

均未恶化超过 10%，首帧与定位未超过一秒。附加真实输入二十次（同一播放路径、保存隔离前的构建）播放响应 P95 317.60ms，定位响应 P95 29.16ms，保留于 `supplementary/input-latency.json`；没有把提交时间当作完整呈现。

Core 320、App 相关回归 16、UI 录屏／渲染回归 11、Platform 232 通过；125 个需原生环境或其他专题的 ignored 测试不冒充全跑通过。所需原生驱动单独运行并逐项记录；原始时标阈值失败仍保留。格式、严格全 workspace all-targets Clippy、Slint 编译及 Windows Release 构建通过。

夹具失败另行保留：旧脚本使用 `PostMessage` 移动源窗口，随后同步查询并不能排空旧消息，导致源窗口迟到置顶遮挡预览；改为同步移动和实际 HWND 命中确认。前台销毁短暂返回空 HWND、首次文字字体尚未准备、以倒数 80ms 代替真正最后视频帧、用固定亮红阈值忽略小字号抗锯齿，均修正检查口径而不修改产品呈现。保留首轮失败及修正脚本，不将重试覆盖为首轮通过。

最终测试已通过真实托盘退出；受控声音和图像源收到停止信号，测试移动的窗口按 HWND 与当前几何校验还原。环境清理见 `environment-restored.json`。本轮无新增业务入口、可见文案、配置、依赖、crate 或 Core Port，未暂存、提交或合并。
