# 截图选区比例锁定验证

日期：2026-10-17。提交前基线为 `551487d`（手动尺寸与可拖动紧凑面板）；本次比例锁定修改未暂存、提交或推送。

## 实现与验收口径

- 尺寸面板增加紧凑的“锁定比例”开关，基础尺寸由 288×136 调整为 288×166 个逻辑像素；保留原有标题栏拖动、跨 DPI 处理及辅助窗口身份。开关使用既有 SettingsSwitch 的紧凑变体，默认尺寸与其他使用处不变。
- 面板的宽高、开关及比例均为草稿。开启锁定捕获当前有效宽高，用户编辑任一字段联动另一项；程序联动不产生新的用户编辑。应用原子提交，取消不提交；空值和非法值不可应用，超大整数安全处理。
- Core 保存约分的正整数比例，鼠标、键盘及数值输入共用整数换算与联合边界限制。派生尺寸四舍五入，最小 1×1；整数无法精确表示比例时保留原比例源。反复调整不从取整结果重建比例。
- 右／下固定左上角，左固定右上角，上固定左下角，四角固定对角；键盘和面板固定左上角。移动不改变尺寸，取消只恢复几何，保留已提交约束。
- 每次截图默认关闭，不跨截图持久化，不影响首次框选、普通标注、贴图或 OCR。对象、样式和标注撤销历史不变；同帧预览及清洁输出链路不变。

### 最终原生结果

使用最终同一哈希程序，在 100%（1920×1080，原点 2560,0）和 125%（2560×1440，原点 0,0）双屏上完成 31 个实际输出用例：

| 场景 | 实际输出与检查 |
| --- | --- |
| 锁定后输入宽度 640 | 两屏均为 640×480 |
| 锁定后输入高度 300 | 两屏均为 400×300 |
| Ctrl＋右 1px | 两屏均为 321×241，左上角不变 |
| Ctrl＋Shift＋下 10px | 两屏均为 333×250，左上角不变 |
| 八个控制点 | 两屏各 8 个用例均为 360×270；截图中的边界及输出采样位置核对已确认锚点 |
