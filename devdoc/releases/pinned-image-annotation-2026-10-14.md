# 贴图可编辑标注验证（2026-10-14）

## 实现范围

- 右键菜单新增“标注”和可勾选的“隐藏标注”，同步 12 种语言。
- 每张贴图分别拥有裁切底图、可编辑文档和撤销历史。截图前的桌面标注保持底图像素；截图内新增标注可继续编辑。
- 截图与贴图共用冻结图像编辑、预览、工具及参数流程。贴图编辑借用其现有窗口，不创建额外画布；正文与控制点分别呈现，控制点不进入图片输出。
- 完成或无内部编辑时的 Escape 保留修改，恢复原屏幕标注为“选择对象”；原标注关闭时不额外打开。隐藏仅改变可见性，复制和保存冻结请求时的文档及隐藏状态，输出后继续编辑。
- 原图物理坐标、源 DPI 和撤销历史不随贴图移动、缩放改变。底图以外的效果采样仅保留合成所需小区域，不保留完整多屏冻结帧。

## Windows 实机

### 原生诊断运行

实际 App 的忽略诊断测试通过，耗时 36.65 秒，日志 `target/pin-edit-native-final.log`。使用真实原生鼠标／菜单输入完成：截图内矩形、聚光灯及马赛克 → 第一张贴图 → 屏幕其他区域绘制 → 第二张贴图 → 先移动新贴图，再移动旧贴图 → 编辑旧贴图、增加对象、撤销 → 隐藏／恢复 → 重开并撤销原有对象 → 关闭两张贴图。核对被关闭的 HWND 已销毁。该诊断使用 Debug 构建，不替代以下 Release 检查。

### Release 桌面检查

从项目 `target/release/lexift.exe` 启动，分别在 96 DPI（100%）和 120 DPI（125%）显示器操作截图、绘制、贴图、右键标注、继续绘制、完成及关闭。编辑期间窗口枚举只包含目标贴图及一套工具条，结束恢复原标注，最后关闭所有临时测试贴图与标注窗口，保留后台托盘。

证据均在忽略目录 `target/pin-edit/`：

- `release-editor-96.png`、`release-editor-120.png`：桌面合成截图，包含贴图、控制点和编辑工具条。
- `release-shown-96.png`、`release-hidden-96.png`、`release-restored-96.png`：隐藏前、隐藏及恢复；相同背景下隐藏前与恢复后逐像素一致，隐藏时标注消失。
- `release-undo-96.png`：重开编辑并撤销后，新画对象消失，原截图对象仍在。
- `release-check.ps1`：本轮真实输入与桌面截图辅助脚本。
