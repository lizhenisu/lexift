# Windows 异形截图贴图验证

基线为 `a12c1a9`。范围包括多窗口、多边形、选区加减和自由手绘截图。

- 复制、保存及贴图共享同一遮罩合成，输出采用有效像素的外接矩形。
- 截图保持忙碌直至普通贴图首次呈现。准备失败或首次呈现前关闭时，截图保留确认选区。
- 透明孔洞的显示使用最小非零 Alpha，以便 Windows 在整个图片矩形内投递输入。可编辑底图及复制、保存、历史中的透明像素仍为零 RGBA。
- 普通贴图沿用截图来源及确认文档。只有成功结果才进入图片历史，且不修改 `R`。
- 原生脚本、截图、剪贴板解码结果、PNG 和构建哈希记录在 `target/screenshot-masked-pin/`。

## 自动化

运行 Core、App、Platform 和 UI 测试，合计 1238 项通过。覆盖遮罩合成、普通贴图、截图输出与图片历史；新增测试确认首次贴图在截图完成前继承原截图来源。严格 Clippy、格式检查及 Windows Release 构建通过。

## Windows 原生

以合成窗口为输入，在 100% 和 125% 屏验证四种入口。脚本先取消异形截图的 PNG 对话框，再点击贴图，检查截图交接。贴图透明孔洞命中原生窗口并能打开右键菜单。自由手绘另测孔洞拖动及跨屏轨迹。实际剪贴板 DIBV5 与贴图再次保存的 PNG 解码后逐像素相同；几何夹具核对了轮廓内颜色和透明区。自由手绘的指针采样允许斜边附近出现最多两像素的轨迹差异。

专项未覆盖首帧前原生窗口被强制销毁、四种贴图逐一进入编辑后标注及 OCR、窗口失败注入，以及十二种语言与浅深主题下每种异形控制条的原生布局。相关既有组件布局由 UI 回归覆盖。
