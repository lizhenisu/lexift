# 独立截图快捷键验证

基线 main `4c04df2`，实施分支 `codex/screenshot-hotkey`，本轮未暂存、提交、合并或推送。证据放入 Git 忽略的 `target/screenshot-hotkey/`。

## 实现

- Schema 11 增加 Alt+S；四组键互斥，Windows 注册先新后旧，实际注册结果用于指南。
- Core 先接纳快捷键输入并冻结其前台／鼠标上下文，再通过请求号取得 UI 快照；新增来源区分无工具条和原桌面标注。取消、失败、退出及过期快照不会创建或恢复无关窗口。
- 原有快照和挂起恢复支持工具条为空；显示器 DPI 由 Platform 提供原生桥接。设置录制优先接收全局组合。
- 新增字段使原运行配置命令跨过既有枚举体积检查阈值，因此把该命令的配置快照改为 Box；只迁移所属构造和消费点，没有改变事务顺序。

## 验证中发现并修复

1. 原生贴图收到按下、尚未执行排队的移动请求时，松手会清掉 pending move，却漏发 `NativeMoveFinished`，使 UI 拖动门禁一直未释放。`pending-move-red2.log` 保留失败回归；修复后过期 begin 消息和重复松手只报告一次结束。UI 用共享手势 Cell 即时标记原生移动结束，Registry 收尾仍回到事件循环。
2. 桌面标注画布拥有焦点时，挂起销毁原窗口导致前台改变，首次框选曾显示但无法直接使用键盘。`annotation-native.log` 保留实机失败；截图收尾／挂起现在仅迁移所属文档窗口同步退役的身份，拒绝外部前台和过期会话。文字输入窗口及工具条同样遵循此规则。
3. 系统占用 Alt+S 后，Settings 重新录入同一个配置曾因“无变化”被跳过，无法重试注册。`conflict-native.log` 保留失败；现在配置相同但实际未注册时重新进入现有保存／注册流程，已经注册时仍不重复请求。
4. 同一快捷键冻结请求若所属工具条会话已失效，会释放自己的 pending 标记；旧请求不能清除新请求。

## 原生验证方法

- 单独启动 Release，用真实 Alt+S、鼠标和键盘操作。两屏物理范围为 `(0,0)-(2560,1440)`（125%）及 `(2560,0)-(4480,1080)`（100%）。没有脚本强制激活截图画布。
- 用 RGB `(37,113,181)` 夹具，框选 320×240px。实际剪贴板和 PNG 全像素对照；C 结果为 `#2571B5`。R 后创建贴图、点击聚焦贴图、再次截图／R／取消，检查原贴图恢复。
- 原生 `WinEvent` 记录核对框选前没有工具条创建／显示闪现。真实首帧就绪以两屏完整反馈呈现与所属前台共同判断，不能只等待 HWND 出现。观察延迟包含脚本输入及轮询开销，是上界，不是精确渲染耗时或 P95。
- 原生移动循环可能在松手消息之后才完成。脚本等待 `GetGUIThreadInfo` 的 Move／Capture 清空及物理按键释放后再发下一请求；不重发失败快捷键，也不以额外点击补救焦点。
- Settings 用真实录制从 Alt+S 改为 Ctrl+F9，检查旧键失效、新键截图；将 OCR 尝试改为截图键，核对冲突拒绝并保留原设置；最后恢复 Alt+S。测试不输出个人配置、凭证或内容。
- 系统占用由测试所属 `RegisterHotKey` 夹具提供，启动后检查截图键不可用而 Alt+A 可用；释放占用后在设置重试。

## 测试脚本边界与失败记录

`native-final.log`、`native-final2.log` 在双屏图片流程通过后，因测试错误地要求 Settings 使用辅助窗口身份而失败。Settings 按仓库规则允许进入任务栏，已修正测试，不修改产品身份。早期设置导航点落在“常规”，已依据实机截图改用实际热键导航范围。

`settings-native3.log` 错误要求重新保存未变化的默认值；普通无变化不写配置是正确行为。`settings-native4.log` 尝试录制既有全局 OCR 键，启动了原有 OCR 流程；后续改用已接入录制桥接的截图键验证反向冲突，原 OCR 快捷键录制行为不在本轮扩展范围。不得把这些脚本失败当作最终通过证据。

## 未覆盖范围

- 实机默认中文／浅色；十二语言、深色、窄窗和两种 DPI 由组件矩阵验证，不宣称全部语言逐一原生操作。
- 保存失败及注册替换失败回退、会话乱序／退出注销以自动化和测试 Port 验证；没有破坏真实配置目录或系统权限制造保存失败。
- 本次真实输出覆盖复制、PNG 与贴图；未重复进行 JPEG、长截图、OCR 正文识别或全部原有编辑功能的完整原生验收，业务忙碌拒绝由相应领域／UI 回归覆盖。
- 原标注原生恢复使用矩形；文字事务收尾及输入窗口退役走同一所属身份保护并有现有文字回归，未另做完整中文输入法专项。
- 未实测非 Windows 系统；未支持的截图快捷键注册返回不可用。
