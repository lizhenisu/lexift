## 旋转／翻转补验与修复（2026-10-24）

上节是原功能实施时的记录，原功能随后合入 main。补验分支为 `codex/image-transform-validation`，基于 main 的 `39b56bd`；本轮未暂存、提交、合并或推送。保留上文的原始验收边界；下面记录补验发现的问题及修复，不将早期基础验证追认为完整验收。

### 修复内容

- 文字关联箭头使用对象局部坐标命中。新建文字在非默认图片方向下保留点击的字形起点，输入和重新排版不再围绕变化的包围盒中心漂移。
- 原生文字输入按字形局部方向、文字独立旋转及整体图片变换投影四角，最后在屏幕空间裁切。已定向的图片可见范围不再次应用整体方向，修复旋转后输入窗口被压到图片边缘的问题。序号标题使用所属序号的局部中心。
- 贴纸仅变换纹理，不旋转区域或笔刷轨迹；文字、序号仍使用字形局部变换。旋转控制等操作图标保持正向。
- 贴图输入直接读取与已呈现像素对应的方向和几何快照，不依赖能否借用 Registry。裁剪／方向历史的候选画面成功后同步安装这些数据。
- 图片方向候选同时校验编辑器、画布、会话和呈现版本。迟到失败不能解除新任务的忙碌状态；旧画布的完成通知不能提交新编辑器的历史。
- 补验贴图混合历史时发现鼠标模式把绘制关闭与原生鼠标穿透绑定，导致编辑中无法打开右键菜单。现在单独保留菜单输入；截图挂起和裁剪仍按各自规则屏蔽，未修改普通贴图拖动和输出规则。

### 原生验证口径

双屏物理布局为主屏 2560×1440／125%、副屏 1920×1080／100%。窗口跨屏通过真实标题拖动，输入发到实际命中的 HWND，不强制激活编辑器补救。

- 导入来源：侧置底图旋转后 OCR；新建文字、中文输入法组合与提交；保存、生成贴图。
- 贴图链路：保留可编辑资源后裁剪、依次撤销裁剪／文字／整体方向，复制 180×600 结果；重做后恢复 600×180 成品；OCR 排除新增标注；隐藏／显示标注并核对实际复制像素。
- 历史来源：从同源记录恢复，直接 OCR、保存，与成功成品逐像素一致。导出的含标注 PNG 再导入后，真实 OCR 可读出新增英文文字，核实字形方向。
- 序号／贴纸：旋转后新建序号及标题，创建区域贴纸与笔刷；再整体翻转，PNG 与独立 Pillow 参考变换逐像素比较。
- 长图来源：实际滚动采集镜像行号夹具，进入编辑后翻转，OCR 检查连续 12 行各出现一次，复制尺寸为 600×1200。

原生脚本以实际可见的工具选中反馈和目标窗口命中为准备条件。早期脚本在选中反馈尚未显示时发出绘制点击，及把零高度区域当作贴纸绘制，均未计为通过；修正脚本后须重新核对实际成品，不能仅凭脚本执行到末尾判断成功。

证据放在忽略的 `target/transform-validation/`：文件／历史／贴图链路 `file-native.ps1`、序号贴纸 `glyph-native.ps1`、中文输入法 `ime-native.ps1`、真实长截图 `long-native.ps1`、独立像素对照 `verify.py`，及各自截图、PNG、剪贴板对照和构建哈希。最终 Release 的执行结果在下面单独追加。

### 验收边界

本轮发现的实际功能问题均已修复，并完成上述代表性 Windows Release 链路；不再以“额外点击后键盘可用”或“窗口可见”代替输入和成品验收。原生脚本不强制激活编辑器来补救焦点。

八方向、负原点、局部文字旋转、箭头命中、候选失败／取消／迟到通知及重建隔离由自动化覆盖；实机为当前两块非负坐标显示器、右转及水平翻转的代表组合，未穷举每种方向、字体、工具与第三方应用的全部组合。原生权限拒绝、GPU／内存故障注入、其他输入法和非 Windows 平台未实测；现有忽略测试仍保留原忽略原因，没有计入通过。没有测量本轮每个动作到桌面呈现的延迟分布，不将脚本中的准备等待或整段耗时作为性能收益。
