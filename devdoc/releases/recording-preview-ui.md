# 录屏预览界面优化验证

基线为 `main 25a088e`，实施分支为 `codex/recording-preview-ui`。操作见[录屏预览使用说明](../features/screenshot-mode.md#完成后的预览与回放)。

## 自动化与布局

- UI 与 App 共 649 项回归通过。组件交互测试覆盖一帧范围、播放头和两个把手的独立命中、拖动取消、逐帧调整、选项的鼠标和键盘操作、关闭后焦点恢复及忙碌屏蔽。
- 渲染 12 种语言、浅深主题、100%／125% DPI、640×360 与 960×760 两种窗口尺寸，以及就绪、播放、失败、两种导出进度、画面裁剪、倍速和成品声音八种状态，共 768 张布局证据。检查最小窗口选项展开时视频仍有 80 个逻辑像素高度。
- 格式检查、Slint 编译、严格 Clippy 和 Windows Release 构建通过。Slint 保留原有截图尺寸输入的可访问名称重复警告。

## Windows Release

| 实测 | 解码结果 |
| --- | --- |
| 125% 屏，30fps 含系统声录制，播放与定位、两种裁剪、1.5×、50% 成品声音、取消另存后重试 | MP4 1230×840，30fps，28 帧，0.9333 秒，双声道 AAC。独立解码的首尾帧编号为 358／550，与保留源片段一致。 |

| 从 100% 屏拖到 125% 屏并缩放 | 原生视频子窗口与预期视口吻合，关闭确认取消后仍可使用同一预览，随后确认丢弃成功。 |

初次原生运行的 UI Automation 仅公开视频窗格，改用有窗口命中校验的真实鼠标输入。快速注入标题拖动未完成原生交接，补测在鼠标仍按下时等待应用确认拖动开始，再完成跨屏拖动和缩放。初次脚本日志一并保留。

预览窗口的捕获排除属性为 17，桌面抓图只显示其下方内容。视觉对照使用旧版组件截图与新版 Slint 软件渲染。视频呈现边界与成品像素以原生子窗口几何及独立解码核对。实机语言为简体中文，其余语言及主题由组件渲染覆盖。
