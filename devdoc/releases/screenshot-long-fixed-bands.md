# 长截图固定页眉和页脚验证

Windows 单屏长截图在首次确认向下位移时识别稳定的整宽固定栏。Core 先寻找同坐标 RGBA 完全相同的边缘行，再用正文的原分辨率重叠验证位移。栏高至少 4 个物理像素，单侧至多占四分之一，两侧合计至多占三分之一。正文至少重叠 16 行且达到正文高度的四分之一。纯色边缘、歧义边界、反向及不足的重叠无法建立固定栏匹配。

确认后预览和导出共用行序。首帧页眉在顶部，后续只追加正文新行，最近有效帧的页脚在末尾。固定栏像素变化时保留上次确认结果，自动滚动沿用既有停止流程。首帧直接完成仍得到完整原始选区。

Core 回归覆盖仅页眉、仅页脚、两栏并存、无栏、首帧完成、1px 步长、重叠下限、预览裁剪、歧义边界、纯色、重复纹理、伸缩变色、浮层、反向、取消和缓冲上限。原生脚本、参考图、复制成品及运行日志保存在忽略的 `target/long-fixed-bands/`。

## 双屏 Chrome 原生验证

以下场景在 100% 和 125% 屏各执行一次。通过实际截图热键和控制条完成，输出与独立参考图逐像素比较。日志、滚轮目标和偏移、首屏、参考图及实际剪贴板图片保存在 `chrome-r1/`，像素哈希与停止原因见 `results.json`。

| 场景 | 两屏结果 |
| --- | --- |
| 固定导航和底栏，自动滚动 | 600×2045，与完整参考图一致。两栏各出现一次，末尾由画面未变化停止。 |
| 内嵌列表固定表头，手动滚动 | 600×2025，与完整参考图一致。表头出现一次。 |
| 第三档滚轮改变导航栏颜色 | 自动滚动因重叠不可靠停止，保留前两档确认的正文。600×600，与参考前缀一致。 |

Chrome 使用独立测试进程和本机夹具页面。夹具逐行显示可区分的编号和像素，原生输入记录全部命中选中区域。参考对照还确认控制条、范围遮罩及预览未进入复制图片。
