# 贴图旋转／翻转验证

日期：2026-10-25。基线 `main/7f6f753`，分支 `codex/pin-image-transform`。本轮不暂存、提交、合并或推送。

## 实现与边界

- 右键子菜单复用四种方向文案，新增子菜单名称同步十二语言；没有新增按钮、快捷键、依赖或 Port。
- Core 冻结候选文档，成功准备并由所属窗口确认后提交共享历史；原图坐标、完整底图、裁剪、标注显隐及效果采样继续保留。锁定检查包含翻转、正方形旋转和方向历史。
- UI 保留分数内容中心与物理缩放，方向、像素、窗口和输入映射统一提交；工作区限制只缩小和夹紧。裁剪仍固定左上角。中心缓存同时绑定已呈现源范围和实际几何，移动、缩放及裁剪后重新取基准。
- 候选失败、窗口关闭、开始截图或替换会话不提交历史，过期结果不恢复旧状态；后台缺少底图时明确完成失败，不留永久忙碌。

## 自动化

Core 覆盖四种动作与八种方向组合、渲染确认前不提交、去重、多实例、锁定及业务冲突、失败、取消和旧结果；UI 覆盖分数中心、奇偶尺寸反复转动、负坐标工作区、上下限，以及候选无效像素／迟到结果／原生几何失败时不提交。候选保留旧画面引用直到 Core 确认，确认前取消会回退几何和文档；失败版本后到达的成功帧不会重新安装。

相关回归共 1045 项通过：Core 247、UI 507、App 76、Platform 215；另有 111 项既有忽略项，未计为通过。完整 UI 回归后又专项检查确认竞争，App 回归包含按贴图版本取消预览任务。日志 `tests-final.log`、`ui-final.log`、`app-final.log`、`ui-ack-final.log`；严格 Clippy、格式、Slint 编译通过。

复核发现原 `publish` 使用不含撤销栈的输出快照作为 Core 文档，编辑中下一次方向操作会丢失之前的历史。已改为通过既有 `freeze_visible` 保留共享历史，并在安装方向后重新同步工具编辑域、参数和光标。首次创建也将 UI 保留的可编辑基线交给 Core，统一初始编辑会话编号；从历史创建时仍按原规则清空旧撤销栈。新增组件回归同时验证这两个基线，专项实测增加编辑中旋转后的连续两步撤销及两步重做。
