- Core 截图回归 50 项通过，覆盖奇偶填充、重复包围抵消、采样合并及回折、短轨迹、采样上限、无效重画、保存取消和旧结果隔离。工作区库回归、格式、Slint 编译、严格 Clippy 和 Windows Release 构建通过。
