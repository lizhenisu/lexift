# Windows 异形截图复制验证

基线为 1d988d7。构建哈希、脚本和证据位于 target/screenshot-masked-copy/。

- Core、App、UI、Platform 工作区库测试、严格 Clippy、格式、Slint 编译及 Windows Release 构建通过。Core 回归覆盖复制与保存竞争、失败重试、旧结果、图片历史及 R。
- 最终 Release 在 100% 屏和跨屏选区验证 Ctrl+C，在 125% 屏验证复制按钮。均先取消原生保存对话框，再直接复制。独立解码 CF_DIBV5，检查头、四通道掩码、行序、尺寸和 Alpha。单屏保留像素与冻结参考每通道差不超过 1，透明区域 RGBA 全零。
- 独立进程以测试窗口 HWND 持有剪贴板时，复制失败后保留选区，释放剪贴板后重试成功。早期使用空 HWND 的占用夹具未产生预期失败，日志留存。
- 原生剪贴板用例使用自由手绘入口。其余三个入口共用同一输出命令，未逐入口进行原生复测。目标应用粘贴、完整语言和主题视觉矩阵、窄工作区与外部前台切换未单独实测。
