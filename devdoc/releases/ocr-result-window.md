# OCR 结果窗口验证

Windows Release 双屏验证见 `target/ocr-result-window/release-native-13/`。100% 和 125% 屏均通过截图与贴图的查看入口。夹具包含两行英文与一行中文，复制结果保留顺序和换行。打开窗口时剪贴板序列号不变。Ctrl+A／Ctrl+C、Shift 加方向键选择片段、Tab 后激活「复制全文」均核对了真实剪贴板。贴图关闭后结果仍可复制，Escape 销毁了结果窗口。

第一次原生验证捕获到浏览器尚未绘制的页面，产品返回空结果。后续复现了截图工具条遮挡结果窗口，成功路径现在先退役截图编辑。测试脚本还调整了方向键扩展标志，并用原生关闭消息稳定触发原贴图关闭。

相关 crate 回归 1,234 项通过，最后另跑截图退役及迟到结果专项。严格 Clippy、Slint 编译、格式和 Windows Release 构建通过。构建 SHA256 为 `2c50f69fef37b1af91159fd35d608799c931f8a00a7e939b46b93d4dd2ff0622`。

本轮原生脚本未覆盖裁剪贴图、识别中切到外部前台、鼠标拖选和鼠标点击复制全文、主题与十二语言的逐项交互、工作区边缘及复制失败注入。十二语言目录随 Slint 编译校验。
