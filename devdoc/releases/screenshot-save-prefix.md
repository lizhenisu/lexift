# 截图保存文件名前缀验证

实施基线为 `2704c11`，分支为 `codex/screenshot-save-prefix`。

## 行为

- 「设置 → 截图设置」提供截图文件名前缀和即时预览。保存成功后，两种自动命名方式才使用新值。恢复默认先修改草稿，默认前缀为 `Lexift`。
- Schema 16 保存前缀。旧配置和手工写入的非法前缀使用默认值。接受去除首尾空白后的 1–32 个字符，支持中文、内部空格和合法句点。拒绝 Windows 禁用字符、控制字符、末尾句点和会生成 Windows 设备名的前缀。
- 快速保存接纳时锁定前缀，复制后自动保存生成任务时锁定前缀。两者保留已有本地时间和原子重名防覆盖规则。快存文件名中的内部句点保留。

## 验证证据

Core 截图专项 59 项、Config 26 项、App 截图专项 22 项和 Platform 图像文件专项 11 项通过。逐项覆盖旧配置迁移、失败保留确认值、保存请求冻结、中文前缀、句点与并发原子发布。广筛 App 测试时，长图编辑器效果合成测试 `long_image_crop_outputs_exact_full_composition_slice_and_retains_effect_sampling` 超过 60 秒未结束，已停止该次运行，排除该测试后的截图专项通过。Platform 的两项交互测试保持默认忽略。

UI 设置组件通过十二语言、浅深主题、100%／125% DPI 和 640／960 逻辑像素布局组合的 96 张渲染快照测试。格式检查、严格 Clippy、Slint 编译与 Windows Release 构建通过。Slint 编译仍报告原有截图尺寸输入框的重复可访问文本警告。
