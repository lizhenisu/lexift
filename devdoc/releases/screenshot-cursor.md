# 静态截图鼠标指针验证

基线为 `main` 的 `6fe7e1f`。验证分支为 `codex/screenshot-cursor`。原生夹具、关键帧、剪贴板读回、像素差异、构建哈希及检查日志位于忽略的 `target/screenshot-cursor/`。

## 实现

- 采集前后读取 Windows 指针。仅在物理位置、热点及像素数据一致时，将指针与冻结底图一起交付。原始桌面像素仍独立保留。
- 对带 Alpha 的指针用 Windows 在黑底和白底绘制的结果还原混合数据。传统光标保留 AND／XOR 掩码，包含反相语义。初次原生验证发现直接从 GDI 位图读出的半透明边缘与系统绘制不一致，失败证据保留在 `native-96/` 和 `shapes-96/`。
- 静态编辑使用局部指针重绘。输出时用冻结选区或遮罩裁切指针，保留跨屏间隙和孔洞透明度。编辑新增标注叠在指针上方。普通贴图与历史保留成功输出的指针像素。

## Windows 原生

多窗口夹具改用标准标题栏窗口，并在获取独立参考图前等待测试窗口完成呈现。初次脚本使用无边框工具窗，没有选中任何窗口。后续运行的原始失败仍保留。125% 延迟首次运行在系统启动忙指针仍有变化时就生成了参考图，最终复测在倒计时内取稳定参考。

跨屏显示器间隙、负坐标和反相光标由 Core 像素夹具覆盖。原生检查使用两块物理屏幕分别测试单屏输出，未独立实测跨屏边界、系统反相光标、指针模式下的快速保存和复制后自动保存、历史恢复后的再编辑，或 OCR／取色完整链路。
