# 贴图倍率与编辑视口验证

## 范围与实现

2026-10-26，从 `main/9ffa9f0` 创建 `codex/pin-image-zoom`。普通贴图通过原生菜单提供六档物理倍率和一次性适应；编辑复用同一 HWND，保存普通返回几何，局部缩放与平移只修改视图。没有新增依赖、配置、crate、Core Port 或全局快捷键。

UI 的高精度视口与独立图片编辑器共享投影／逆投影／锚点算术，独立编辑器保留原有 f32 运算、适应留白和倍率限制。贴图使用 f64 视图，按现有 f32 原图标注坐标的量化间隔与半个物理像素往返误差停止放大；检查先逆转整体方向，避免镜像后的近零坐标掩盖原图远端的精度限制。

普通倍率缓存分数中心和实际比例；默认软件渲染使用 App 注入的 8192px 单边／1600 万像素外框预算，初始化适应及裁剪扩大后的返回几何同样检查。显式未知渲染器保留工作区内限制及原有旋转适应回退。屏幕外窗口保留可操作交集，DPI 变化不把普通真实倍率变成逻辑倍率。

编辑预览缓存原始分辨率不可变像素，初始可复用已有 Arc；视图变化只生成有界的目标视口像素，不合成文档或复制整张长图。鼠标单纯悬停不重建显示缓冲。图片、标注、裁剪、原生文字输入与光标使用已呈现方向及同一视图。原生手形在模式切换前释放，不能清除绘图工具随后安装的自定义光标。

## 自动化

- 高精度视口：负原点、物理缩放、精细滚轮累计、100% 停靠、锚点、平移取消／结束、尺寸变化、超过 1000% 的放大、数值拒绝及镜像裁剪远端原图精度。
- 窗口几何：六档、奇偶尺寸重复交换、分数中心、负工作区、可操作交集、小工作区、原生窗口预算、初始适应预算，以及超限档位拒绝。
- 跨模块 UI：编辑窗口保持有界、平移 Escape 消费、空格重复抑制与工具恢复、手形退出、裁剪取消恢复视图、结束编辑恢复普通裁剪几何；旧裁剪和方向结果、文档／历史及输出回归。
- 组件渲染：十二语言 × 浅深主题 × 100%／125%，共 48 份 BMP，位于 `target/pin-image-zoom/component-renders/`；检查同版本新增文案及主题点阵工作区。原生菜单由 Windows 计算布局，组件渲染不代替原生菜单验证。
- 工作区变化恢复的回归曾失败：辅助准备暂时恢复被动角色，几何事务在输入接收器重新安装前调用策略检查。现将几何确认移至所属接收器准备之后；失败仍保持隐藏，专项回归通过。

最终测试、严格 Clippy、格式及 Release 结果见下节；历史中间构建和失败日志仍保留于忽略的证据目录。

## 原生验证口径

所有操作使用实际鼠标、滚轮、键盘、原生菜单矩形和实际剪贴板／文件。不通过脚本强制激活画布或额外补点补救焦点。按 HWND 读取物理范围、DPI、辅助窗口样式及前台；保存菜单、视口、平移和工具切换截图。

- 普通 321×160 非对称夹具：两屏六档实际窗口内容尺寸、100% 单选、编辑中放大／平移、Escape、空格绘图与撤销、编辑结束返回、真实 OCR、PNG 和跨 DPI；锁定禁用倍率。
- 3000×1600 夹具：普通 100% 越工作区显示，200% 超窗口预算禁用；编辑内部连续滚轮超过 1000%，窗口保持有界，复制仍等于完整原图，适应可找回图片。
- 真实手动长截图：两屏采集 600×1200，旋转／翻转、OCR、局部放大、裁剪、扩大恢复、混合撤销重做及 PNG。期望结果由独立 Pillow 变换和实际物理输入换算生成，按尺寸及全部 RGBA 字节比较。
- 100% 长图补验最初没有裁剪：脚本 `[Math]::Min(1, double)` 选中整数重载，将约 0.76 倍取为 1，起点落到工具条。修正为双精度并检查 `WindowFromPoint` 后才计入通过。整数裁剪范围按物理鼠标位置 floor／ceil，不强求两种 DPI 下得到相同的人工百分比范围。

脚本与独立像素检查器：`target/pin-image-zoom/native-release.ps1`、`native-long.ps1`、`verify_pixels.py`。中间调试和预验收使用的二进制、旧截图不作为最终 Release 通过证据。
