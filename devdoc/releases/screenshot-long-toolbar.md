# 长截图单行工具条与延迟提示验证

日期：2026-10-20。当前分支 `codex/screenshot-long-capture`，保留原有未提交实现。本轮不暂存、提交、合并或推送。

## 修改

- 删除原 72px 双行卡片、常驻状态说明及内联 hover 文案。控制条固定 40px 逻辑高度，按拖动柄、尺寸、采集／编辑、输出、取消分组；按钮 32px、SVG 18px，尺寸区域测量并预留合法最大文字宽度。
- 复用 `AnnotationHintTarget`／既有一秒延迟提示窗口；长截图控制条增加会话、操作、组件实例的归属校验。移出、按下、拖动、输出及关闭撤销所属提示；尺寸区域悬停显示滚动说明。
- 暂停、匹配失败、达到上限及错误复用被动屏幕 toast，约三秒后销毁。按状态转换触发，相同状态的进度刷新不重新开启计时；离开状态撤销迟到通知。普通操作说明不触发 toast。
- tooltip 与 toast 在显示前完成原生准备和画布归属登记，沿用动态捕获排除标记；不通过逐帧隐藏窗口规避污染。toast 位于采集屏幕工作区底部中央，不获取焦点、不接收鼠标。
- 仅改变长截图控制条与所需提示接线，不新增翻译键、依赖、配置、crate 或 Core Port。使用既有十二种语言文案。

## 原生验证发现的问题

第一份 Release 在新增提示接线后，控制条拖动遇到 `RefCell already mutably borrowed`。原因是移动桥接仍持有 View／Registry 借用，原生几何操作重新分发输入时，提示归属解析重入了同一状态。修正为先冻结组件及必要数据、结束借用，再查询或更新原生窗口，回写时重新校验当前实例。增加桥接可重入回归，显式在光标查询回调中再次解析所属窗口并取得两处状态借用；不以忽略回调或捕获 panic 规避。

首次失败的记录保存在 `target/screenshot-long-toolbar/attempt-1-*`，不计入最终通过。

第二次原生检查确认，普通 tooltip 的非层叠输入策略仍可能由 `WindowFromPoint` 命中。长截图提示改为复用现有层叠反馈桥接：保留共同的延迟、布局、归属与销毁流程，仅在显示时将 Slint 小组件快照转换为预乘 RGBA，通过原有原生反馈表面呈现并保护鼠标穿透样式。toast 共用该显示 helper；普通标注提示、OCR 及其他 toast 保持原流程。没有桌面截图取纹理、拖动轮询或逐帧文字重建。第二次失败记录见 `attempt-2-*`。
