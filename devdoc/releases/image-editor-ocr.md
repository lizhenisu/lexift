# 图片编辑器 OCR 验证

日期：2026-10-23。基线 `main` 的 `c1bda63`；分支 `codex/image-editor-ocr`。没有暂存、提交、合并或推送。生成夹具、原生脚本、截图和像素复核在忽略的 `target/image-editor-ocr/`，运行日志位于 `target/image-editor-ocr-*.log`。

## 实现边界

长图结果、文件导入和历史恢复使用同一编辑器 OCR 用例，识别确认范围的底图并保留宿主。静态截图仍走原有识别后退出的路径。Core 管理宿主、操作、冻结范围和结果；App 将贴图 OCR 队列推广为共用单 worker／最新待处理任务，源像素以不可变引用持有，裁切后复用既有 OCR 和串行剪贴板写入。

UI 临时切到鼠标浏览模式，独立映射识别忙碌与图片输出忙碌，平移、缩放和窗口操作不被输出屏蔽。正在平移时完成或取消，等手势结束后恢复原工具。原生与 Slint 输入继续走既有单份路由。请求有 UI 接收凭据，旧排队快照不能提前释放临时输入屏蔽；窗口退役按所属请求凭据取消，旧退役不能取消新任务。

## 时序记录

对同一最终 Release 再跑两屏文件／历史识别，App 记录的四次后台任务耗时依次为 216、48、43、45ms，见 `target/image-editor-ocr/timings.log`。口径为 worker 取出任务后至裁切、资源检查、推理及剪贴板写入完成，不包含队列等待或 UI 呈现；首个为该进程首次识别，其余为驻留识别，不能作为端到端延迟或 P95。原生取消在 Escape 后等待约 1200ms 再检查编辑器和剪贴板，没有把脚本等待当作取消响应耗时。

## 未覆盖与副作用

未逐项实机覆盖全部语言／主题、所有标注和效果组合、所有 OCR 语言模型、物理负坐标或显示器热插拔。未注入系统剪贴板拒写、模型损坏、磁盘错误及内存不足；对应状态和错误分支以自动化覆盖。未完成所有外部前台竞争、菜单／输入框及捕获丢失的原生组合，也未对独立 OCR 翻译入口重跑整套实机矩阵。单次／少量夹具通过不构成 OCR 准确率或性能保证。

脚本会改变系统剪贴板内容及测试工具条位置；只启动并关闭本次所属应用和生成夹具窗口。未读取个人图片或个人剪贴板历史，不将截图、正文和日志纳入版本控制。峰值缓冲和多窗口长时间压力未做系统测量，历史缓存预算不等于进程工作集。
