## 覆盖边界

组件渲染不等于逐语言原生交互；原生操作使用当前 Windows 鼠标和键盘，覆盖 100%／125%，未扩展到其他 DPI 或其他操作系统。数值输入／忙碌／过期回调等有自动化覆盖，未逐一对所有输入框、菜单和绘图工具执行原生故障注入。未新增长时间历史压力或极限文档内存验收。

本轮不新增配置、依赖、crate 或 Core Port；实现位于 `codex/annotation-redo`，未自动暂存、提交、合入 main 或推送。
