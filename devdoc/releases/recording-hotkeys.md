# 录屏全局快捷键实施与验证

基线 `main bd3cc23`，分支 `codex/recording-hotkeys`。实施保留七个 crate，扩展现有 HotkeyPort 与配置 Schema 12，不新增依赖或 Core Port。所有夹具、时序、视频及截图放在忽略的 `target/recording-hotkeys/`。

## 实现边界

- Ctrl+Alt+F9 暂停／继续，Ctrl+Alt+F10 完成；仅开始前临时注册、暂停保留，收尾与取消注销。开始准备等待注册尝试完成，逐项失败不阻止录制。
- Core 保存 scope 与实际注册结果；scope 使用 session／operation／generation，独立于运输控制 request。迟到准备结果只清理，不能在退出或新截图后启动采集；重复完成不注销仍有效的本轮注册。
- App 的注册完成／取消握手避免“先注销、后注册”竞态；未退役不累积监听线程。Windows 仅一个临时消息循环管理两键，旧四键实现不重构。
- 六组快捷键设置校验、系统试注册、目标字段持久化与失败回退；录制期间两项只读，空闲未注册不是故障。UI 使用实际可用组合更新现有延迟提示。
- 暂停过滤标注文字和参数焦点，包括尚未修改数值的输入框；完成共用原有提交和末帧栅栏。原生自有菜单、模态窗口和移动循环在适配器输入层过滤，外部应用不受影响。

- `app-final.log`：82 项通过，1 项既有显式原生测试忽略。`app-lease-final.log` 补验注册未完成时取消不能提前报告退役。
- `smoke/smoke.json`：首个候选真实全局按键暂停／继续／完成、前台保持和系统占键生命周期通过；最终矩阵复核结果见后续记录。

## 本轮实机发现与修复

- 标注选项弹层打开时，暂停快捷键曾穿透输入过滤。UI 现在把任何已打开的参数／选项弹层都视为快捷键输入遮挡；完成键仍可在文字或参数输入事务中提交。
- 录制画布曾在 `show()` 前后发生扩展样式重写，导致窗口显示后丢失鼠标穿透。UI 在全部录制装饰显示后再次安装输入策略，Platform 重装窗口子类并把透明状态存于 HWND 属性，避免旧子类数据把新策略清掉。
- 最终双屏矩阵使用真实 Ctrl+Alt+F9／F10 操作；外部应用被正常置于前台，暂停、继续和完成期间前台 PID 保持为夹具进程。

## 性能结论

首轮 Release 对比保留了 `performance-comparison.json`：125% 屏的 `stop_to_sealed_ms` 为 104.31ms → 115.17ms，回归 **10.41%**，略高于计划的 10% 门槛。该失败来自同轮中的单次离群值，不作因果归因。

使用最终构建按“预热 index 0、计时 index 1–10”重新执行，并与保留的同一基线十轮结果比较，结果写入 `performance-comparison-exact.json`：

- 125%：五项回归分别为 4.27%、3.75%、−2.92%、3.95%、0.87%。
- 100%：五项回归分别为 −1.41%、2.32%、3.80%、3.63%、−2.45%。

两屏全部低于 10% 门槛。首轮失败与最终修正后结果同时保留，最终原始时序位于 `final/final-perf-exact/`。

## 保留的失败与环境处理

首次严格 Clippy 报告嵌套条件可合并，修正而未压制警告，保留 `clippy-first-failure.log`。参数输入检查进一步加入焦点状态，避免只依据“是否已改值”判断。

退出冒烟进程时，托盘脚本两次未收到菜单请求；实际命中为 NVIDIA Overlay 的 CEF 浮层，PID／HWND／范围证据保留在 `foreign-occlusion.json`。临时移开遮挡后真实托盘退出成功，未修改产品焦点策略。关闭该浮层属于测试环境准备，不能声称系统快捷键注册能检测第三方低层拦截器；不对显卡驱动或编码器做改动。

最终 Release 的双屏按键矩阵、弹层输入、保存、GIF 输出和同口径性能对比已经通过。资源记录仍保留截图窗口生命周期造成的 ALPC／Mutant／Section 句柄增长；该问题不影响快捷键监听退役，但不应在后续截图资源专项中被标记为已解决。
