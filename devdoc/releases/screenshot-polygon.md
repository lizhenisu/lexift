# Windows 多边形截图验证

基线为 `ef8367b`。验证证据保存到 `target/screenshot-polygon/`。

- 工作区库回归、严格 Clippy、Slint 编译、格式和 Windows Release 构建通过。Core 验证斜边半开规则、凹多边形、负坐标、显示器间隙、重复点、交叉边、重开轮廓和保存操作隔离。
- 最终 Release 原生脚本在 100% 和 125% 屏验证菜单、撤点、闭合、取消保存和重试。冻结后移动源窗口。单屏逐像素检查 Alpha 和颜色，允许不透明像素相对屏幕参考每通道差 1。跨屏单独逐像素核对 Alpha。结果见 retest-96.log、retest-120.log、retest-cross.log，构建哈希见 final.sha256。
- 多区域和多窗口原生冒烟通过。首次双屏脚本失败及其输出留作证据。修正夹具后，按冻结画面取参考，并分开等待各次点击。
- 完整十二语言和浅深主题视觉矩阵、外部前台切换及单区域原生回归未单独实测。
