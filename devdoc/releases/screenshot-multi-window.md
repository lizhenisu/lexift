# Windows 多窗口截图验证

基线 `7ee9961`。多窗口模式使用冻结桌面像素，按窗口前后顺序裁出可见部分。透明范围与画布反馈共用同一份遮罩。

- Core 夹具逐像素验证未选窗口遮挡、不可选浮层、前后窗口同时选中、负坐标及显示器间隙。
- Core 验证空范围和尺寸上限、重复保存、取消保留选区及旧保存结果隔离。
- Windows 原生夹具、构建和测试日志位于忽略目录 `target/screenshot-multi-window/`。

## 本机验证

- 工作区库回归通过。追加的 Core 截图回归 42 项通过，包含四项多窗口专项用例。格式、Slint 编译及严格 Clippy 通过。
- Windows 调试构建在 100%／125% 屏从真实菜单进入，选择两个窗口，冻结后移动源窗口，取消原生保存后重试。独立解码 PNG，核对未选前窗遮挡为全零 RGBA，两个所选窗口的可见像素正确。
- 初次 Windows Release 冒烟因冻结前后顺序不同退回。修复后允许互不相交的窗口交换堆叠顺序，相交窗口顺序改变仍退回。原始失败日志保留。
- 原生自定义窗口形状、半透明浮层、显示器间隙拖动、辅助窗口和外部前台的完整矩阵未单独实测。新增文案已同步十二种语言，未逐语言进行视觉检查。

最终 Windows Release 构建通过。100%／125% 屏均重跑菜单、冻结后移动、保存取消和 PNG 透明像素检查，结果通过。构建哈希见 `final.sha256`，原生结果见 `verified-96.log`、`verified-120.log`。
