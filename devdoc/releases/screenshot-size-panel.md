# 紧凑截图尺寸面板与标题栏拖动

日期：2026-10-17。本文替代宽高输入初版的面板布局与固定位置说明；整数草稿、确认／取消及输出语义继续沿用。

## 实现

- 基础尺寸 288×136 逻辑像素，标题居中，宽高同排并显示 × 和 px，取消／应用在底部右对齐。长语言按测量扩宽，窗口尺寸读 Slint 布局，不再在 Rust 固定为 340×170。
- 复用输入框、SettingsButton、WindowHeaderButton、Design Tokens 和现有关闭 SVG；关闭可访问名称及延迟提示复用 12 种语言的 Close 文案。
- 标题栏单独命中，复用工具条 Drag 的物理坐标和 DPI 抓取点变换，沿原生捕获输入事件更新位置，不新增轮询。移动、尺寸改变和拖动结束不重新锚定到标签；跨屏同步所属画布，结束时夹紧到工作区。
- 组件与原生 Escape 共用取消入口及按键释放保护，一次 Escape 只取消正在进行的拖动；捕获丢失保留当前位置。关闭退休输入、撤销捕获、停止准备与 Escape 保护任务并清理提示。
- 保留原草稿、整数校验、确认、外部点击、失焦、输出及对象／历史语义。不增加坐标、比例锁定、交换或预设。

## 自动化与组件渲染

- 14 项尺寸输入专项回归通过，包含新增 5 项：标题命中和保位、输入／按钮／关闭的独立命中、跨 DPI 与负坐标夹紧、Escape 双路取消、关闭清理与旧组件。
- 全部 UI：430 项通过、11 项既有显式忽略。
- UI Clippy（all-targets，-D warnings）、格式检查及 Slint 编译通过。
- `target/screenshot-size-panel/render/` 保存 12 种语言 × 两种主题 × 两档 DPI 共 48 张组件图，`components.png` 为人工检查的样例汇总。渲染检查发现绝对定位容器中未指定的坐标会被默认居中，已补齐显式坐标并回归实际控件命中。

| 关闭提示与关闭按钮 | 悬停后出现所属面板的关闭提示，点击 SVG 关闭按钮取消宽度 640 的草稿；随后复制仍为原 320×240。见 `close-tooltip*.png`、`closed.png`、`closed-output.png` |

| 确认、校验与输出 | 两档 DPI 拖动后继续 Tab 编辑高度，Enter 应用，实际输出均为 640×360；空值不能确认，0／0 归一为 1×1。输入 23 位整数安全截断，固定原点 (2680,160)，输出为虚拟桌面剩余的 1800×1280。见 `invalid.png`、`minimum.png`、`clamped*.png` |
| 像素 | 两屏 640×360 输出的 624×344 内部区域与画布逐像素相同；关闭取消后的 320×240 同样匹配。超大截断输出在可见屏幕内，排除左下操作提示后也逐像素相同，结果见 `pixels.json`。初次大选区比较包含了操作提示，已修正比较区域；该提示属于交互帧，按既定规则不进入输出 |
