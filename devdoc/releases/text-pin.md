# Windows 剪贴板文字贴图验证

基线为 `main 95d917b`，实施分支为 `codex/text-pin`。入口、复制和生命周期见[贴图使用说明](../features/pin-interaction.md)。

## 自动化

- Core 验证 UTF-8 字节上限、空白、原始字节切片、实例上限、准备和复制的迟到结果，以及图片与文字混合批次的部分失败。
- App 验证只读取一次剪贴板，打开时不写剪贴板，局部与全文通过敏感文本接口写入，以及失败重试和关闭隔离。
- UI 软件渲染验证全选、复制、右键菜单键盘操作和 Escape。生成十二种语言、两种主题、两种 DPI 下的 48 张窄窗口布局快照。
- Core 387、App 90、UI 559、Platform 239 项测试通过。格式、严格 Clippy 及 Slint 编译通过。Slint 仍报告原有截图尺寸输入的可访问名称重复说明。

## Windows 原生验证

- 在 125% 显示器从真实系统托盘创建文字贴图，核对辅助 HWND、默认置顶和外部前台保持。拖动到 100% 显示器后验证缩放适配、边缘改宽和滚动。
- 用合成中英文、Emoji、空白、CRLF 及长链接夹具。读回真实剪贴板，核对 `Ctrl+A`／`Ctrl+C`、局部复制和菜单复制全文，并检查 Windows 历史排除标记。测试脚本将原剪贴板暂存在内存中并恢复。
- 原生夹具占用剪贴板时，复制失败且保留原选区。释放后可复制同一选区。空白和超过 64 KiB 的正文只显示提示。
- 验证置顶切换、图片与文字统一隐藏／恢复、保持原 HWND、截图开始时暂时隐藏及取消截图后恢复。验证 Escape 后 HWND 销毁及托盘退出。
- 实机从 125% 屏的托盘创建，在 100% 屏验证跨屏后的实际操作。十二语言和浅深主题用软件渲染覆盖。未改变系统显示器布局，也未逐种语言切换实机系统设置。
- 初始脚本记录保留于 `native-release-1` 至 `native-release-mixed`。失败分别涉及 Shell 托盘图标就绪判断、扩展键扫描码，以及图片贴图本地化标题定位。改用通知区域无障碍定位和真实按键后，混合链路见 `native-release-mixed-2`，占用、空白与超限结果见 `native-release-failure-check`。

最终 Windows Release 已重新运行整套原生脚本。结果见 `native-release-final.log`，SHA256 为 `dd208ce599959fe9b867f738dd36b72534d8f986dc58dd3655173a2fef56ede3`。窄窗口修正后的完整 UI 回归及严格 Clippy 已通过。

原生脚本、构建日志、哈希和合成内容截图保存在根目录下忽略的 `target/text-pin/`。
