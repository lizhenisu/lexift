# Windows 异形截图 OCR 验证

基线为 `f361439`。多窗口、多边形、选区加减和自由手绘共用确认遮罩，异形标注编辑复用同一冻结底图。遮罩外及透明部分合成到白底后识别。直接复制经串行剪贴板链路写入，查看结果在用户复制前不写剪贴板。成功、取消和失败均保留截图上下文，不更新图片历史或 `R`。

自动化检查包含两种 OCR 目标、所属结果窗口关闭后恢复，以及取消后的迟到结果。像素夹具核对负原点、孔洞、屏幕间隙及预乘透明度。原生脚本、构建哈希、时序日志和合成文字夹具保留在 `target/screenshot-masked-ocr/`。

Core、App、UI 和 Platform 的 OCR 筛选回归共通过 61 项，11 项按原测试标记忽略。Core 的 `masked` 筛选另通过 4 项。格式及严格 Clippy 通过，UI 检查包含 Slint 编译。

Windows Release 构建通过。原生脚本 `run-9`／`run-10` 分别在 100%／125% 屏验证选区加减直接复制、查看结果时剪贴板序号保持不变、关闭结果后选区仍在，以及进入异形标注后再次识别得到相同正文且编辑器保留。实际剪贴板包含两行可见标记，孔洞及选区外的两行标记均未出现。前几轮的定位失败和截图一并保留。

原生矩阵未覆盖其余三种异形模式、标注内容排除的实机像素对照、识别期间取消，以及十二语言和主题下新增菜单的逐项实机操作。
