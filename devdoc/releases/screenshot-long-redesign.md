# 长截图采集、预览与结果编辑体验重做验证

日期：2026-10-20。分支：`codex/screenshot-long-capture`。工作树未提交；保留首版已有改动。

## 替代的旧体验与实现

旧版本的范围框随冻结画布消失、预览采用 `thumbnail(220,200)` 整图适应、完成后近全屏编辑器，以及必须先编辑才能输出，均由本轮实现替代。旧版[验证](screenshot-long-capture.md)的像素结果仍是历史证据，不能证明这些交互通过；此前漏测了范围持续显示、预览可读性与完成画面。

- 独立透明范围层持续绘制蓝框和外围遮罩，采集区内透明；范围层和预览都穿透鼠标、不激活。暂停保留反馈，退出销毁。
- 紧凑横向控制条与预览分离；拖动柄移动控制条，进度更新不重置位置。控件优先在所属采集屏幕区外布局；区内浮动依赖原生捕获排除成功。
- 预览宽度以 200 逻辑像素为基准，限高后只采样已确认的尾部块；绿色框标记最后确认的完整帧，上部溢出显示折线。像素、全图范围、可见范围及当前帧同版本提交，拒绝帧保留旧画面。
- 编辑／复制／保存／贴图共用结束与冻结过程。完成图只展平一次；保存取消或输出失败保留 Frozen 结果供重试，不重启采集。原生保存期间隐藏采集反馈，返回后恢复。
- 独立编辑器默认约 960×760 逻辑像素、限制为所属采集屏幕工作区的 90%，从顶部适应宽度且不超过物理 100%；小图居中。支持标题拖动、右下角窗口缩放、整图适应、100%、缩放及滚动，工具条在移动／尺寸／DPI 变化后跟随并夹紧。
- 连续采集资源在冻结后释放；保留旧画布到编辑器首个实际反馈帧，准备失败返回冻结结果。旧首帧回调校验窗口实例及版本，不得关闭新界面。长图不更新 R 的桌面区域记录，原 512MiB 缓冲预算不放宽。

### 实机发现并修正的问题

普通提示的非层叠透明窗口即使返回 `HTTRANSPARENT`，也不足以将输入交给其他进程。最初夹具因范围层阻挡而不滚动。专用反馈桥接改为层叠 RGBA 表面，并按窗口角色持续保护 `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`；后端样式重写也不得移除。普通提示窗口不启用此策略。真实源窗口滚动和像素检查通过后才计入本轮验收。

另修正了控制条最小／最大高度约束导致状态行被裁，以及 Slint 默认定位将标题栏放到窗口中部的问题。原生拖动脚本须在按下后等待事件循环进入系统拖动再发送移动／松手；修正脚本后标题拖动通过，不能把无间隔脚本的误报记为产品修复。

## 性能与资源口径

最终 24 段合成源采集中处理 421 帧、接受 421 帧；配准平均 **2.19ms／帧**，有界预览数据生产平均 **0.36ms／帧**。不包括捕获等待、UI 安装及桌面呈现；正常夹具零拒绝不代表任意动态页面。

UI Prepare 到范围首个反馈呈现的中位数 **321ms**、P95 **379ms**（24 段）；选择编辑到实际反馈呈现的三次记录 **111／82／111ms**。不把脚本固定等待或滚动节奏算作产品延迟。旧首版记录配准平均 2.58ms，但使用的源样本和测量范围不同，不能据此声称本轮加速；未保留相同夹具下旧版进入编辑／预览呈现的可比基线，本轮不宣称前后延迟比例通过。

已确认像素块／锚点峰值 **10.99MiB**；20 轮输出后采样进程 PrivateBytes **104.76–185.81MiB**，最后一轮 104.76MiB，未见单调增长。这不是所有瞬时分配峰值或 GPU 显存，也不替代资源所有权清理。

## 覆盖边界

- 原生交互为本机中文浅色、100%／125% 两屏；全部语言和主题的结果属于组件渲染，未逐语言操作原生窗口。
- 合成 WinForms 源、Chrome 正文／列表实际覆盖；未对其他任意文档软件、网站及 UIA 提供者作承诺。负坐标、拒绝／重复／过期帧和上限由自动化覆盖，未重配实际负坐标屏、热插拔或跑满 512MiB／32MP／32768px。
- 本轮实机验证原生保存取消和重试，未强制制造磁盘／剪贴板系统故障。失败保留 Frozen、编辑器准备失败、取消及旧回调有自动化覆盖。
- 长图滚动后的文字输入沿用图片坐标映射与相关回归；本轮新编辑器实机标注验证为未滚动的矩形，未逐工具重测所有旋转／文字组合。
- 辅助窗口身份由原生样式及生命周期检查覆盖，未另录像任务栏／Alt+Tab 列表。截图、关键帧动画（非连续视频）、临时夹具、像素与时序日志均在忽略的 `target/screenshot-long-redesign/`，不纳入提交。
