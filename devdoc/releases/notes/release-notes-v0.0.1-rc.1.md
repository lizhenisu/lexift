# Lexift 0.0.1-rc.1

Lexift 首个候选版本，提供 Windows 桌面翻译和屏幕讲解标注功能。

## 功能

- 使用 `Alt + X` 翻译当前选中文字；支持鼠标拖选和双击选词。
- 使用可自定义的全局快捷键打开选区工具条。
- 使用 `Alt + A` 打开标注工具条，可在屏幕上绘制矩形、椭圆和聚光灯标注。
- 支持 DeepL 翻译、多个目标语言、界面语言和浅色／深色主题。
- 提供 Windows x86_64 安装包和 portable ZIP。

## 安装

下载 `Lexift-0.0.1-rc.1-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
