# Lexift 0.0.1-rc.2

Lexift 候选版本更新，改进标注工具与系统托盘交互。

## 更新内容

- 将系统托盘菜单改为主题适配的原生 UI 菜单，支持鼠标和键盘操作，不再显示在任务栏或 Alt+Tab 中。
- 改进标注参数下拉菜单，避免选项被窗口裁剪，并优化画布光标反馈。
- 增加几何图形和聚光灯的可视化自定义颜色选择器，支持 HEX 输入、实时预览和撤销。
- 统一几何图形与聚光灯的自定义颜色入口样式。

## 安装

下载 `Lexift-0.0.1-rc.2-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
