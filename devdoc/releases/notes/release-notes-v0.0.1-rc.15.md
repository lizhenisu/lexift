# Lexift 0.0.1-rc.15

本候选版本集中完善截图工作流、图片历史和屏幕录制后处理。

## 更新内容

- 录屏预览新增画面裁剪：支持偶数像素吸附、移动和八向调整，可与首尾裁剪组合；MP4 和 GIF 使用同一确认范围。
- 截图支持多区域、多窗口、多边形、选区加减、自由手绘、透明复制和透明贴图。
- 异形截图与异形标注支持文字识别，可识别并复制，也可在独立结果窗口查看和局部复制。
- 新增截图预设、OCR 结果窗口、快速 PNG 保存，以及复制成功后自动保存 PNG。
- 长截图支持横向手动拼接、自动滚动、固定页眉页脚处理，以及采集内裁剪。
- 新增实时窗口贴图与关闭贴图恢复，并完善贴图裁剪、交互和窗口资源交接。
- 更新截图、长截图、贴图和录屏说明，补齐十二种界面语言和专项验证记录。

## 安装

下载 `Lexift-0.0.1-rc.15-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。
