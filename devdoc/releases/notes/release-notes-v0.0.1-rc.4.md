# Lexift 0.0.1-rc.4

本候选版本继续完善屏幕标注工具，并改进首次打开工具条时的鼠标响应。

## 更新内容

- 改进箭头和折线绘制交互，支持拖动或两次点击绘制箭头，并优化弯曲控制点的位置、样式和光标反馈。
- 优化放大镜的连接线、缩放锚点和首次显示流程；调整工具条修改倍率时放大框的缩放中心。
- 改进几何图形悬停提示、曲线图标和鼠标光标资源。
- 将首次打开标注工具条的 Windows 鼠标钩子移至独立消息线程，减少初始化期间对真实鼠标输入的阻塞。
- 改进工具条与多屏画布的分帧初始化，并增加首次打开阶段诊断。
- 调整 Settings 导航排版和 Windows 应用图标。

## 安装

下载 `Lexift-0.0.1-rc.4-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
