# Lexift 0.0.1-rc.14

本候选版本完善屏幕录制、图片编辑和截图效率，并增加可直接用于日常操作的快捷键。

## 更新内容

- 完成无声屏幕录制链路，支持 30／60fps、标准／高清画质、系统声音与麦克风、倒计时、预览回放、首尾裁剪、MP4 与 GIF 输出，以及录制期间实时标注。
- 录制期间可使用 `Ctrl+Alt+F9` 暂停／继续、`Ctrl+Alt+F10` 完成；两项均可在设置中修改，并只在录制期间临时占用。
- 主页改为使用指南，正常启动后直接驻留后台；新增可配置的独立截图快捷键 `Alt+S`。
- 截图支持刷新底图，保留当前选区、标注和编辑状态，同时排除截图交互装饰。
- 图片编辑器增加非破坏颜色、亮度、对比度和尺寸调整，并优化大图预览、取消和资源复用。
- 继续完善截图按点识别、区域复用、焦点交接、长截图、贴图和托盘交互。
- 更新十二种界面语言、快捷键说明、功能文档和验证记录。

## 安装

下载 `Lexift-0.0.1-rc.14-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。
