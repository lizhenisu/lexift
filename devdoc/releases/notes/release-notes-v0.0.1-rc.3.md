# Lexift 0.0.1-rc.3

本候选版本完善屏幕讲解标注，新增铅笔和荧光笔绘制，并改进圆角控制点编辑反馈。

## 更新内容

- 新增铅笔自由曲线绘制，支持多种线型、选中、移动和缩放。
- 新增荧光笔直线与圆角矩形绘制，支持半透明显示、选中、移动和编辑。
- 优化圆角控制点光标，使箭头尖端对准控制点，弯曲标记显示为独立弧线。
- 完善标注工具参数、颜色和撤销交互。

## 安装

下载 `Lexift-0.0.1-rc.3-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
