# Lexift 0.0.1-rc.5

本候选版本增加可编辑的文字标注和水印，并继续完善标注工具的交互与样式。

## 更新内容

- 新增画布文字标注，支持多行输入、字体与文字样式、背景和描边、旋转、缩放、移动及连接箭头。
- 新增会话水印，支持多种时间格式、位置、透明度、大小、颜色和字体设置。
- 改进文字编辑与提交后的排版一致性、鼠标定位、输入法组合文字、角点操作和缩放表现。
- 补齐文字、水印及相关设置面板的自定义颜色选项，并改进样式菜单和时间格式列表。
- 修正文字斜体、描边显示、箭头控制点、鼠标光标及工具条菜单交互。

## 安装

下载 `Lexift-0.0.1-rc.5-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
