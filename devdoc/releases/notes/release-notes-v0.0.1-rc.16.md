# Lexift 0.0.1-rc.16

## 更新内容

- 静态截图可选择包含采集瞬间的鼠标指针，覆盖普通截图、多区域、多窗口、多边形、选区加减和自由手绘。默认关闭。
- 统一异形截图控制条，改进操作布局。截图设置可自定义快速保存和复制后自动保存的文件名前缀。
- 长截图支持横向自动滚动、固定左右栏识别，以及沿采集轴的双向扩展。
- 支持把文字贴在桌面，新增贴图管理窗口。
- 更新录屏预览和剪辑界面，增加播放及导出速度控制，以及导出音量调整和移除音轨。
- 升级至 Slint 1.19，修复部分提示窗口呈现及 Windows 退出时的资源释放问题。

## 安装

下载 `Lexift-0.0.1-rc.16-windows-x86_64-setup.exe` 安装，或下载便携 ZIP 解压后运行 `lexift.exe`。可用 `SHA256SUMS.txt` 校验下载文件。
