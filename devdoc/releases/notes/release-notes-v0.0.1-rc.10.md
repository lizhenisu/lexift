# Lexift 0.0.1-rc.10

本候选版本加入本地 OCR 翻译，并继续整理标注、窗口与 OCR 的内部职责。

## 更新内容

- 新增本地 OCR Provider。按 `Alt+T` 框选屏幕内容，在本机识别后使用当前翻译服务显示结果。
- 支持自动检测、中／日／英和拉丁文字识别；可选安装韩文扩展，加入自动检测候选。
- 将基础 OCR 模型包和韩文扩展作为独立资源发布，首次使用时可分别下载；包均带完整性校验。
- 将标注导出改为后台采集、合成和保存流程，并拆分标注与窗口 UI 模块。
- 移除仓库历史中的三张 OCR 测试图片；需要真实模型推理测试时，可通过 `LEXIFT_OCR_TEST_IMAGES` 指向本地测试图片目录。

## 安装

下载 `Lexift-0.0.1-rc.10-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

这是候选版本。请通过 GitHub Issues 报告问题。
