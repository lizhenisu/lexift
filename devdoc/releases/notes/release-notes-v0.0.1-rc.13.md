# Lexift 0.0.1-rc.13

本候选版本扩展图片导入与编辑，并增加贴图显示和颜色控制。

## 更新内容

- 支持从 PNG／JPEG 文件打开图片进行编辑，也支持将剪贴板图片贴图；新增 PNG 与 JPEG 保存。
- 图片编辑器支持旋转、翻转、缩放、裁剪、撤销／重做及 OCR；图片历史可恢复编辑内容。
- 贴图支持锁定、鼠标穿透、批量隐藏／恢复、透明度，以及灰度、反色、亮度和对比度调整。
- 改善托盘菜单连续打开稳定性，并修复图片变换后的标注输入与呈现。
- 截图新增延迟启动和取消；继续改进窗口／区域识别、焦点交接与长截图编辑体验。
- 更新界面翻译和操作文档。

## 安装

下载 `Lexift-0.0.1-rc.13-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。
