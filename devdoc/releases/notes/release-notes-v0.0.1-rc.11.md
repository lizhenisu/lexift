# Lexift 0.0.1-rc.11

本候选版本新增截图模式与可编辑贴图，并改进标注编辑、工具提示和划词工具条定位。

## 更新内容

- 新增截图模式：框选屏幕后可使用标注工具编辑，并复制、保存或生成贴图。
- 贴图支持再次标注、隐藏／恢复标注、独立撤销，以及右键复制、保存、阴影和置顶操作。
- 修复多贴图同时存在时拖动和关闭偶发失效的问题，并改进贴图窗口和截图工具条的生命周期。
- 矩形橡皮擦绘制后可以继续移动、缩放和调整圆角；松手后立即显示控制点。
- 标注工具条和参数面板增加延迟悬停提示；字体目录改为后台加载，减少首次打开参数面板时的等待。
- 调整划词工具条与选区的间距，并修复屏幕边缘反向划词时的定位问题。
- 移除 OCR 资源下载完成后的额外确认提示。

## 安装

下载 `Lexift-0.0.1-rc.11-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

这是候选版本。请通过 GitHub Issues 报告问题。
