# Lexift 0.0.1-rc.12

本候选版本扩展了截图与图片编辑流程，新增长截图、贴图 OCR、图片裁剪及进程内图片历史。

## 更新内容

- 截图支持像素放大镜与取色、窗口和内部区域识别、滚轮切换候选层级，以及复用上次成功输出的区域。
- 改善截图准备与编辑焦点交接；首次框选和编辑阶段继续支持取色与键盘操作。
- 新增长截图采集、连续画面拼接、独立图片视口编辑及复制／保存／贴图输出。
- 长图和贴图编辑器支持非破坏性裁剪、扩大恢复、撤销与重做；修正浏览平移时的抓握光标。
- 贴图右键菜单新增 OCR 识别并复制文字；长图 OCR 按重叠区块检测，减少长图缩小识别导致的漏字。
- 新增仅保留于当前进程的图片历史，支持恢复截图、长图及其可编辑内容；退出程序后清空，不自动写入图片文件。
- 新增图片历史工具条和托盘入口；同步更新界面文案及操作说明。

## 安装

下载 `Lexift-0.0.1-rc.12-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

这是候选版本。请通过 GitHub Issues 报告问题。
