# 截图复制后自动保存 PNG

基线为 `3d72948`。设置默认关闭。首次启用时目录和开关一起写入配置，随后后台复用快速保存目录。普通截图、长截图采集结果和长图结果编辑器复制成功后，使用同一份冻结像素写 PNG。写盘拥有独立生命周期，最多保留一项执行中和一项等待。退出取消等待任务及尚未发布的成品。

Core／Config 回归覆盖 Schema 迁移、配置往返、首次启用原子提交、取消后拒绝迟到目录结果，以及复制成功去重和异形截图排除。Platform 复用快速保存的同目录临时文件、PNG 编码及原子防覆盖发布。运行日志、原生脚本及输出对照位于 `target/screenshot-auto-save/`。

Core 379 项、Config 25 项和 App 截图相关 25 项通过。App 包含队列容量及退出取消测试。Platform 239 项通过，139 项按原测试标记忽略。通过项包含原生 PNG 解码对照、中文路径、取消不覆盖及并发发布。

首轮 Release 实测 `run-6`（SHA256 `8d6202e0fcd13c8b1bea4292beebc39da9b03d7263032f8eb09cc11615918af0`）从托盘进入设置，取消首次选目录后仍为关闭，确认后保存并重启。从 100%／125% 屏分别用静态截图、长图采集控制条和长图结果编辑器复制，六张 PNG 与真实剪贴板逐像素一致，并与受控图像一致。关闭开关后仍能复制，目录未新增 PNG。前置脚本定位失败保留在 `run-1` 至 `run-5`。

`extended-final` 使用同一构建重跑以上六条链路，并验证改目录后写入新位置。临时移除新目录后，实际复制仍成功，后台记录写入失败，原文件保留。恢复目录后关闭开关，下一次复制未触发写入。
