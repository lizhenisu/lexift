## 实现边界

- 仅首次截图框选启用。默认最深有效元素，滚轮上扩大、下缩小，到首尾停止；相同范围合并，同一叶内保留层级，换叶重置。按下冻结候选并忽略滚轮，超过原有 4px 逻辑阈值后自由框选。
- 扩展既有 ScreenCapturePort 和 ScreenshotCapture，不新增依赖、crate 或 Port。App 在原有冻结图片采集前后取得几何，最终再校验窗口范围和层级；OCR 仍走原像素方法。
- Core 只接收不透明整数身份、父身份、窗口、范围及遍历顺序，处理稳定性、祖先裁切、去重及命中。不向 UI 传 COM 对象；UI 只命中冻结图，复用边框、遮罩、单份尺寸标签和放大镜。
- Windows 使用一个自有 MTA 工作线程与一个最新待处理任务。UIA8 连接／事务超时均配置 50ms，无法配置就返回空集合；每轮等待最多 250ms，最多 8 窗口、2048 节点、16 层。不读取名称、正文或值，不对外部程序执行操作。
- 超时／取消不等阻塞提供者立即返回，不创建替代线程；只保留已发布且前后可校验的前缀。COM 在所属线程释放。退出运行时取消活跃及待处理任务。
- UIA 工作线程显式设为每屏 DPI 感知；最初独立原生探针在 125% 屏出现坐标虚拟化，已修正，不能只依靠 100% 屏检查。
- 12 语言初始提示增加“滚轮切换区域”。键盘重复与修饰键状态共用同一个后端监听，避免覆盖 C 取色的重复抑制；旧宿主的修饰键引用在关闭时失效。

### 未覆盖

- 未提供可访问性信息、权限隔离、系统隐藏或超出预算的程序只承诺整窗回退，不承诺所有浏览器／自绘控件。权限拒绝和不可配置 UIA 超时未在系统中强制制造；错误分支为空集合回退，受控阻塞／取消以工作队列回归验证。

- 未重跑独立 OCR 推理、所有绘制工具及所有驱动／远程桌面组合；相关 Core／App／UI 回归通过。
