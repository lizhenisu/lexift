# 截图选择对象模式回归（2026-10-15）

> 鼠标模式的对象编辑及“选择对象”命名已被后续修正取代，当前行为以 [鼠标模式语义与穿透回归](mouse-mode-validation.md) 为准。本页保留当时的验证记录。

## 原因与修复

截图的对象编辑使用共用标注流程。`adopt_selected_style` 在按下和松手后按对象类型切换绘制工具，随后 `open_panel` 再次切换，导致主工具条离开“选择对象”。

本轮在共用 UI 流程中区分对象参数入口和工具设置入口；对象入口绑定身份与类型，不改变选择模式或记忆的绘制变体。选择模式支持共用参数事务，修改选中对象时不调用记录绘制默认值的路径。对象光标也走共用控制点及手势反馈，截图模块只补充选区命中。

没有新增 Core 状态、Port、配置、依赖、crate 或可见文案，普通标注沿用原有工具行为。保留上一轮选区调整隐藏工具条的实现。

从项目 `target/release/lexift.exe` 启动，分别在 96 DPI（100%）和 120 DPI（125%）显示器执行：截图框选 → 绘制矩形 → 点击“选择对象” → 点击矩形 → 贴图 → 进入贴图标注 → 选中矩形。

四组桌面合成截图均确认主工具条保持“选择对象”的蓝色高亮，同时显示选中对象控制点及共用参数面板；对象按下期间工具条没有误用选区调整的隐藏规则。
