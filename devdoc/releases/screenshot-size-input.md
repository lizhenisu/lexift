# 截图手动宽高输入验证

日期：2026-10-17。

本记录对应宽高输入初版；当前紧凑布局、窗口尺寸及标题栏拖动见 [后续验证](screenshot-size-panel.md)。

## 实现边界

- 仅截图编辑的鼠标模式可点击尺寸标签打开面板；首次框选、绘制工具、普通标注、贴图和 OCR 不响应。
- 宽高为整体物理像素，输入保留草稿，Enter／应用一次提交；取消、Escape、外部点击及失焦不应用。固定左上角，最小 1×1，超出虚拟桌面自动截断。
- `RegionEditor::set_size` 与键盘缩放共用边界函数，不模拟按键，不改变对象、绘制参数和文档历史。
- 初始画布和后台预览均在成功呈现像素后记录对应标签命中范围。预览结果携带画布实例及标签／选区快照；旧版本、错误画布和失败提交不能更新命中范围。过期标签点击被消费，不误拖新版选区。
- 面板由 App 已注入的原生准备、归属、输入与激活能力管理；跨屏定位在隐藏阶段留出一次 DPI 事件交接。会话、画布、面板实例及选区快照约束回调，关闭退休输入队列并停止准备任务。
- 面板在复制／保存／贴图前取消草稿；标注输出仍取独立干净快照。面板打开时左下角提示隐藏，工具条保留。

## 未覆盖范围

- 实机使用既有中文浅色设置；12 种语言和浅深主题由组件渲染覆盖，没有修改用户语言或主题配置。
- 本机没有负坐标排列；负坐标、无效整数、异步准备失败和迟到帧主要由自动化覆盖。
- 实机使用图片剪贴板输出，没有逐项重复 PNG 保存对话框、贴图及所有标注效果；相关既有 UI 回归通过。跨屏输出核实尺寸及左屏像素，未逐像素对比右屏全部区域。
- 没有高帧率录屏和长时间压力测试。比例锁定、尺寸记忆及新快捷键不属于本轮。
