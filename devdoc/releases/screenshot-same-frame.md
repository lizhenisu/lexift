日期：2026-10-15。

当前定位以本文末尾“固定顺序定位精简”及功能文档为准；中间各轮标签／工具条互相避让记录保留为历史，已不代表当前交互。

## 问题与实现

原方案由后台线程绘制选区整帧，再通过独立原生窗口移动标签；两者完成时间不同。即使层级正确、窗口可见，也无法保证快速拖动时位置一致。

- 初始框选将标签内嵌到区域宿主；编辑阶段将标签、边框、控制点、遮罩合成到同一像素帧。每份不可变输入携带选区、标签布局、文字及按主题／DPI 准备的字符纹理，拒绝选区不匹配的反馈。
- 删除截图专用标签窗口、owner、位置计时器、层级重试及对应测试；普通工具提示窗口保持原实现。
- 字符纹理只在隐藏准备时生成并随会话清理。不会为每个尺寸值缓存整张图片，不在移动中截图或加载标注系统字体。
- 每个显示器复用未变化的文档合成及变暗底图，移动／缩放只进行必要行拷贝和反馈绘制；缓存随内容、样式、效果、源图、DPI 变化失效。单个待处理任务继续合并为最新请求，没有降低现有刷新调度频率。
- 标签不属于 Core 文档或导出合成，复制／保存／贴图不能包含标签。取消、会话替换及窗口关闭后，旧帧不能更新新目标。

## 自动化与性能

- 整帧像素回归覆盖浅深主题、100%／125% DPI、连续移动／缩放、延后完成的完整帧、尺寸文字与边界一致、单宿主跨屏布局、零面积及缓存清理。
- UI 投递回归在人为推进当前选区后投递较早的完整帧，确认其像素仍保持完整一致；旧版本、另一会话及已关闭窗口的结果被拒绝。
- 字体服务注入不允许扫描的加载器，确保尺寸标签准备不启动标注字体扫描。导出像素检查确认不含标签。
- 同机、同一 1280×720 合成输入、丢弃前 10 次热身后的 40 个样本的调试构建后台帧基准：修改前中位数 **280.495ms**、P95 **282.306ms**；修改后含标签中位数 **45.118ms**、P95 **45.352ms**。日志 `target/screenshot-frame-baseline.log`、`target/screenshot-frame-after.log`。此数字包含纯 CPU 帧生成，不是 Release 交互延迟或端到端 FPS。
- 组件像素证据位于 `target/screenshot-same-frame/same-frame-*.png`。

## 选区调整后的恢复定位修正

用户补测发现：左上角首次框选的标签可见，但再次调整右下角尺寸并松手后又被工具条盖住。上一轮验证只覆盖首次框选后的桌面画面及避让纯函数，没有覆盖工具条完整隐藏／恢复流程；此前顶边通过结论只适用于首次显示。

原因是恢复调用 `show_main` 时存在另一套只按选区定位的路径，显示后覆盖了标签避让位置；随后仅按选区边界缓存的预览更新又跳过了正确定位。

- 截图首次显示、恢复显示与选区反馈共用定位入口；显示前强制计算当前选区、标签、工具条尺寸、工作区和 DPI，删除截图显示后的重复定位。普通标注及贴图保留原路径。
- 缓存改为计算结果和窗口尺寸，仅用于减少重复原生定位；恢复显示始终绕过缓存。保留实例、会话、调整编号及手势状态校验，手动拖动工具条期间不覆盖位置。
- 自动化使用可记录位置和显示时位置的窗口适配器，执行真实工具条恢复调用链，覆盖八方向缩放、区域移动、按下未移动、Escape、捕获丢失、连续恢复及调整中的旧显示调用。断言恢复后的窗口不与像素帧中的标签相交，且显示时已完成定位。适配器仅保留弱引用，避免测试夹具影响原有图像释放断言。

## 上下拥挤时优先使用侧边

按用户确认的交互，通常保持左上方；上方放不下或与工具条候选位置相交时，优先左侧、其次右侧。标签靠近选区上角、保持原有 8 个逻辑像素间距，纵向可在工作区夹紧，完整放入所属宿主后才采用。左右不足时沿用原有上下回退及工具条预留空间。

共用布局支持可选工具条避让范围：初始框选传入空范围，编辑阶段先计算不含标签的工具条候选，随后计算标签，最后按最终标签范围定位工具条。标签仍属于同一份预览快照与像素帧，没有增加窗口或拖动期间的字体准备。

- 新增纯定位回归覆盖通常上方、顶边、仅左侧、仅右侧、两侧不足、工具条退到上方、四角组合、负坐标和 100%／125% DPI。
- 新增整帧像素回归覆盖左／右标签、工具条避让、浅深主题与两种 DPI，并继续断言标签和边界属于同一选区。
- 之前的实际恢复显示调用链回归继续覆盖八方向调整、移动、无移动、取消、捕获丢失与旧显示回调；本轮 UI 全量为 405 通过、11 忽略，UI all-targets Clippy 通过。

## 固定顺序定位精简

用户确认工具条可手动移动，因此删除两者互相避让：标签只按上方、左侧、右侧、下方依次尝试。外部候选保持 8 个逻辑像素间距且完整位于所属宿主工作区；均不足时在选区内左上角附近保留 8 个逻辑像素内边距并夹紧到工作区。工具条可覆盖标签，由用户拖开。

- 删除标签的工具条输入、候选工具条计算、碰撞判断与侧边纵向搜索；删除工具条为标签预留空间的逻辑。标签布局只接受选区、屏幕／DPI 和工作区。
- 保留同帧呈现、有限字符纹理缓存、整体物理尺寸、单宿主显示、截图退出清理及窗口恢复前定位。工具条位置、尺寸、收起或手动拖动不改变标签像素。
- 纯定位回归改为固定顺序、四角、内部回退、负坐标与 100%／125% DPI。整帧像素覆盖四个外部方向及内部标签，并确认内部标签也不会进入输出。
- 窗口恢复回归保留八方向调整、移动、无移动、取消与旧回调；删除“不允许覆盖标签”的旧断言，新增改变工具条位置和尺寸后标签布局、文字和整帧像素均不变的断言。
