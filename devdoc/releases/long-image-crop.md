# 长图编辑器裁剪验证

日期：2026-10-21。分支 `codex/long-image-crop`，基于 `main` 的 `4209718`；未暂存、提交、合并或推送。

## 实现

- Core `image_crop` 管理原图整数范围、创建／移动／八方向调整及拖动取消，使用左闭右开边界、向外取整和 1×1 最小值。边缘命中容差不引起按下跳变。
- 已确认范围进入 `annotation::Session` 的同一快照历史；取消和无变化不记录、不清除重做。原图和范围外对象不删除，原图坐标不平移。
- UI 草稿所属编辑器实例；复用原生／Slint 唯一视口输入、捕获及延迟提示。裁剪只改反馈属性，不在鼠标移动时合成或复制全图；应用和历史恢复后居中适应范围，小图不放大。
- 底部临时显示紧凑取消／应用按钮，不恢复左上角浏览按钮行。裁剪中禁用输出和历史；工具切换取消，失焦／捕获丢失恢复本次拖动前草稿。
- 输出监视器分区仍为完整原图，最终才裁切；贴图保留文档和完整冻结采样，保持跨裁剪边缘的效果一致，不更新桌面区域复用记录。
