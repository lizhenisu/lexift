# Lexift 0.0.1-rc.7

本候选版本完成标注工具的主要功能，并改进划词工具条、窗口交互和编辑体验。

## 更新内容

- 新增完整标注体验，包括本地字体名称选择、实时马赛克与模糊、静态马赛克贴纸、橡皮擦及屏幕标注 PNG 导出。
- 改进标注对象编辑规则、数值参数控件、工具条弹层避让与层级，并修复放大镜擦除缺口、文字样式和绘制参数继承等问题。
- 优化标注渲染准备和鼠标输入隔离，减少首次操作卡顿风险。
- 修复划词工具条准备期间的被动窗口样式保护；增加选区边界定位，使工具条避开正向、反向及多行选中的文字。
- 验证图片剪贴板在划词期间保持不变，原应用的复制、剪切、撤销、全选、粘贴快捷键继续工作。

## 安装

下载 `Lexift-0.0.1-rc.7-windows-x86_64-setup.exe` 安装，或下载 portable ZIP 解压运行 `lexift.exe`。

首次翻译前，在 Settings → Service providers 中配置 DeepL API Key。

这是候选版本。请通过 GitHub Issues 报告问题。
