# 界面国际化

## 实现

- App language 独立于 Target language，配置字段 `ui_language` 默认 `en-US`，旧配置缺失该字段时同样使用英文，不跟随系统语言。
- 支持 zh-CN、zh-TW、en-US、en-GB、ja、ko、de、fr、es、it、pt-PT、pt-BR。下拉框使用语言自称，地区变体有明确标识。
- Slint 使用无默认组件上下文的 `@tr`，12 份 PO 位于 `crates/lexift-ui/translations`。Rust 查询表由同一词条在构建时生成，不读取外部运行时翻译文件。
- 配置复用 Core 设置队列、失败回退及最新请求合并。UI 在线程内先选择语言再映射动态状态；现有窗口原地刷新，新窗口显示前应用语言。
- 常见 Core 消息使用稳定的 MessageId，状态及保存反馈使用领域枚举。外部技术错误保留原文并增加本地化说明。
- Windows 托盘图标由 Platform 管理；右键菜单按需创建为 Slint 窗口，由 UI 的同一译文目录生成 TrayMenuLabels。切换语言会关闭展开的菜单，下次打开前应用最新文案，并按实际字体测量宽度。支持方向键、Home/End、Enter/Space/Escape；首字母唯一匹配直接执行，重复匹配循环选择。菜单采用 Slint 可访问列表与条目角色（当前 Slint 未提供 menu/menu-item 角色），并提供本地化名称与默认操作。
- 标注倍率使用本地化数值格式；整数输入仍沿用原有校验和步进。

## 验证（2026-09-26）

- 工作区测试；配置读写、旧配置默认英文、无效语言、保存失败、快速连续切换及目标语言独立性。
- 12 种语言的全部 Settings 页：960 px 浅色、580 px 深色；主窗口、Popup、语言菜单、标注工具条和参数面板渲染。检查简繁中文、日韩、德法与葡萄牙语；侧边栏按文案测宽，按钮长文字可换行。
- 动态切换保留输入、译文、截图数值、标注参数和当前页面；英语/德语小数格式与解析验证。
- Windows 当前显示器 125% DPI 实测 App language 下拉切换为中文、保存提示、托盘中文菜单及方向键操作、设置窗口关闭重开、后台启动后第一次唤出、应用重启恢复语言、Alt+A 工具条和参数面板本地化。
- Slint 静态检查、workspace build/test、Clippy 和 Windows Release 构建。

不同 DPI 双屏的交互布局尚未实机复核。外部服务和系统技术详情保留原文；译文尚未经过逐语言母语审校。

## 复现渲染

设置环境变量 `LEXIFT_I18N_SNAPSHOT_DIR` 后运行：

```powershell
cargo test -p lexift-ui i18n::tests::all_languages
```

测试按需输出 BMP；不设置该变量时只做断言，不生成文件。词条维护说明见 translations/README.md。
