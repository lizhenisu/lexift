# 马赛克贴纸

马赛克分组的第二个工具条目是独立的静态贴纸（内部条目 12），原实时马赛克保持条目 11。贴纸具有独立编辑范围，不依赖屏幕采集能力。

## 对象与纹理

- Core 保存区域／圆形笔刷几何、纹理类型、不透明度、创建 DPI、物理直径、纹理大小、固定种子及局部坐标变换，不保存屏幕像素或纹理位图。
- 默认区域、方格玻璃、95% 不透明度、12 逻辑像素纹理、12 逻辑像素笔刷；区域圆角 21。磨砂使用固定浅灰颗粒，不读取底层颜色。
- UI 使用 64×64 的确定性重复纹理，缓存最多 8 个类型／种子组合。区域与笔刷复用共用覆盖栅格，避免重复笔刷段叠加透明度。
- 区域对象的整体移动和缩放同时变换纹理与擦除覆盖；纹理大小修改设置当前显示尺寸。笔刷完成后不可选中、移动、缩放或修改参数，与普通铅笔及实时马赛克／模糊笔刷一致；仍支持橡皮擦、撤销和全部清除。参数面板复用 UI 数值字段，其中 `strength` 表示不透明度，`zoom` 表示纹理大小，独立数值参数字段为 `-109`，不改变放大镜字段含义。

## 渲染与生命周期

贴纸作为普通栅格标注进入软件与 GPU 场景，遵守文档顺序及对象擦除覆盖。现有对象栅格缓存保留静止像素；只有贴纸时不启动实时效果 worker、采集请求或轮询定时器，也不等待首帧采集。会话关闭清理纹理缓存。

半透明贴纸只改变覆盖颜色，不能真正模糊下方内容，可能仍能读出文字。100% 不透明度可以完全盖住内部内容；边缘保留抗锯齿。

## 回归

- Core：独立编辑范围、区域控制点、笔刷完成后锁定、负坐标区域移动缩放、纹理变换、擦除缺口、撤销及全部清除。
- UI：采集可用／不可用均能创建，采集调用为零，无实时 worker／轮询，静止呈现复用；对象回填不透明度不受聚光灯影响。
- 像素：两种纹理、100%／125% DPI、确定性重复、软件与原生场景栅格一致、擦除及移动失效、0% 透明度、放大镜包含／排除贴纸。
- 实机截图与验证日志写入忽略的 `target/sticker-*`，不进入版本库。双屏 100%／125% 已执行菜单选择、纹理切换、区域与笔刷绘制；负坐标由自动化覆盖。
