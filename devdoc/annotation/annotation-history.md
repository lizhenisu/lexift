# 标注撤销与重做

普通屏幕标注、静态截图、贴图标注及长图编辑共用 Core `annotation::Session` 的文档历史。每份文档独立持有记录，关闭文档后释放；不写配置或磁盘。

## 操作

| 入口 | 行为 |
| --- | --- |
| 撤销按钮、Ctrl+Z | 撤销一次已提交操作；有未完成绘制时先按既有规则取消当前操作 |
| 重做按钮、Ctrl+Y、Ctrl+Shift+Z | 恢复一次已撤销操作 |

重做按钮位于撤销右侧，使用 SVG 图标及一秒延迟提示。没有对应历史或输出忙碌时禁用。快捷键兼容大小写，仅所属编辑器本地处理，系统按键重复逐次执行，不注册全局快捷键。

文字、宽高和参数输入优先使用自身编辑规则；菜单、对话框及 OCR／输出期间不修改文档历史。绘制、对象手势及图片平移期间忽略重做。点击工具条历史按钮会按既有规则收尾文字或样式事务；如果形成新提交，旧重做分支失效。

## 事务与身份

新增、删除、清空、几何变换、样式、文字、水印及擦除均以提交事务为单位。拖动和连续参数调整不产生逐帧历史。新的有效提交清除重做分支；取消、无变化操作、选择及工具切换保留它。

选区位置／尺寸、图片平移／缩放、窗口位置及未作用于对象的工具默认值不属于标注文档历史。

快照保存对象及身份、序号后续值、水印、聚光灯透明度和擦除覆盖。恢复后按当前工具编辑权限过滤选择；对象 ID 分配器不回退。失败的临时马赛克对象同时从撤销、重做及手势快照中移除，不能被旧历史复活。

历史恢复同步参数投影、序号、悬停和按钮状态，退休过期参数／菜单目标，并使受影响的效果呈现缓存失效。贴图接收可编辑文档时保留其历史；普通导出仍只冻结可见内容，不复制历史进入渲染任务。

验证及实机覆盖边界见[标注重做验证](../releases/annotation-redo.md)。
