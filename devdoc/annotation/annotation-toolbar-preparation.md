- 主工具条改接已有非激活工具条输入桥：点击收起／展开和拖拽不激活主工具条。参数面板仍使用原有可交互桥，允许用户主动编辑数值；没有通过事后抢回焦点修复。

## 实现约束

- 主标注工具条使用原有客户区指针桥的鼠标捕获。按下固定逻辑抓握点，移动读取物理桌面光标位置，跨 DPI 时重新换算偏移。翻译窗口仍使用原生标题栏移动。
- Escape 在已有工具条跟随计时中检查，只在工具条实际拥有捕获时释放捕获并恢复起始位置；捕获丢失保留当前位置。整个过程不激活工具条。
- 二级参数面板与工具分组菜单共用窗口身份、隐藏准备及销毁能力。参数面板先设置位置和 DPI、测量完整未换行宽度，再计算最终宽度下的换行高度；物理宽高向上取整。工具选择菜单直接使用 220 DIP 宽度及按条目数计算的高度，不读取参数布局属性。
- 隐藏快照使 Slint 真正求值最终宽度的布局。仅比较属性而不求值，实机仍可出现约 32 个物理像素的首次宽度变化。
- 连续两轮的窗口 token、DPI、位置、大小、工具、布局和语言版本一致后，完成输入桥及 owner 接线再显示；仅参数面板将参数值纳入稳定性判断。Slint/Winit 使用最终尺寸预绘首次画面；显示后不再切换原生框架样式。
- 准备任务由当前面板 Slot 的可取消计时器持有，最多重试 20 次、间隔 16ms；关闭和重开通过会话及实例版本丢弃旧回调。准备失败销毁窗口。

## 本轮验证（2026-10-07）

- UI 回归覆盖待创建 HWND 不可见、两轮布局稳定、显示前输入接线、owner 失败重试、重开后旧任务失效、物理取整和负坐标。
- 独立软件像素回归覆盖 14 个工具、320／1400 逻辑像素可用宽度、100%／125% DPI；检查首次绘制的四角及底边。
- 实际 Windows App 在两台显示器的 100%／125% DPI 下，各轮换矩形、放大镜、荧光笔开关面板 100 次；首次检测窗口边界与 90ms 后边界一致。
- 两个 DPI 的把手按下前／按下后截图逐像素一致；检查四向光标不变、前台窗口不变、拖动与 Escape 回到原位。
- Release 录屏分别为 605 帧／12 秒（约 50.4 FPS）和 620 帧／11.983 秒（约 51.7 FPS）。逐帧提取共 64 个首次出现画面，检查圆角及高度；没有把请求的 60 FPS 当成实际帧率，也不能据此保证覆盖 144Hz 的每帧。
- UI／Platform 库测试、Slint 编译（UI build.rs）、Clippy 和 Windows Release 构建通过。

本机证据保存在忽略的 `target/`：`toolbar-grip-before-*`、`toolbar-grip-pressed-*`、`toolbar-first-visible-*`、`toolbar-first-frames-*.mp4`、`toolbar-first-*.csv` 和 `toolbar-recording-check-*.json`。

本轮未在实机单独覆盖负坐标、极小工作区、全部语言或每个工具分别 100 次；负坐标和受限宽度由自动化覆盖。正文焦点、鼠标穿透、过期回调及参数行为沿用现有回归测试。未暂存、提交或推送。

## 下拉标记与贴边吸附（2026-10-07）

- 共用 ComboBox 改用保留原形状的 SVG，按实际高度居中。独立像素测试覆盖 30／38 DIP、100%／125% DPI 的正常、悬停及展开状态，可见箭头中心偏差不超过一个物理像素。
- 客户区拖动从原抓握点计算坐标，12 DIP 内贴齐主工具条到光标所在显示器的工作区边缘，超过 20 DIP 解除。各轴独立；工作区、DPI 或窗口大小改变后清除旧锁定。工作区未知或该轴容不下工具条时自由拖动。
- 移动事件和既有跟随计时共用定位函数，处理跨屏后的 DPI 稳定；只在位置变化时设置窗口位置。二级面板保持现有跟随及边缘翻转，不扩大为联合吸附矩形。
- Release 实机验证两个 DPI 的四边、角落、吸附后拉开、面板跟随、四向光标、前台焦点、Escape，以及 125%→100% 跨屏拖动。捕获取消通过向所属工具条发送原生取消并确认实际捕获释放验证；跨进程夹具的 SetCapture 未转移原捕获，不作为通过证据。
- 截图保存在 `target/toolbar-dropdown-centered-*.png`、`toolbar-dropdown-open-*.png`、`toolbar-snap-*-*.png`。负坐标、尺寸过大、阈值边界、回程及尺寸／DPI／工作区变化由自动化覆盖；负坐标和極小工作区未实机覆盖。
- 相关 UI／Platform 回归、Slint 编译、Clippy 及 Windows Release 构建通过。没有新增 Core 接口、依赖或配置；未暂存、提交或推送。

- 选择菜单不加载系统字体目录、不创建字体/参数模型、不回填水印参数或绑定参数事务。文字、水印及序号参数面板按需启动后台字体服务，显示不等待系统扫描；见[字体目录与默认选择](annotation-fonts.md)。
