# 矩形橡皮擦连续编辑

## 行为

矩形橡皮擦在绘制期间显示实际擦除结果与细边界，松手后显示八个尺寸控制点和四个圆角控制点。命中顺序为控制点、圆角区域内部、空白区域；内部可移动，四个圆角控制点共同调整统一圆角。

编辑仅限当前一次擦除。空白处开始下一次擦除、切换工具或橡皮擦模式、进入鼠标操作模式后固定结果，不能重新选中。撤销结束临时编辑；捕获丢失或 Escape 沿用既有手势取消规则，恢复当前调整前的覆盖和几何。

创建和每次有实际覆盖变更的调整分别提交撤销步骤。空白或重复覆盖不创建历史，但有效矩形仍保留并立即进入编辑；宽高任一不足 2 个物理像素的创建不保留编辑区域。空白创建可移动到创建前已有目标并擦除。取消一项调整不会撤销此前已完成的擦除。

## 所有权与渲染

- Core 的 `Session` 持有临时矩形编辑和创建前的目标身份／覆盖基线，不保留截图或复制对象正文。移动、缩放与圆角调整先恢复基线，再由既有栅格适配器判断可见目标。旧擦除保留，新绘制对象不受旧擦除影响。
- 绘制／编辑阶段独立于文档快照，松手明确转入编辑并请求重绘，不依赖下一次点击。`RoundedRectangle` 提供共用的控制点、圆角和命中计算；现有荧光笔、马赛克和贴纸复用相同几何规则。擦除不作为任何可见标注对象加入文档。
- UI 冻结一次手势的参数和几何，输入由既有画布路由处理。独立交互层绘制边界，控制点绘制与荧光笔、马赛克和贴纸共用，显示签名包含几何及控制点可见状态，文档／效果签名仅包含实际擦除覆盖。
- 圆角擦除沿用目标所属覆盖及仿射变换；软件合成和 GPU 效果使用同一栅格遮罩。导出快照只复制已应用的覆盖，不复制临时编辑状态，不导出控制点。
