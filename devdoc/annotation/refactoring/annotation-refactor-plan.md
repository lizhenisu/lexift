### 模块边界与代码约束

- Core Session 拥有文档、选择、可编辑规则和撤销；UI 不复制业务状态机。
- 编辑实例拥有内容、光标、选区、组字和编辑任务；参数模块拥有来源、目标和补丁；窗口/焦点模块拥有组件、事件桥接和关闭返回规则。
- 协调器保留会话身份、跨模块交接顺序和路由；纯几何、排版、窗口构建与效果算法不接收整个 Registry。
- Platform 拥有采集、GPU、原生呈现与设备恢复；App 保持组装职责，遵守现有七个 crate 的依赖方向。
- 每批迁移一条完整操作链路和全部调用方，删除被替代路径；不增加通用事件总线、服务容器或第二份状态。
- 当前范围不新增公开 Core 接口、配置、crate 或依赖；如确有必要，先说明具体能力缺口和依赖方向，再调整计划。
