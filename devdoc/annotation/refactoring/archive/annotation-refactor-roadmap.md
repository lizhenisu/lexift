## 本轮审查结论与执行计划（2026-10-03）

本节是当前执行入口，优先于下文历史阶段的“下一批”描述。既有实现与性能证据保留在 [实现与实验记录](../annotation-refactor.md)，不重新实施已完成的迁移。计划整理阶段仅修改文档；后续实现进度单独列在下节。

### 后续实现进度：参数来源与P0回归修复

参数State现已分别拥有绘制默认值与按ObjectId校验的对象投影，未使用Index/IndexMut兼容层。参数更新校验事件来源对象；新序号读取默认样式；取消、撤销、删除及选择目标改变后重新回填。字体的显式手动选择继续作为偏好保存，对象回填不标记手动选择。矩形/椭圆工具槽与Core共用身份的映射保留。

原序号测试要求对象参数修改传播到下一对象，与本计划的参数来源规则冲突。已保留当前对象中文格式、字号、说明、插入选区及继续输入断言，并增加新建默认格式、删除后面板回填、过期对象事件拒绝和新目标回填断言。当前workspace 435通过/38忽略，Clippy及Windows Release通过，详见证据账本。下表“当前基线存在失败”为制定计划时的事实，不再代表这批修复后的测试状态。

剩余范围明确保留：空白编辑草稿、水印独立来源、参数事件的编辑实例校验、菜单请求接口、编辑场景副本、失败降级保留，以及GPU独立源/候选/真实显示对应和真实App验收。本节不把基础状态分离等同于整个B批完成。

参数值事件的编辑实例校验现已接入：事件发出时捕获panel/tool/ObjectId/editor完整Target，执行时与当前Target比较，不再到执行阶段才给旧事件赋予新editor编号。编辑所有者提供不持有窗口的身份句柄，take/clear/Drop先失效，Registry重入期间也可捕获真实来源。同对象关闭重开后的旧参数事件通过真实面板回调验证被拒绝。草稿/水印来源及菜单、拖动结束等其余事件入口仍待处理；本项不代替整组弹层与焦点生命周期验收。

新文字草稿的参数现由文字编辑实例拥有，Registry仅将工具8的读写路由到活动草稿。提交使用取出的草稿参数生成对象样式，取消及准备失败释放它们；编辑结束时先回填面板，避免后续关闭面板把旧值保存为绘制默认值。空白草稿缩放回填也进入该存储；已有对象/序号说明继续使用对象投影，不创建额外草稿参数副本。取消不产生撤销，提交保留字号、自定义颜色及背景参数，一次撤销移除新对象的回归通过。下一步仍需处理水印独立来源及其余延迟事件，完整性能与真实App验收范围不变。

已应用水印现使用独立参数投影，应用模板和对象回填不再写入绘制默认值。投影版本在应用、清除、撤销及重新回填时更换，参数值事件捕获并校验该版本；连续滑杆调整保留版本以合并撤销。默认字体更新可独立于已应用水印进行，实际水印字体仍由对象投影显示。新增取消输入保持已应用内容、改色/字号不污染默认值、清除后旧事件拒绝及撤销回填回归。基础参数来源分离已接线；菜单请求、拖动结束/焦点等其他事件入口、场景复制与GPU完整验收仍未完成。

三级参数菜单已保存打开时的参数Target；选择、颜色、样式、显示重试及返回父面板共用目标校验。对象/编辑目标变化或水印投影更换时销毁旧菜单，旧关闭不恢复新编辑焦点；二级工具条保留。真实回调回归保留旧菜单组件，关闭重开同一序号说明后继续触发旧字体选择，确认不改变字体及新编辑，参数面板仍显示。菜单构建仍接收较宽Registry上下文；普通对象相同ObjectId下撤销后的投影版本、其他延迟入口及GPU/真实App验收继续保留为后续工作。

普通对象投影版本已接入统一参数Target。重新回填和取消选中使旧版本失效，连续参数编辑保留版本；撤销恢复同一ObjectId后，旧工具条及菜单事件也被拒绝。真实回归先调整矩形线宽，排入旧线宽/外形事件，再撤销；恢复对象身份、外形和线宽保持正确，菜单关闭，二级工具条保留，第二次撤销移除创建且无额外历史。该UI事件版本不进入文档签名或GPU场景；菜单请求接口、其他延迟入口及完整性能/真实App验收仍需继续。

菜单字段补丁现在显式携带目标，通过共用参数入口立即更新Core对象及编辑草稿，再回填工具条。工具条事件使用同一入口，Slint属性回调的重复值作为无变化事件忽略；移除马赛克菜单的特殊二次转发。已复现并修复“菜单颜色已接受、说明立即结束后丢色”的问题。菜单仍需由独立请求构建，不把这次应用入口统一当作整个菜单解耦完成。

菜单窗口构建现接收明确展示请求、工具类型及不可变参数快照，不访问Registry或工具条组件。协调层从有效参数来源获取快照，保持目标校验、菜单替换及焦点规则。窗口构建与原生展示的边界已分别收窄，但菜单回调协调、时间菜单构建及剩余Registry依赖尚未全部迁移。

马赛克的显式区域/笔刷选择现独立于对象效果投影。已复现取消选中后笔刷模式丢失；修复保留后续绘制模式，效果及强度仍恢复默认值。未手动选择模式时保留对象类型回填，避免禁用旧笔刷直径控件；主动选择后的模式在重新回填时保留。该字段角色拆分不扩展到其他尚未验证的参数，剩余事件/场景/GPU/实机验收范围保持。

GPU测试源现先在离屏GDI缓冲区绘制完整色带，再通过一次BitBlt发布，避免逐色带窗口写入被统计为额外源更新。当前三组各1800次绘制均对应1800次所属窗口取帧，同机旧大模糊基线为1824次取帧。总提交仍约75/s，P95约22ms；这些数据仍非有效显示帧率。独立源帧版本到不可变输出候选/成功提交，以及真实显示和输入延迟的对应继续未完成。

测试诊断现为采集已发布纹理保存token/sequence/WGC ticks，效果重算时冻结实际采样来源及下层依赖，输出候选和成功原生提交继承该快照。来源记录不参与生产状态比较，不读回像素。三组所属源不同版本提交约59.935/60.003/60.036每秒，间隔P95约25.826/24.643/24.878ms，取帧到提交P95约22.3ms，均无混合版本、无来源记录丢弃；各有一个区间边界未匹配记录。仍未核验paint ID和实际显示，不能用提交FPS代替显示FPS；P95门槛仍未达到。

所属源统计现只计区间内取帧版本的首次成功提交，排除热身与重复版本；纯回归覆盖热身、重复及混合候选。重新测量四重叠/大模糊/长笔刷的首次取帧到提交P95为9.925/9.388/9.220ms，原约22ms口径包含重复提交，不能视为算法优化前后差异。交换链统计独立探测在当前机器返回有效计数/QPC，但首帧失效且计数会滞后；下一步须将计数与冻结候选对应，仍未证明实际显示FPS、paint ID或输入到显示延迟。

交换链提交编号已与冻结候选来源关联，系统呈现计数按实例及精确编号匹配；跳号不确认中间候选，重复/其他交换链回归通过。当前三组所属源系统计数约59.067/59.669/59.802版本每秒；仅为OS计数/元数据证据，CPU观察间隔不是精确显示时间。下一步按QPC核算并验证paint ID/像素及真实App输入，保留完整重构与失败降级范围。

系统呈现间隔现按DirectComposition的QPC频率核算，仅接受相同链路/频率、单调QPC及刷新计数一致的样本，并排除区间外来源版本。三组QPC频率10MHz、有效间隔均无排除，P95均27.784ms，仍超过20ms门槛；不能把CPU观察约29ms当作精确值，也不能据此直接归因GPU计算。后续保留显示刷新周期/调度归因、paint ID/像素、真实输入及UI迁移要求。

采集比较绕过实验经两次复测未稳定改善显示指标，已撤回。当前新增仅测试使用的刷新周期直方图：大模糊推算周期6.946ms、QPC间隔P95 27.784ms，其中225个间隔跨4周期，仍未通过20ms门槛。诊断不改变生产调度或系统刷新率，后续仍需像素/输入与真实App验收；详情见证据账本。

水印时间菜单现与参数菜单共用仅依赖展示请求的列表构建；选择、取消及原生关闭由统一窗口回调向协调层报告。受控回归覆盖旧菜单存活、排队事件跨重开，以及有效预设选择后继续输入。协调层Registry依赖与其余任务所有权仍保留为后续迁移，详见证据账本。

原生场景编辑现借用Core文档，仅持有替换的活动文字/说明对象；不再在原生提交前复制全部轨迹。交互层仍独立缓存，旧软件效果拥有快照保留。画面对照与20000点未编辑轨迹引用回归通过，实际延迟/资源及剩余软件副本验收继续保留。

软件效果worker现借用Job内的下层对象范围，放大镜取景不再复制整组对象；保留Tile索引，后台取景关闭选框并限制聚光背景范围。必要跨线程Job快照仍存在，UI软件编辑投影及实际性能验收继续保留，详见证据账本。

软件Job现共享不可变文档快照，屏幕采集serial变化而文档内容不变时复用Arc及轨迹缓冲区。复用检查完整内容而非视口签名，停止软件或清空采集区域时释放缓存。20000点复用/变更冻结/Weak释放回归通过；UI软件编辑副本、GPU呈现与完整实机验收仍未完成，详见证据账本。

软件编辑现同样借用Document，visible_session整份副本已删除；绘制、签名、手势与后台物化共用编辑替换，预览临时复制也已移除。软件/原生及后台对象对照通过；必要预览状态、窗口迁移、故障恢复、GPU显示性能与完整App验收仍未完成，详见证据账本。

### 实施顺序

#### P0：恢复可靠基线

- 复现序号参数失败，跟踪面板值、默认值、对象投影、编号计数器及回调目标；判断实现错误还是测试预期与已确认行为冲突，禁止直接放宽断言。
- 核对新建、取消、撤销、删除及选择切换后的面板回填，特别是矩形/椭圆共用Core工具身份、序号创建默认值和已关闭面板的延迟事件。
- 整理行为清单：二级工具条保持展开、三级独立关闭、说明参数操作后继续输入、一次操作一次撤销、取消恢复编号、已完成铅笔不可编辑。
- 保存当前失败证据；修复后重新运行相关回归和workspace门禁，形成对应当前源码的基线。

出口：当前失败得到解释与修复，行为清单可重复验证；旧测试结果不得替代本批结果。

#### P1：完成参数、菜单与焦点边界

- 复用已有参数State，明确四种来源：后续绘制默认值、选中对象投影、编辑草稿、水印编辑。选中回填只更新投影，手动字体偏好单独管理。
- 参数事件使用明确目标和字段补丁；来源包含会话、窗口/面板实例、对象或编辑实例。校验通过才应用，避免整份旧AnnotationValues覆盖新状态。
- 选择变化时重新生成实际投影；取消和撤销后以恢复的Core状态回填，不只更新binding编号。
- 菜单仅接收定位/展示请求并返回用户选择；工具切换、参数事务和焦点恢复由协调层决定。字体扫描、默认推荐不进入鼠标热路径。
- 复用现有焦点协调器：输入控件和弹层交互完成后恢复同一编辑实例，保留插入位置、选区和中文组字；旧恢复任务失效。

出口：选中不同对象不改变新对象默认值；改色、字号、字体后原位置继续输入；三级关闭后二级仍显示；过期事件无效果。

#### P1：收拢手势及窗口任务所有权

- 创建、移动、缩放、连续参数操作遵循统一开始/更新/提交/取消规则，Core拥有撤销快照，UI拥有输入捕获及临时手势。
- 每个窗口、菜单、编辑实例拥有自己的计时器、回调和延迟任务；销毁同时取消，不保留隐藏组件等待重开。
- 收窄剩余子模块对Registry的访问，传递明确上下文与能力；数字工具/字段协议逐步限制在Slint边界，不一次替换全部事件系统。

出口：Escape、捕获丢失、切换工具与关闭均正确收尾；一次操作一次撤销；重开后旧任务不能修改新窗口。

#### P2：减少场景复制与扩大增量复用

- 先记录实际任务中的深复制、栅格重算和上传范围；必要的跨线程快照保留，重复轨迹副本逐项消除。
- 编辑投影只替换正在编辑的对象，其余对象借用或共享不可变绘制资产；不把撤销历史送入渲染任务。
- 文档内容与选框、光标、组字等交互覆盖层分别失效；光标闪烁不重算正文或马赛克。
- 复用当前SceneCompiler、RasterCache及逐效果依赖，验证下层变化只影响相关后续效果、静止像素不重复提交。

出口：长笔刷、编辑说明和光标闪烁的复制/重算范围有前后证据；图层顺序及文字测量、绘制、定位保持一致。

#### P2：按证据优化实时链路，并验证故障降级

- 建立独立源绘制帧、WGC到达/取帧、比较确认、不可变输出候选、提交与实际显示的对应；区分重复通知、中途更新和独立有效帧。
- 只优化测量确认的瓶颈，一次一个阶段；沿用最新帧合并、有界诊断及候选授权。不恢复已证明无收益的显示重试实验，不通过降低画质或积压帧达标。
- 注入采集失败、设备丢失、重建失败与提交失败；首次失败回滚，后续失败保留最近有效效果，软件降级复用场景规则。
- 检查关闭后线程、纹理、DC、订阅、回调和任务释放；重开从最新Core状态重建。

出口：每次优化有独立对照；故障不留下空白对象或旧实例结果；资源释放有证据。

#### P3：真实应用验收及清理迁移路径

- 当前Windows Release覆盖全部工具、中文IME、选区与焦点、撤销/取消、快速关闭重开，以及100%/125% DPI、负坐标、跨屏。
- RTX 4060、60Hz变化源下，1280×720高强度模糊、80逻辑像素长笔刷、四个重叠效果各测30秒。
- 沿用目标：独立有效更新平均≥57FPS、帧间隔P95≤20ms、GPU处理P95≤12ms、输入到显示P95≤50ms；软件降级不承担这些性能指标。
- 普通字形保持结果；马赛克每通道误差≤1，模糊有效σ偏差≤10%，强度单调且无接缝。无法实机覆盖的场景标为未验证。

- 捕获丢失、Escape、工具切换统一取消；无变化操作不产生撤销。
- 迁移 UI 调用后删除重复身份和旧快照逻辑。

出口：一次用户操作一次撤销；取消恢复对象、编号及选中状态；身份不会因撤销或重开被错误复用。

### 3. 拆分 UI 状态所有权

- 按窗口与弹层 → 参数与焦点 → 文字编辑 → 手势的顺序迁移，逐项保持可运行。
- 用明确的工具、参数目标和实例类型替代跨模块数字协议；只在 Slint 边界转换。
- 延迟任务校验会话、所属窗口/编辑实例与菜单状态；由所属模块取消任务和释放回调。
- 移除生产模块对父模块的通配导入；测试内的 `super::*` 不作为问题处理。

出口：参数操作后继续输入；三级菜单关闭不收起二级工具条；旧任务无法影响新窗口；子模块可独立测试。

### 4. 建立不可变场景与增量缓存

- 场景只包含绘制必要数据，不复制撤销历史。
- 普通标注与文字使用局部 RasterKey 缓存；几何、样式和字形变化各自使必要资产失效。
- 文档内容与交互覆盖层分开版本；光标闪烁不重新处理模糊或整屏文字。
- 建立效果依赖：下层改变只使受影响的后续效果失效；保留放大镜现有不递归取景规则。
- 清理删除对象、离开视口和结束会话对应的缓存。

出口：可验证的失效范围；静止状态不重复栅格化；普通文字的测量、绘制与鼠标定位保持一致。

### 5. 接通 GPU 默认路径与降级

- App 注入已有 AnnotationRenderPort，UI SceneCompiler 提交场景，Slint 保留输入与 IME。
- 逐步接通普通标注、马赛克/模糊、放大镜、交互覆盖层；每一步可运行并有画面对照。
- 正常 GPU 路径保持纹理在设备上；不读回整屏像素再交给 CPU 合成。
- 完成最新帧调度、相同像素检测、提交前版本校验和暂停区域恢复。
- 删除最后一个实时效果时停止采集；关闭会话释放线程、窗口、纹理、DC 与回调。
- 设备故障尝试重建，失败后切换软件后端；首次采集失败不留下空白对象。
- 验证新路径后删除旧的重复编排逻辑；软件降级复用场景和参数规则。

出口：实际应用使用 GPU；故障可恢复；两种后端共享行为，不维护两套 UI 状态机。

### 6. 验收与收尾

- 画质：普通字形无变化；马赛克每通道误差不超过 1；模糊有效 σ 偏差不超过 10%，强度单调，分块无接缝。
- 性能：当前 RTX 4060、Release、60Hz 变化源，单个 1280×720 高强度模糊、80 逻辑像素长笔刷、四个重叠效果各测 30 秒。
- 目标：平均更新至少 57FPS；帧间隔 P95 ≤20ms；GPU 处理 P95 ≤12ms；输入到显示 P95 ≤50ms。软件降级不承担该指标。
- 交互：覆盖全部工具、焦点、中文输入、撤销、取消、快速关闭重开、100%/125% DPI、负坐标与跨屏。
- 构建：相关测试、workspace 测试/构建、Slint 编译、Clippy `-D warnings`、Windows Release。
- 保存真实截图、性能统计与资源生命周期证据；无法实机覆盖的情况明确记录。

出口：每项证据对应当前代码，移除迁移遗留分支；不以旧日志或单项 GPU 基准替代应用验收。

## 风险控制

- 不同时改文字排版与焦点生命周期；文字视觉结果作为固定基线。
- 不一次性替换全部窗口机制；每个窗口所有者迁移后先验证关闭与重开。
- 不把性能问题简单归因于文件过长；以耗时、栅格范围、上传量与排队延迟确定优化点。
- 不先承诺完成日期；阶段 1 测量后再估算剩余工作，按阶段出口推进。
