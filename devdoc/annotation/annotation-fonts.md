# 标注字体目录与默认选择

文字、水印和序号共用本机已安装字体目录。目录按显示名称忽略大小写排序，同名时按原名称稳定排序并去重；名称保持原样，不翻译或按拼音排序。

## 按需加载

首次进入文字、水印、序号参数面板或使用文字类工具时，按需启动后台目录任务。启动软件和普通工具选择菜单不扫描字体。依次采用第一个已安装的候选；候选缺失时解析系统无衬线字体。

## 后台准备与共享缓存

`annotation/font_service.rs` 管理未加载、加载中、就绪、失败四种状态；并发请求合并为一次扫描，失败仅在用户点击重试后重新加载。扫描、排序、别名和默认字体元数据生成均在后台，锁只用于读取或发布状态。空目录作为失败处理。

就绪结果持有不可变 `Arc<fontdb::Database>`。UI 字体目录、软件绘制和后台导出复用该数据库；各线程单独保留字形字节和排版缓存，不再通过线程局部初始化扫描系统字体。公共数据库按进程缓存，关闭标注不释放，不引入磁盘缓存或安装监控。

`font_workflow.rs` 在 UI 线程管理不持有组件的订阅，完成时校验加载请求、标注会话和面板实例。面板关闭撤销订阅；后台仍可完成公共缓存，重开时直接采用缓存。完成更新只回填目录、字体默认值和字体索引，保留其他参数，默认值按当时界面语言解析。

参数面板沿用隐藏准备流程；固定大小的 `FontPicker` 显示加载或重试状态，不因完成而重建窗口。加载期间字体选择、水印内容编辑、新建文字和序号不可用；其他参数可操作。被拒绝的创建不进入撤销历史、不延后执行。创建与编辑入口检查就绪，导出遇到未就绪字体明确失败，禁止同步扫描回退或输出空白正文。

## 默认字体

候选匹配后，使用字体自带的语言名称元数据，优先选择当前界面语言对应、且已存在于目录中的名称。例如简体中文默认选择“微软雅黑”，而不是“Microsoft YaHei”。没有对应名称时保留候选原名；系统无衬线回退同样处理。中英文名称仍全部保留，手动选择英文名称不会被转换。名称对应关系只在目录初始化时建立。

| 界面语言 | 候选顺序 |
| --- | --- |
| 简体中文 | Microsoft YaHei、Noto Sans CJK SC |
| 繁体中文 | Microsoft JhengHei、Noto Sans CJK TC |
| 日语 | Yu Gothic、Meiryo、Noto Sans CJK JP |
| 韩语 | Malgun Gothic、Noto Sans CJK KR |
| 英语及其他欧洲语言 | Segoe UI、Noto Sans、Arial |

三个工具分别保存本进程内的手动字体偏好。语言切换只更新未手动选择的默认字体；已有对象、当前编辑草稿保持实际字体。对象参数回填不记为手动选择。关闭标注会话保留偏好，退出进程后不保留。

## 菜单定位

字体菜单展开及窗口 DPI 布局完成后，将当前字体滚动至列表中部；靠近首尾时限制在滚动范围内。上下方向键、Home 和 End 更新选中行，并确保该行可见。推荐字体不改变目录排序。
