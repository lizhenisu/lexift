# 标注数值参数 UI

数值入口统一使用 `NumericButton`：SVG 图标、数值块、参数名提示。
点击后使用现有 `AnnotationChoiceWindow` 显示滑杆、数值输入框和滚轮提示。
序号下一编号继续使用原有输入框。

## 入口覆盖表

| 工具或面板 | 数值参数 | 范围／步进 | 禁用条件 |
|---|---|---|---|
| 矩形、椭圆 | 边框宽度、圆角 | 1–100、0–100；步进 1 | 填充时禁用宽度；椭圆禁用圆角 |
| 聚光灯 | 边框宽度、圆角、强度 | 1–100、0–100、0–100%；步进 1 | 关闭边框时禁用宽度；椭圆禁用圆角 |
| 铅笔 | 笔画大小 | 1–100；步进 1 | 只改变后续笔迹 |
| 荧光笔 | 笔画宽度 | 1–100；步进 1 | 矩形模式禁用 |
| 箭头、折线 | 笔画宽度 | 1–100；步进 1 | 沿用原工具规则 |
| 放大镜 | 边框宽度、倍率 | 1–100；1–8×，步进 0.01× | 沿用原工具规则 |
| 文字、序号 | 字号 | 5–i32::MAX；步进 1 | 无新增上限 |
| 水印 | 字号、不透明度 | 5–144、0–100%；步进 1 | 沿用原水印应用规则 |
| 序号说明 | 相对说明字号 | 60%、80%、100%、125%、150% | 收起说明设置时隐藏入口 |
| 文字、序号描边 | 描边宽度（面板内嵌滑杆与输入框） | 1–20；步进 1 | 描边未启用时不显示面板 |
| 文字背景 | 不透明度、圆角、内边距（面板内嵌滑杆与输入框） | 0–100；步进 1 | 背景未启用时不显示面板 |
| 马赛克 | 笔刷大小、强度 | 1–100、0–100%；步进 1 | 区域模式禁用笔刷大小；能力不可用时不显示绘制入口 |
| 橡皮擦 | 笔刷大小 | 1–100；步进 1 | 矩形模式禁用 |
| 备用设置入口 | 宽度、圆角、强度、倍率、字号 | 使用共用参数描述 | 下一编号保留原输入方式 |

## 状态与事务

- `annotation_numeric::Parameter` 集中声明字段、范围、启用条件和滚轮步进。
  `NumericPresentation` 负责对应的本地化名称、SVG 和显示单位。
- 数值菜单只发出一个字段的编辑；样式面板的颜色事件只提交颜色。
  原编辑目标、会话、面板和菜单实例都必须仍然有效。
- 文字／序号字号滑杆初始上限 144，打开时包含当前大字号；确认更大字号继续扩展。
  弹层存续期间不收缩上限。数值框直接输入在确认／失焦时提交，滑杆与滚轮实时提交。
- 序号比例在领域层仍保存 0–4；输入百分比确认时选择最近档，同距取较小档。
  放大倍率在领域层仍保存 100–800。
- 按钮、轨道、滑块、数值框的纵向滚轮都调整同一参数；横向滚轮不修改参数。
  数值框拥有输入焦点时，外部数值变化也更新其文字，防止 Enter 提交旧值。
- 工具条使用按内容尺寸计算的换行布局，原生窗口使用实际布局宽高。
  大数值菜单宽度变化会重新执行共用避让规则，受限空间继续使用原滚动容器。
- 描边／背景面板使用 `NumericRow`，名称、SVG、滑杆及输入框直接展示，不再打开数值子菜单。
  内嵌修改只提交对应字段；图标、轨道和输入框滚轮同步最新状态。颜色选择器继续使用父面板返回协议。
  输入确认及拖动结束沿用原焦点协调与撤销合并；绘制手势保持首次快照。

## 自动化覆盖

- 每个工具在宽／窄布局、100%／125% DPI 下的滚轮命中、点击入口及锚点边界。
- 字段隔离、原范围、字号上限扩展、五档吸附及倍率精度。
- 数值框聚焦后的滑杆／数值框滚轮同步，横向滚轮忽略。
- 已有边框与两条分隔线的增量重绘像素回归。
- 共用菜单的负坐标工作区、工具条避让、生命周期、正文焦点和撤销回归。

实际原生交互截图和日志保存在忽略的 `target/numeric-*` 中；不进入版本库。

### 数值控件居中

- `NumericAdjustmentRow` 使用等高单元，滑杆、输入框及单位共享中心线；内嵌行的名称和 SVG 同样按行高居中。背景行统一预留单位列。
- 输入框在数字区排除箭头后的范围内使用对称内边距和水平居中；下一编号也使用这一规则。
- 共用行保留内部双向数值同步，外部值更新同时刷新滑杆和聚焦中的输入框，避免后续滚轮或 Enter 恢复旧值。
- 两种 DPI 的软件像素回归检查内嵌／弹层滑块中心和单字符、多位数字的水平中心，误差不超过 1 个物理像素；既有增量边框、输入确认及倍率精度回归同时执行。
- UI 301 项测试、UI 全目标 Clippy、Slint 编译、格式检查及 Windows Release 构建通过。
